Local rule (PD-03): unit, web, typecheck, Biome and each task's integration file run locally; the e2e, the real-cell
smoke, `pnpm gate:compose` and the full `pnpm verify` run on the PR's CI only (the isolated e2e script would touch the
owner's demo database). No test touches the network, a real device, `~/.ocw`, the demo or `ocw.autofy.ing`.

## Sampling Rate

- **After every task commit:** the task's unit files (+ its integration file).
- **After every plan wave:** `pnpm lint && pnpm guard && pnpm typecheck && pnpm exec vitest run --project unit
  --project web` locally, then the PR's pipeline (integration included).
- **Before `/gsd-verify-work`:** every workflow green on the final tree (15 T3).
- **Max feedback latency:** 120 seconds locally (unit).
