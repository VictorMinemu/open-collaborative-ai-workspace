## Phase Goal

See `07.12-01-PLAN.md`. **This plan's slice:** the ROADMAP's success criterion 5 and D-08: the whole chain proven on a
clean Linux machine, the way a real server would do it, with only what the API serves.

<objective>
An opt-in proof, run through `scripts/e2e-isolated.sh --cmd`, that starts the pinned slim `node:24` container, installs
`curl git ca-certificates` (D-11), installs the runtime from the isolated API, runs `setup --yes --service none`, lets a
Playwright proof spec approve it in the web, share it with Sam and run Sam's session, then checks the container's doctor
JSON and the no-systemd refusal.

Purpose: HSR-07 (container chain); complements 09 (host) and 04 (unit-tested units).
Output: `scripts/headless-server-proof.sh`, `e2e/proof/headless-server.proof.ts`.
</objective>
