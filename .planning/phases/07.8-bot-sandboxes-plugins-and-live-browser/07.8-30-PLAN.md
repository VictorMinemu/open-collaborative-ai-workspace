## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell (model output) → API | Browser tool bodies are model-written and untrusted |
| viewer → live-view socket | Input frames come from a person's browser |
| contracts → every app | One schema set bounds every payload |
