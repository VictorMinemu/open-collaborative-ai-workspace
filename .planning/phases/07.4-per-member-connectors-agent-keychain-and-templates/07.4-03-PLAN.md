## Phase Goal

A shared agent acts with the credentials of the person who asked, and secrets are used by reference and never seen by
the model (plan map and executor rules: 07.4-01-PLAN.md).

**This plan's slice (tracer, network level):** after the package gate, one guarded request reaches an allowed local
server through a pinned, validated address, and a host that resolves to a private address never gets a connection;
then the whole policy and the Semgrep rule. This is the first building block of the phase (D-07): the API becomes an
HTTP client of admin-, authorization-server- and model-influenced URLs, on the same compose network as PostgreSQL,
Redis and Garage. Plan mode first (CLAUDE.md, D-06).

    // apps/api/src/lib/egress.ts
    export type EgressRefusal = "bad_url" | "scheme" | "userinfo" | "https_required" | "private_address"
      | "platform_host" | "dns_failed" | "timeout" | "too_large";
    export class EgressRefusedError extends Error { readonly code: EgressRefusal; readonly host: string | null }
    export interface EgressPolicy {
      privateAllow?: readonly string[];  // exact "host:port" admitted to RFC 1918 / CGNAT / ULA addresses (never
                                         // loopback, link-local, metadata or unspecified) and to plain http
      requireHttps?: boolean;            // default true: http only for privateAllow hosts and test hosts
      maxBytes?: number;                 // default 1 MiB; readCapped enforces it on the body
      timeoutMs?: number;                // default 15000 (connect + headers + body)
    }
    export interface Egress {
      fetch(input: string | URL, init?: RequestInit, policy?: EgressPolicy): Promise<Response>; // redirect forced "manual"
      bound(policy: EgressPolicy): typeof fetch;  // fetch-compatible, for the MCP SDK `fetchFn` / transport `fetch`
    }
    export function createEgress(opts: { platformHosts: readonly string[]; testHosts?: ReadonlyMap<string, string>;
      lookup?: (host: string) => Promise<Array<{ address: string; family: 4 | 6 }>> }): Egress;
    export function egressFor(env: Env): Egress;            // memoised per env object; platform hosts + test hosts from env
    export function platformHostsFromEnv(env: Env): string[];
    export async function readCapped(res: Response, maxBytes: number): Promise<{ text: string; truncated: boolean }>;
    export function hostPortOf(url: string | URL): string;  // "host:port" with the scheme's default port

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.4-03-01 | Information disclosure | SSRF to platform services or cloud metadata | critical | mitigate | Lookup-time classification of every address, platform host list by name, host:port and address, metadata always refused (Tasks 2, 3) |

| T-07.4-03-06 | Elevation of privilege | test override enabled in production | high | mitigate | Env refusal when NODE_ENV=production (Task 3) |
| T-07.4-03-07 | Tampering | a later change bypasses the guard with a raw call | medium | mitigate | `ocw.raw-egress` Semgrep rule in `pnpm guard` (Task 3) |
