## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| registries → installer | Third-party artifacts and their install scripts |
| installer → bot sandbox | Installed files reach the bot read-only |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07.8-17-01 | Tampering | upstream artifact swapped after approval | high | mitigate | sha256 verified at every install; mismatch refused (Task 2) |

| T-07.8-17-04 | Information disclosure | installer reaching beyond registries | medium | mitigate | Install network with a registries-only egress policy (Task 1) |
