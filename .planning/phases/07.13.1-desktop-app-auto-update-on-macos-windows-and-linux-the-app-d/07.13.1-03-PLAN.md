runs by itself after the check and nothing installs until the click (no install on quit, no unattended restart).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub releases → desktop main | Release metadata and files (untrusted until sha512 verified) |
| desktop main → daemon control socket | The hold request; local, same user |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.13.1-03-01 | Tampering | a turn cut by an install (NSIS kills processes under the install dir) | high | mitigate | Install only from `onQuit` (after shutdown) and only after `held`; tests assert no install call before the quit event |
| T-07.13.1-03-02 | Spoofing | the feed redirected by environment or config | high | mitigate | Feed set in code; test variables ignored when packaged; loopback http only |
| T-07.13.1-03-03 | Tampering | a downgrade or a pre-release pushed as latest | medium | mitigate | `allowDowngrade = false`, `allowPrerelease = false` asserted in tests |
| T-07.13.1-03-04 | Elevation of privilege | the Squirrel or root package-manager updaters | high | mitigate | Explicit construction; Semgrep `ocw.desktop-updater-class` with fixtures |
| T-07.13.1-03-05 | Information disclosure | host paths in UI or logs | medium | mitigate | `logger = null`; views built from fixed sentences, versions and counts; test that serialized views carry no path |
| T-07.13.1-03-06 | Denial of service | restarting under someone at the keyboard | low | mitigate | Unattended restart only at `automatic`, only with `hold(false)` held and 30 min of system idle |
