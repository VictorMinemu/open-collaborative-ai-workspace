## Phase Goal

See `07.17.1.1.2-01-PLAN.md` (PD-14). **This plan's slice:** the Work Zone wake source: a session the task started
wakes the task when the session finishes a turn, waits for an approval, fails, ends or goes offline (the sandbox wake
source is 11, beside it).

<objective>
Store `bot_work_sessions.task_id` when a task turn starts a session, and deliver that session's 07.16 wakes as task
turns while the task waits and has budget (stop it and send a plain wake otherwise; a view turn while another task turn
runs) (D-03, D-04, D-07).

Purpose: "it is woken when … its Work Zone sessions finish" (owner, CONTEXT D-03): the bot hands work to its session
and picks the task up again by itself.
Output: one write in the session start, one branch in the wake delivery, one integration file.
</objective>
