## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API (app role) → PostgreSQL | Application bugs or a compromised route must not read personal rows of another user |
| migration runner (migrator, BYPASSRLS) → data | The backfill writes owner-scoped rows outside RLS |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.2-02-01 | Information disclosure | Admin or cell session reading personal memory rows | critical | mitigate | RESTRICTIVE `personal_owner_only` on four tables keyed on `app.user_id`; tested as `ocw_app` with admin and empty user (Task 1) |
| T-07.2-02-02 | Tampering | App code storing a personal row with a NULL owner (bypassing the policy) | high | mitigate | SECURITY DEFINER trigger derives the owner from the scope, ignoring input; forged NULL test (Task 1) |
