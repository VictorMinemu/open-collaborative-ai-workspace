## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tray / Runtime menu → main | The person's clicks (main process only; no IPC from web content) |
| main → daemon control socket | The hold and release |
| userData files → main | `update-result.json` and the stored AppImage name, read at start |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.13.1-05-01 | Tampering | an installer started while the daemon lives | high | mitigate | The only install call is `onQuit()` in the `quit` event, after `before-quit` awaited `shutdown()` |
| T-07.13.1-05-02 | Elevation of privilege | web content triggering an update or a move | high | mitigate | Items exist only in main-process menus; `DesktopStatus` and the main preload gain nothing (acceptance grep) |
| T-07.13.1-05-03 | Spoofing | a release link outside the repository | medium | mitigate | Fallback links pass `isSafeExternalUrl` and `isReleasePageUrl` as today |
| T-07.13.1-05-04 | Information disclosure | paths in notifications or logs | medium | mitigate | Notifications use versions and file names only; `log()` gets no updater error text |
| T-07.13.1-05-06 | Denial of service | a Mac swap waiting on pid 0, or a daemon orphaned by "Move OCW to Applications" | high | mitigate | Daemon pid recorded before `shutdown()` and passed as 0 only when there is none; the move awaits `shutdown()` before Electron's mover terminates the app (owner UAT row in VALIDATION.md) |
| T-07.13.1-05-05 | Denial of service | a second instance reopening windows during a quit | low | mitigate | `second-instance` ignored while quitting; the AppImage post-install instance exits at once |
</threat_model>
