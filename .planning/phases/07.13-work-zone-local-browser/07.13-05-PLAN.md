## Objective

Per D-04, PD-02, P6 (hub `07.13-01-PLAN.md`). The bots' `brw` image is built from the shared `@ocw/browser-engine`
files (root build context, as the egress image already is), and the infra copies are removed, so bots and Work Zone
sessions read pages through the same redaction code. Every place that builds the image switches to the root context in
24 (same wave, disjoint files). D-04's reversibility note: the brw build and its lockfile scan change; the lockfile
itself (`infra/sandbox/browser/package-lock.json`) stays where `scripts/guard/licenses.mjs` reads it.

Purpose: no second copy of the redaction can drift. Output: the Dockerfile, one shared import in `agent.mjs`, the
removed copies, the sandbox README.
