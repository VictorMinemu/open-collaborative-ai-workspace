## Objective

Per D-10, D-14, D-15, D-19, PD-12, PD-20, PD-25 (hub `07.13-01-PLAN.md`). The Control Plane side of the device's
browser: a new `work-browser` module beside the bots' `browser` module (never generalizing it, research
Anti-Patterns), the Device Link plumbing (capability storage, binary frames off the JSON chain, browser frames both
ways, ephemeral and cross-instance) and the audit of every browser event.

Purpose: principle 12 (every sensitive action audited) and the transport every later API plan uses. Output: hub
extensions, link branch, module skeleton with events and audit, FakeDevice support, tests.
