## Phase Goal

See 07.7-01 (Phase Goal, plan map, cross-plan contracts, P-01 … P-19).

**This plan's slice:** the return half of a consult — the answer and the asker's reply are accepted as triggered posts,
the hop closes when the target's turn is done, the asker gets the answer as a new turn for the same human — plus nesting,
handoff, taint, billing, and Stop. Timeouts and automatic cancel are 07.7-09.

<objective>
Close hops on the turn-done signal, deliver the answer back as `agent.consult_reply.v1`, make consult turns valid
triggers, and let the human stop a chain.

Purpose: A2A-01 (the answer returns as a new turn; each hop visible and audited), A2A-02 (route-level visibility, Stop
authority), A2A-03 (nesting bounded, H pays, limits, taint); D-01, D-02, D-03, D-04; P-02, P-08, P-09, P-11, P-12, P-13, P-14.
Output: `chains.ts`, `chain-routes.ts`, done route, trigger extension, reply capture, three integration test files.
</objective>

    // chains.ts
    turnDone(core, perms, ctx, eventId, { agentId, outcome }): Promise<void>
      1. turn = agent_turns(eventId, agentId) (404 unknown_turn); outside any chain → return
      2. hop = turn.answering_hop_id; if this event opened a pending `consult` hop (source_event_id = eventId) → return (parent stays pending)
      3. hop set: UPDATE … SET status = answered|failed, answer_message_id = turn.reply_message_id, closed_at = now()
         WHERE id = hop AND status = 'pending' RETURNING *  — no row → return (replay, double done, timed out, cancelled)
         audit agent.consult.answered|failed; consultUpdated([question, answer?]);
         mode consult and chain active → deliverConsultReply(hop, outcome); mode handoff → nothing
      4. complete the chain (status active → completed) when it has no pending hop and either this turn is a root-agent
         turn (no answering hop) or the return delivery produced no event
