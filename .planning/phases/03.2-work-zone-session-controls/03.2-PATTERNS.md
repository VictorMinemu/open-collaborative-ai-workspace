## Shared Patterns

### Tenant + transaction
`core.db.withTenant(tenant(req), async (tx) => ...)` in every route; device-side handlers use `this.deps.db.withTenant(this.sys(device), ...)` (service.ts 313). Org id inside tx: `tenantOf(tx).organizationId`.

### Audit
`core.audit.record(tx, { action, resourceType, resourceId, sessionId, deviceId, metadata })` — routes.ts 466-472, device/routes.ts 236-242. Actions to add: `work_session.settings_changed` (incl. denied), `work_session.full_access_entered/left`, per-turn effective mode, `work_zone_policy.updated`, `device.grant_*`.

### Device commands
`hub.enqueue(tx, { deviceId, workSessionId, kind, payload })` inside the same tx (redelivery + idempotent ack handled; daemon dedups by `cmd.id`, daemon.ts 321-325).

### Realtime
`emitSession(tx, id)` for session changes; `core.realtime.appendEvent(tx, \`org:${orgId}\`, EventTypes.deviceUpdated, ...)` for devices.

### Errors
`badRequest(msg, code)`, `conflict(msg, code)`, `notFound(msg)` from `apps/api/src/lib/errors`; forbidden via `perms.assertCan` rejection.

### Fail closed on device
