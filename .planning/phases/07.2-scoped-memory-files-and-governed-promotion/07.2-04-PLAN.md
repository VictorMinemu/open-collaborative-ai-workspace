## Phase Goal

Platform-owned Markdown memory per scope with a file-tree viewer and governed promotion (plan map, cross-plan contracts
and executor rules in 07.2-01-PLAN.md).

**This plan's slice (tracer, detector level):** a secret pasted anywhere is recognised by one shared rule list, and the
device's `redact()` output stays byte-identical; then the PII detectors with checksums and masking.

<objective>
Move the secret patterns from the Local Runtime into contracts without changing `redact()`'s output, and build the
always-on detector layer 1 (secrets block; IBAN, cards, NIF/NIE, email, phone warn) as pure, browser-safe TypeScript.

Purpose: MEM-05; D-06 (layer 1), D-08 (`redact()` patterns moved to contracts keeping output identical; secrets
blocked on every write, applied by 08/09/11).
Output: `sensitive-data.ts` + tests; `sanitize.ts` delegating; parity test with a committed corpus.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| human/agent text → detector | Arbitrary, possibly adversarial input (ReDoS, evasion) |
| detector output → card, audit, logs | Findings travel to people who may not see the raw content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.2-04-01 | Information disclosure | Findings leaking raw PII/secrets | high | mitigate | Masked samples only; test asserts raw values absent from serialized findings (Task 2) |
| T-07.2-04-02 | Tampering | Moving patterns silently weakens device redaction | high | mitigate | Fixture captured before the move; byte-identical parity test (Task 1) |
