## Phase Goal

See `07.17-01-PLAN.md` (PD-07, PD-10, PD-11). **This plan's slice:** the cell can call the open tool on a run turn (also
after reading the MCP), and its local guard lets board moves on automation-opened cards reach the route while still
blocking card creation after outside content.

<objective>
Add the plugin tool `ocw_conversation_open` (turn-scoped, posting the turn's ids and the items, rendering the answer), put
it and `ocw_board_card` moves in the route-decides-taint set (board moves also after a session read), make the board tool
refuse `create` locally on such turns, and teach the fake Agent Channel API the route (D-02, D-05, D-06, D-12, PD-07,
PD-10, PD-11).

Purpose: the API decides; the plugin must not block what the API allows (the 07.16 Pitfall 7 pattern) nor allow what
it refuses.
Output: one new tool file with tests, guard and board tool changes with tests, registration, fake API handler.
</objective>
