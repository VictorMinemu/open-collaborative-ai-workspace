## Phase Goal

**As a** controller of a Work Zone session, **I want to** change the model, the thinking level and the permission mode — up to a real Full access where the device owner allows it — **so that** I can steer long coding work while my organization stays in control (ROADMAP Phase 03.2 goal; full user story in 03.2-01-PLAN.md).

**This plan's slice:** a device owner shares a device (e.g. a server hosting the harnesses) with chosen people or units, each capped at a mode, and can take it back.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (owner) → grant routes | The owner changes who may use their device |
| browser (grantee) → session routes | Listed people start sessions on someone else's device |
| API → device (`session.stop`, `session.configure` after revocation) | Access changes reach running sessions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.2-05-01 | Elevation of privilege | non-owner editing grants | high | mitigate | `device.update` (owner relation) on PUT/DELETE; admins read-only via `device.revoke`; 403 tests |
| T-03.2-05-02 | Elevation of privilege | Full access granted without the device opt-in | high | mitigate | 409 `device_opt_in` on grant and everyone-share; Plan 04 intersection still applies per turn |
| T-03.2-05-03 | Elevation of privilege | revoked grantee keeps running | high | mitigate | `onAccessChanged` stops creator sessions without access; per-turn author cap refuses their prompts (Plan 04) |
| T-03.2-05-04 | Spoofing | grant to a principal of another org / unknown unit | medium | mitigate | Principal validated through RLS-scoped tables; 400 `unknown_principal`; cross-tenant tests |
| T-03.2-05-05 | Information disclosure | grant list visible to everyone | low | mitigate | `grants` only for owner/admin; grantees see only their own `viewerMaxMode` |
| T-03.2-05-06 | Repudiation | sharing changes | medium | mitigate | `device.grant_added/updated/removed`, `device.updated` (shareMaxMode), downgrade and revocation audits |
| T-03.2-05-07 | Repudiation / cost | subscription use by others | low | accept | D-06 line states whose subscription is used; vendor terms are the owner's responsibility (ADR-0012 consequences) |
