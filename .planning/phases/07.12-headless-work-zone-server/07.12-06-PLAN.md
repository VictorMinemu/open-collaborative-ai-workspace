<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → public routes | Anyone can fetch the script and bundle |
| API → server shell | `curl … | sh` executes what the API answers |
| npm registry → server | The SDK tree comes from the server's registry |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.12-06-01 | Tampering | Host-header-driven script URL | high | mitigate | URL only from `OCW_PUBLIC_API_URL`, validated and single-quoted; Task 1 sends hostile Host and X-Forwarded-Host |
| T-07.12-06-02 | Tampering | bundle in transit / corrupt on disk | high | mitigate | Embedded sha256 verified with node before install; the API re-hashes before serving (503); http refused off loopback |
| T-07.12-06-03 | Tampering | partial script execution | medium | mitigate | Body in `main()`, last line calls it; Task 2 truncation case |
| T-07.12-06-04 | Elevation of privilege | installer asking for root | medium | mitigate | No elevation command in the script (Task 2 asserts), warns on uid 0, writes only under the user's home |
| T-07.12-06-05 | Tampering | npm install scripts of the SDK tree | medium | mitigate | `--ignore-scripts`, `--omit=optional`, exact pins (PD-04) |
| T-07.12-06-06 | Denial of service | download hammering (2-3 MB per request) | low | mitigate | 30/min per IP; the Buffer is cached once verified |
| T-07.12-06-07 | Information disclosure | build secrets in the image | low | mitigate | Only `/out` crosses into the runner; `.dockerignore` excludes `.env` and `.git` |
| T-07.12-06-SC | Tampering | npm installs on servers | medium | transfer | The server's own registry and npm; pins from the tested package.json; documented in SERVER.md and ADR-0033 |
</threat_model>
