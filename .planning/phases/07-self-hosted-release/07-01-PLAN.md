## Phase Goal

**As an** engineering team that wants to run the workspace on its own servers (Autofy's own engineers first), **I want
to** install, upgrade, back up, observe and expose an MVP 1 instance with one command each, **so that** we run it with
confidence that the MVP 1 acceptance scenario works on exactly that stack.

(ROADMAP Phase 7 goal restated as a user story, same intent: "Any engineering team can install, upgrade, back up,
observe and expose an MVP 1 instance with one command each, and the MVP 1 acceptance scenario runs against that exact
stack in CI". Informational, following the Phase 4–6 precedent.)

**This plan's slice (tracer, policy level):** one Semgrep rule wired through `pnpm guard` into `pnpm verify`, then the
remaining rules, the license checks and CODEOWNERS.
