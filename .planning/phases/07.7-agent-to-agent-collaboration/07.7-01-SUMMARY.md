# Phase 07.7 Plan 01: Agent-to-agent contracts Summary

**Zod contracts for the whole consult flow (strict tool request, `{ok, code?, sentence}` answers, origin-carrying
mention, `agent.consult_reply.v1`, `Message.consult`), the `agent.message` grain closed by default for agents with
per-target `agent:<uuid>` rules, the Bots module entry and the turn additions.**
