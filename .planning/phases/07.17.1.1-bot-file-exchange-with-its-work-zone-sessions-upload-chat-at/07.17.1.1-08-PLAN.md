## Phase Goal

See `07.17.1.1-01-PLAN.md` (PD-05, PD-17). **This plan's slice:** the write side of the byte transport: a device streams
one session file into a pending attachment of the bot's turn, bounded before a byte is read, at any size up to the
ceiling, without the API holding the file whole.

<objective>
Add `ObjectStorage.putStream` (S3 multipart), split `storeServerAttachment` into `recordServerAttachment` plus its
storage write and add `streamServerAttachment`, add `PUT /api/v1/runtime/files/:transferId` with every refusal that must
not consume the row checked before the claim, and the FakeDevice's PUT side (D-03, D-07, D-08).

Purpose: 04's daemon PUTs downloads here; 11 finishes a download from the row and attachment this route writes.
Output: the storage method, two artifact functions, one route, tests.
</objective>
