## Phase Goal

See `07.17.1.1.2-01-PLAN.md` (Cross-plan contracts › Plugin, PD-10, PD-16, PD-17, PD-26). **This plan's slice:** the
cell side of the phase against 01's mirror: the three tools, their gate rules, the bridge's quiet and done behaviour,
the turn's task block, the proactive paragraph, and the real-cell smoke.

<objective>
Add the three task tools to the OpenClaw plugin (names, client calls, registration, gate sets, cap exemption, once per
turn), make the bridge accept quiet and silent task turns and report done for them, map `agent.task.v1` and render the
"Your task" block, append the proactive paragraph to `buildPersonaPrompt`, and prove it in the real cell (D-02, D-06,
D-13, D-14).

Purpose: without these, the API's continuations would never be scheduled (no tool) or would be re-dispatched as
failures (the bridge), and the model would keep asking "¿continúo?".
Output: one tool module, gate and bridge changes, mapper additions, one smoke scenario with two fixtures.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → plugin tool | The model's arguments are untrusted |
| plugin → API | Ids and notes only; the API decides |
| API → model | `turn.task` notes are the bot's own earlier text: data, not instructions |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.17.1.1.2-05-01 | Spoofing | a model naming a user, conversation or budget | high | mitigate | Closed input schemas; the plugin adds only the turn's ids (P6) |
