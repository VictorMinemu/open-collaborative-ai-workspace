| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.1-11-01 | Elevation of privilege | members reaching column settings | medium | mitigate | UI hides them without `channel.update`; the API refuses (07.1-06); member e2e case |

| T-07.1-11-03 | Tampering | XSS through column names or card text | high | mitigate | React text nodes; descriptions only through `<Markdown>` in the thread |
| T-07.1-11-04 | Tampering | data loss on column or card delete | medium | mitigate | Move target required when the column holds cards; last column protected; confirmation dialogs focusing Cancel |
| T-07.1-11-05 | Tampering | lost edits | low | mitigate | `expectedVersion` with a visible conflict and Reload card |
</threat_model>
