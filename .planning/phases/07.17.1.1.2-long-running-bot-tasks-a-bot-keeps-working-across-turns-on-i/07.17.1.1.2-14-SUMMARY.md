## Decisions Made

- **The rest of the release page.** The release workflow publishes `docs/releases/<tag>.md` as the release body
  (`--notes-file`), and the file only had the intro and the two phase sections. So this plan added Fixes, Upgrade,
  "Install the server", "Desktop app", Files and "Known limitations", in v0.3.1's shape, outside both phase markers. The
  sibling's section is byte-identical. The intro gained one sentence.
- **Helper bodies in the rule.** The rule covers the bodies of the `auditTask` and `auditTaskRefused` helpers too:
  they record from an `action` variable, and the literal-action patterns cannot see that.
- **No regex prefilter.** It was dropped: it moved the finding line of a multi-line record onto the `action` line. The
  SQL fixture still passes without it.
