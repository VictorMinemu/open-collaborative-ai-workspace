one `SessionBrowserTools` object. The fake runtime drives it from prompt lines, so the e2e journey (22) uses the real
browser. `daemon.ts` is edited here only: later device plans work behind the manager.

Purpose: one place enforces the browser rules for both runtimes (principle 5: the adapters only expose the tools).
Output: tool table, manager, approvals broker, shim token, daemon wiring, fake driver, tests.
