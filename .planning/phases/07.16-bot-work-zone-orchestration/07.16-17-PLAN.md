## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device → API (persisted) | Session events and changes already contained and redacted on the device |
| API → cell | The read answer carries the runtime's work product (untrusted) to the model |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.16-17-01 | Information disclosure | absolute paths or secrets in output | high | mitigate | `onlyRelativePaths` and `redactSecrets` server-side on top of the device's `contain()`/`redact()`; tests with raw paths and a key fixture |
| T-07.16-17-02 | Information disclosure | people's prompts reaching the bot (and its wider audience) | medium | mitigate | Only counts and the bot's own prompts are returned |
| T-07.16-17-03 | Tampering | injected text in output steering other tools | high | mitigate | `session_output_read` set on read; the claim refuses other side effects (15); the plugin mirrors it (08) |
| T-07.16-17-04 | Elevation of privilege | reading another session | high | mitigate | Ownership check; organization-B and other-bot cases |
| T-07.16-17-05 | Denial of service | huge answers | low | mitigate | Contract bounds and `readOutputChars`; the turn's tool cap |
</threat_model>
