## Phase Goal

Any engineering team can install, upgrade, back up, observe and expose an MVP 1 instance with one command each, and
the MVP 1 acceptance scenario runs against that exact stack (user story and plan map: 07-01-PLAN.md).

**This plan's slice (tracer, back up):** a gate stack's database and objects go out with `ocw backup` and come back
with `ocw restore` after the data changed; then the cell state, refusal rules, fresh-volume restore, the
`--force-recreate` check and the runbook. Executor rules (D-11, D-12) as in 07-01: restore is destructive and only
ever runs on a gate project.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stack → backup directory on the host | Full data incl. sealed secrets leaves the containers |
| backup directory → restore | A backup may be tampered with or come from another release |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-09-01 | Information disclosure | backup files readable by other users or committed | high | mitigate | 0600/0700, `backups/` ignored by git and docker (07-03, 07-04); `.env`/`secrets/` never copied; documented as sensitive (Tasks 1, 2) |
| T-07-09-02 | Tampering | modified or truncated backup restored | high | mitigate | sha256 per file in the manifest, verified before any change; `--single-transaction` (Tasks 1, 2) |
| T-07-09-03 | Tampering | newer backup restored onto an older release | medium | mitigate | Refused by migration names; schema guard (07-02) as a second line (Task 2) |
| T-07-09-04 | Denial of service | accidental restore over live data | high | mitigate | `--yes` required; executor rule: gate projects only (Task 2) |
| T-07-09-05 | Elevation of privilege | restore breaking RLS or roles | high | mitigate | Restore as `ocw_migrator`, `migrate` re-applies grants/policies; tenant check after restore (Task 1) |
| T-07-09-06 | Information disclosure | DB password on a command line | medium | mitigate | Passed through the container environment only (Task 1) |
</threat_model>
