## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → sandboxd | Token-authenticated internal HTTP; the broker is root-equivalent through the socket |
| sandbox → host | The container boundary (gVisor or hardened runc) |
| bot A sandbox → bot B sandbox | Separate networks and volumes |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
