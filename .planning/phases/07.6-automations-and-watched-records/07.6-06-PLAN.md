## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| platform → cell | A run event asks a bot to act for a person who is not present |
| outside sender → turn | Webhook and mail text reaches a model |
| cell → chat | The cell's replies to anchors land in shared conversations |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.6-06-01 | Elevation of privilege | prompt injection in inbound content causing actions | critical | mitigate | Taint at birth, propagation to inbound-rooted threads, separate `inbound` block; side-effecting calls refused (Task 2) |
| T-07.6-06-02 | Elevation of privilege | confused deputy: bot posting for a person who lost access | high | mitigate | Anchor → run-as human → existing agent ∩ human read check; deleted automation → 409 (Task 2) |
| T-07.6-06-03 | Spoofing | agent posting without any trigger | high | mitigate | D-08 rule untouched; only the run anchor is added as a trigger (Tasks 1, 2) |
| T-07.6-06-04 | Tampering | bot rewriting run or inbound cards | medium | mitigate | Platform-owned cards; agent PATCH 403; server-only `updatePlatformCard` (Task 3) |
| T-07.6-06-05 | Denial of service | duplicate deliveries on retries | medium | mitigate | Conditional `queued → delivered` update in the append transaction (Task 1) |
| T-07.6-06-06 | Elevation of privilege | an unattended run driving a browser (member sign-ins, live control) or exceeding the sandbox budget | high | mitigate | `unattended: true` drops the browser family from run turns; sandbox keeps 07.8's decision, kill switch, taint flags and 40-call cap; forged browser call → `policy_changed`, 41st call → `budget_exhausted` (Task 2, D-12) |
