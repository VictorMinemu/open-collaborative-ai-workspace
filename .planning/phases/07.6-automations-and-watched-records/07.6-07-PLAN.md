<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ERP (MCP) → API | External record data is untrusted and may be malformed or huge |
| member's connector → shared board | Data read with one person's credentials is shown to many |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.6-07-01 | Information disclosure | member-account values posted in a shared board | high | mitigate | `activeShare` required for per-member connectors at link, preview and every check (Task 3) |
| T-07.6-07-02 | Tampering | model deciding staleness or supplying hashes | high | mitigate | API-computed canonical hash; no model in checks (Tasks 1, 2) |
| T-07.6-07-03 | Server-side request forgery | MCP calls to internal hosts | high | mitigate | Only 07.4's `callTool` through the egress guard (Task 1) |
| T-07.6-07-04 | Denial of service | check storms from busy threads | medium | mitigate | singleton 60 s per record, 429 on the manual route, interval ≥ 15 min (Task 3) |
| T-07.6-07-05 | Information disclosure | record values in audit or jobs | medium | mitigate | audits carry ids and counts; jobs ids + source only (Tasks 1, 3) |
</threat_model>
