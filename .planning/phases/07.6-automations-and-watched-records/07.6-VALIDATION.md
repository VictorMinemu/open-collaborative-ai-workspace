## Sampling Rate

- **After every task commit:** the task's quick unit / integration / web command (per task below).
- **After every plan:** `pnpm verify` (+ `pnpm typecheck --force` after a contract change); UI plans also run their isolated e2e spec on both projects.
- **After every wave:** `pnpm verify` on the merged wave.
- **Phase gate (07.6-19):** full suite + every 07.6 spec and the regressions on one fresh isolated stack + real-cell smoke + `pnpm gate:compose` + Woodpecker CI; screenshots reviewed against the UI-SPEC.
- **Max feedback latency:** one task's quick command (< 120 s unit/web, < 300 s one integration file; GreenMail files < 400 s).
