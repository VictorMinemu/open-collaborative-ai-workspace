## Phase Goal

See `07.14-01-PLAN.md`. **This plan's slice (the phase's API end-to-end tracer):** the organization's connected account is
used by every member's bots wherever organization tools are offered, through the API connector proxy, with the token
never in the cell — the "bots call its tools with that account" half of COA-01.

<objective>
Make the connector proxy (`agent-channel/connectors.ts`) choose the credential from the server's mode, with the
organization's messages, audit and last-used stamp; split the turn policy's member-account predicate into `proxiedSource`
(logical names, `ocw_connector_call` / `ocw_connector_list`, cell-wide skip) and `memberAccountSource` (the audience rule).

Purpose: without the split an org-mode tool would either never be offered in a channel (member audience rule) or be
offered to the cell under a name it does not have.
Output: the proxy and turn-policy changes, a new org proxy suite, extended turn cases.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → Agent Channel API | Cell requests are authenticated but their body fields are untrusted |
| API → MCP server | The organization's token is sent upstream through the guard |
| conversation readers | Results of an organization account reach everyone allowed in the conversation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.14-08-01 | Elevation of privilege | choosing the credential from a body field | high | mitigate | Principal from the server's stored mode and the ledger's turn human only (`credentialKeyOf`); no body field read |
| T-07.14-08-02 | Information disclosure | organization token reaching the cell | high | mitigate | Proxy-only; logical names; cell snapshot assertion (Task 1) |
| T-07.14-08-03 | Information disclosure | organization-account results read by people the admin did not intend | medium | mitigate | Org-resource checks (`shared_with_group`, `not_every_participant`) and per-tool approvals apply; documented in ADR-0036 and the mode hint |
| T-07.14-08-04 | Tampering | a tainted turn writing with the organization's account | medium | mitigate | Existing taint and `approvalForCall` before any token, unchanged (Task 2 approval case) |
| T-07.14-08-05 | Spoofing | member credential used for an org server (fallback) | high | mitigate | Org keys never touch `connector_connections`; asserted row count 0 |
