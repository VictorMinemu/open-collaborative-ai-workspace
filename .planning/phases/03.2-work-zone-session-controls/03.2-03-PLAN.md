## Phase Goal

**As a** controller of a Work Zone session, **I want to** change the model, the thinking level and the permission mode and reach every option Claude Code and Codex expose, **so that** I can steer long coding work without restarting sessions while my organization stays in control (ROADMAP Phase 03.2 goal; full user story in 03.2-01-PLAN.md).

**This plan's slice:** the Codex adapter applies settings as per-turn overrides, fixes Supervised, reports effective values and publishes its `model/list` catalog — proven with fixtures recorded at codex-cli 0.160.0.

<objective>
Make the Codex adapter a full participant in the session settings protocol of Plan 01: catalog from `model/list`, per-turn stable overrides for every exposed control, a mode mapping table that makes Supervised really ask, effective-state readback, the per-turn cap and the slash-command backstop.

Purpose: D-07, D-08, D-09, D-10, D-11, D-12, D-13, D-14; WZC-01/02/03 on Codex; WZC-06 inventory rows for Codex.
Output: regenerated protocol types, `codex/catalog.ts`, `codex/mode-policy.ts`, `CodexRuntime.configure()` / `catalog()`, mapper for `thread/settings/updated` and token usage, two fixtures at 0.160.0, updated Codex inventory rows.
</objective>
