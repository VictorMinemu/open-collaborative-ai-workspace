The Work Zone browser opens large when you take control, so the page you sign in on is readable.

## What's new

- **A large view for the session's browser.** The Browser tab has an **Expand** button that opens the live page in a
  large window, fitted to your screen. **Take control** opens it by itself on a computer, and **Done** or **Done, save
  my sign-in** bring the page back to the panel. Phones keep the full-screen sheet.

## What's fixed

- **Taking control no longer slips away.** Right after you took control of a Work Zone browser, a refresh that had
  started just before could hand control back, and what you typed was dropped. You now keep control until you are done.
- **Everyone else sees who took control at once.** Their "Private sign-in in progress" notice now names the person
  in control from the first moment, not a second later.

## Upgrade

In `/opt/ocw` (or wherever the server is installed):

```bash
sudo node scripts/ocw.mjs upgrade --check   # current and newest release; changes nothing
sudo node scripts/ocw.mjs upgrade           # backup, this release, new keys, rebuild; never goes backwards
```

- **No migration.** The changes are in the web app and the API server (`ocw upgrade` covers both); devices need nothing new.
- Headless Work Zone servers may update their runtime to 0.5.1 with one click (Settings › Devices › the server ›
  Runtime updates › **Update**); it carries no change of its own.

The desktop app does not update itself yet: install the new files below if you want them. Its runtime ships inside it.
