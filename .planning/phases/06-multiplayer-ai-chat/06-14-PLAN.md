## Phase Goal

**As a** member who holds a private AI chat, **I want to** share it in place with a colleague, a team, a department or the whole organization so that several of us and the model write in the same conversation — the model knowing who said what and answering one request at a time on the asker's own plan or model, nobody's private context leaking, and agents joining as full personas that post live cards — **so that** AI work in the workspace becomes multiplayer, attributable and safe.

**This plan's slice:** the persona side of Agent Cards — the `ocw_agent_card` tool in the cell plugin and the decision coming back as a turn — so agents really post cards, not only tests. P-decisions: `06-01-PLAN.md` (P-11, P-12).

<objective>
Give personas a gated `ocw_agent_card` tool (create or update a card in the active conversation) and route `agent.card_action.v1` into the persona as an inbound turn.

Purpose: AGENT-04 (D-07; P-11).
Output: builtin tool in contracts and turn policy, plugin tool + client methods + manifest, card-action mapping and dispatch, tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output → `ocw_agent_card` params | Untrusted; the tool binds ids from the trusted turn context |
| cell → Agent Channel API | The only path for cards (principle 9) |
| API → cell (`agent.card_action.v1`) | Server-generated decision events |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-14-01 | Elevation of privilege | model steering the tool to another conversation or agent | high | mitigate | Ids from the trusted tool context only; API re-checks `channel.post` and membership; tests (Task 1) |
| T-06-14-02 | Spoofing | phishing Open target from model output | high | mitigate | Local refusal + API `AgentCardRoute` validation (06-13) |
| T-06-14-03 | Tampering | tool used outside a gated turn | medium | mitigate | Builtin offered through `turnPolicy`; gate refuses calls on turns that do not list it (Task 1) |
| T-06-14-04 | Information disclosure | API bodies or tokens in tool answers/logs | low | mitigate | Fixed answer texts; logs with ids/codes only (memory-tool pattern) |
</threat_model>
