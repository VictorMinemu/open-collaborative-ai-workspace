## Phase Goal

See `07.15-01-PLAN.md`. **This plan's slice:** delivery. The API decides, per bot and per asker, which files the turn
reads and how this bot can read each (D-02, D-04), and offers the read tool only on such turns (PD-03), all in the
message's transaction before the `agent_turns` row is written.

<objective>
Fetch the attachment rows of the current message and the history window in `buildMentionEvents`, pass them in listing
order to `turnPolicy`, build `turn.attachments` with `buildTurnAttachments` (access and notes per bot), offer
`ocw_attachment_read` when a file is readable, and prove it for DMs, channels, threads, the window, AI chat personas
and text-only models (D-02, D-04, D-09, D-13, D-14, PD-03, PD-04).

Purpose: the turn is what tells the bot that files exist and what it may do with them.
Output: the delivery change, the builder with unit tests, the integration proofs.
</objective>
