## Phase Goal

See `07.8-01-PLAN.md`. **This plan's slice (tracer, broker level):** an approved npm package and its whole pinned tree
install into a bot's sandbox and run there through exec — then PyPI, Debian, ClawHub, removal, and the refusal of a
dependency republished after approval.

<objective>
Implement package review with full dependency-tree resolution, install from the recorded set only, and removal in
`sandboxd`, with throwaway review and installer containers, the per-bot read-only packages volume, and an offline smoke
against fake registries.

Purpose: SBX-04 (refused capabilities installable as sandbox-confined packages whose whole tree is pinned); D-03 as
refined by D-11 (F-3).

</objective>
