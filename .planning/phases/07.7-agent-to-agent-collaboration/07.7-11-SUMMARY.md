## Deviations from Plan

### Auto-fixed issues (found by the gate, fixed at their source)

**1. [Rule 1 - Bug, 07.7-10 re-opened] The Stop toast was sometimes lost**
- **Found during:** Task 2, isolated e2e (desktop `agent-consult` Stop).
- **Issue:** the server's `message.updated` can turn the chip Stopped before the cancel request answers. That
  unmounts the Stop button, and TanStack Query drops callbacks passed to `mutate()` once their observer unmounts, so
  the "Stopped. @archie won't get more answers…" toast never showed. Mobile passed by timing.
- **Fix:** `cancelChainMutation(source, notify?, fn?)` puts the CR-C-05 toasts in the mutation's own options, which
  fire without an observer. `useCancelAgentChain(source)` uses it. A web test builds the mutation with no observer and
  pins each toast (it was RED first: 2 failing).
- **Files:** `apps/web/lib/consult-queries.ts`, `apps/web/components/chat/consult-chip.tsx` (+ test).
- **Verification:** web 1225/1225; the 07.7 specs green on both projects; Stop repeated 3× on both projects.
- **Commit:** `1529b37c`

**2. [Rule 1 - Test bug] The consult smoke still expected the pre-CR-C-07 key**
- CR-C-07 changed the plugin's key to `<eventId>:consult:<sha256(target, normalised question)[:16]>`, but the smoke
  still checked for `:consult:0`. The review fixer had only syntax-checked the script. The scenario now computes the
  expected key (`10955bfd6cfa17af`, matching the real cell). The other edited expectations held on the real cell:
  "Hi Víctor Ruiz!", the answer's canary only inside the untrusted `consult_answer` block, and the failed-hop taint
  case blocked. **Commit:** `cfff3dc2`

**3. [Rule 1 - Test bug] The fixed automation config check met OpenClaw's own `main` entry**
- Once the check read `agents.entries` (the leftover fix), the real config showed OpenClaw's built-in `main` entry
  next to the plugin's bot. That entry has no tool list, and the cell-wide deny the same check asserts covers it. The
  per-bot deny check now reads the `ocw-*` entries, no entry may offer cron or session tools, and a failure prints every
  entry's lists. **Commit:** `9f5937e2`
