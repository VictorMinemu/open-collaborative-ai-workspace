## Phase Goal

See `07.17-01-PLAN.md` (PD-19). **This plan's slice:** the owner turns fan-out on, sets its caps, names the team to mention,
and sees how many conversations each run opened, all in the existing automation editor.

extend the daily-limit callout with fan-out, and show `fanOutLabel` in run history (D-02, D-08, D-10, D-11, D-16, PD-19).

Purpose: success criteria 1 and 3 configured through the UI.
Output: two new components, editor, run history and query changes, one web test file.
</objective>
