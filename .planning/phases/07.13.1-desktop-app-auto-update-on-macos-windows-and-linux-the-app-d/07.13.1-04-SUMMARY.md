# Phase 07.13.1 Plan 04: macOS AdhocMacUpdater, verified staging and the detached swap helper Summary

macOS now has its own updater: `AdhocMacUpdater extends BaseUpdater` downloads the release's `.zip` through
electron-updater (cache + sha512 from `latest-mac.yml`), `prepareDownloaded` extracts it with `ditto` into
`.ocw-update-<version>/` beside the installed `OCW.app` and keeps it only if `codesign --verify --deep --strict`, the
bundle id, the version, the daemon and the framework symlinks check out, and `doInstall` starts a detached helper
(Electron as Node, argv only) that swaps the bundle by two renames with rollback after the app and its daemon exit,
writes a path-free `update-result.json` and relaunches with `open`.

## What exists now (interface for plans 03, 05, 07)

- `createAdhocMacUpdater({ exePath, userData, helperSource, daemonPid, installedAppOverride?, isWritable?, run?, spawn? })`
  → `{ ok: true; updater: AdhocMacUpdater } | { ok: false; reason: "dmg" | "translocated" | "unwritable" | "not_bundle" }`.
  The override is checked like the real exe (it must be an `OCW.app` in a writable folder, not under `/Volumes/` or
  `/AppTranslocation/`).
- `AdhocMacUpdater#prepareDownloaded({ version, downloadedFile }): Promise<void>`: once per version (a concurrent
  call for the same version shares the promise; a newer version removes the older staging folder first). Rejects with
  `MacUpdateError` (`bad_version`, `extract_failed`, `no_app`, `seal_invalid`, `wrong_bundle`, `wrong_version`,
  `no_daemon`, `symlinks_lost`, `helper_failed`); afterwards nothing is prepared and no staging folder is left.
- `AdhocMacUpdater#installedApp` (read-only) is the bundle being replaced.
- `doInstall` (via electron-updater's `install` / `quitAndInstall`) spawns `process.execPath` with
  `[<staging>/swap-helper.cjs, String(process.pid), daemonPid|"0", installedApp, stagedApp, <userData>/update-result.json,
  version, isForceRunAfter ? "1" : "0"]`, `{ detached: true, stdio: "ignore", env: { ELECTRON_RUN_AS_NODE: "1" } }`, and
  unrefs it; returns false when nothing is prepared. A spawn failure throws `install_failed` (BaseUpdater dispatches it
  as the `error` event).
- `readSwapResult(userData)` → `SwapResult | null` (`{ outcome: "installed" | "failed", version, reason?:
  "app_still_running" | "swap_failed" | "rollback_failed", at }`, strict), the file deleted valid or not.
- `sweepLeftovers(parentDir)` removes only `.OCW.app.old-<digits>` and `.ocw-update-<x.y.z>` (symlinks unlinked, never
  followed).
- Helper: `dist/main/mac-swap-helper.cjs` (no `require("electron")`; ~760 KB because zod is bundled). Exit 0 installed,
  1 failed, 2 refused argv. Bounds: app 60 s, daemon 30 s, 200-ms polls. `daemonPid` `0` skips the daemon wait;
  `isProcessAlive` never signals a pid ≤ 0 (EPERM counts as alive).
- `e2e/support/mac-dummy-app.ts`: `buildDummyMacApp({ dir, version, bundleId?, tamperAfterSign? })` → `<dir>/OCW.app`
  (Info.plist, `MacOS/OCW` from `/usr/bin/true`, `Resources/daemon/bin/ocw-runtime`, symlink `Resources/current` →
  `daemon`, `codesign --force --deep -s -`); `zipDummyMacApp(app, zip)` (`ditto -c -k --keepParent`). Both throw off
  macOS.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical functionality] Framework symlink check got its own code**
- **Found during:** Task 1
- **Issue:** the plan requires "symlinks survived" but lists no code for it.
- **Fix:** `symlinks_lost` when any `Contents/Frameworks/*.framework/Versions/Current` is not a symlink (unit-tested);
  codesign catches most of these too, this names the cause.
- **Commit:** 0a97a364

**2. [Rule 2] Extra fixed codes `no_app`, `helper_failed`, `install_failed`, `no_zip`**
- **Found during:** Tasks 1 and 3
- **Issue:** a zip without `OCW.app` at its root, a missing helper source and a failed spawn needed fixed, path-free
  errors.
- **Fix:** added to `MacUpdateError`'s fixed set.
- **Commits:** 0a97a364, 9c07e864

**3. [Rule 3 - Blocking] Shared constants moved to mac-swap.ts**
- **Found during:** Task 2
- **Issue:** `STABLE_VERSION` and the staging folder name were in mac-update.ts; the helper bundle must not import it
  (it pulls electron-updater).
- **Fix:** mac-swap.ts owns `STABLE_VERSION`, `APP_NAME`, `RESULT_FILE`, `stagingDirName`; mac-update.ts imports them.
- **Commit:** 0c4216ab

No other deviation; no file outside `files_modified` was changed.
