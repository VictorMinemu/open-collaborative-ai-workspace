## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| person → bot files | Only the bot's configurers may see or change its workspace |
| admin → organization policy | Egress and limits are security settings |
| sandboxd events → API state | Events are trusted plumbing on an internal network, still validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.8-11-01 | Information disclosure | files of a bot the person cannot configure | high | mitigate | Resolver precondition, 404-hiding, ids in `withTenant`, org-B cases (Task 1) |
| T-07.8-11-02 | Tampering | malicious file served as active content | medium | mitigate | Attachment disposition, `nosniff`, previews as JSON text, SVG/HTML never rendered (Tasks 1–2) |
| T-07.8-11-03 | Elevation of privilege | egress allowlist injection | medium | mitigate | Host-only validation, ≤ 64, named constraint backstop (Task 3) |
| T-07.8-11-04 | Tampering | lost updates on settings | low | mitigate | Expected version, 409 with current (Task 3) |
| T-07.8-11-05 | Denial of service | double-counted usage or repeated audits after an API or broker restart | low | mitigate | Durable per-organization `sandbox_event_cursor` advanced in the applying transaction; replay test (Task 3) |
</threat_model>
