## Phase Goal

See `07.12-01-PLAN.md`. **This plan's slice:** the phase's end-to-end tracer (PD-02): everything an owner does to turn a
machine into a shared Work Zone server, from `curl … | sh` to a member's session, on the real stack.

<objective>
A helper that installs the bundled runtime from the isolated API into a scratch home, runs `setup --yes --service
none`, hands the printed link to the spec for approval in the web, then starts the installed daemon; and a spec that
approves it in the UI, shares it with Sam and a team project, has Sam run sessions, and checks the doctor's JSON.

Purpose: HSR-06 (and the served, scripted path of HSR-01/02/03/05) proven on the real API, web and bundle.
Output: `headless-server.ts` (+ unit test of its parser), `fake-npm.mjs`, `work-zone-headless-server.spec.ts`.
</objective>
