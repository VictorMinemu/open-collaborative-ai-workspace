- load the session (org-scoped), its device (owner, shared, revoked), its repo link (`work_project_repos.project_id =
  work_sessions.project_id`);
- `access` := team project: `app.work_project_access(unit, user)` (`lead`/`member` = direct membership on the project;
  `team` = an assigned `team_unit_id` on the path of one of the user's memberships, i.e. `team_unit_id = ANY(ou.path)`;

  membership path, minus an explicitly revoked user grant, exactly as `deviceModeCap(...) !== null`);
- `viewer` when `access` is not null and: `project`; or `teams` with an active unit grant still assigned to the project
  whose unit is on one of the user's membership paths; or `people` with an active user grant for the user (`owner` adds
  nobody);
- `creator` when `created_by = user` and (personal, or team with `access` not null); `creator_left` when `created_by =
  user` and it is a team project without access (D-12);
- `device_owner` when `devices.owner_user_id = user` (D-11); `admin` from `org_members`; `project_lead` when the user is
  a lead member of the project unit.
