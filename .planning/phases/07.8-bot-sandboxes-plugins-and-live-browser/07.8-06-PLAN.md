## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → plugin tool | Parameters are model-written and untrusted |
| plugin → Agent Channel API | Credential-free calls with the turn's ids |
| OpenClaw core → host | Core exec, file and browser tools must stay unreachable |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.8-06-01 | Elevation of privilege | OpenClaw sandbox or core exec turned on | high | mitigate | `sandbox.mode: "off"` pinned with a test; DANGEROUS_TOOLS unchanged; smoke asserts "not offered" (Tasks 1, 3) |
