## Phase Goal

Agents keep their memory as Markdown files in folders the platform owns (personal, agent, project, team and
organization scopes) that people browse, read and edit in a file-tree viewer with history, while anything an agent
wants to put into a shared scope goes through a detector and a human approval that the server applies (ROADMAP
Phase 07.2). Owner requirement: a first-class viewer of folders, subfolders and `.md` files where bots keep their memory.

**This plan's slice (tracer, contract level):** one memory path and one memory grain round-trip through the contracts
(parser → DTO → permission tables → module catalog), then the approval, card, turn, channel and realtime contracts every
later plan builds on.
