# Phase 07.8: Bot sandboxes, plugins and live browser: Verification Report

**Phase Goal:** Each bot works in its own isolated sandbox where it can write files, run commands and use plugins that today are refused. It can also drive a real browser that people watch live in a small floating window and take over to sign in themselves, so the bot never sees a password. The Control Plane still decides, audits and can stop everything.
