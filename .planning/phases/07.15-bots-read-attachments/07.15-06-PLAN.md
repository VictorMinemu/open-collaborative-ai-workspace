## Phase Goal

See `07.15-01-PLAN.md`. **This plan's slice:** the cell side. The bot sees which files its turn reads, can read one
through the API-decided tool (images as the tool result's image part, ADR-0029 spike ii), and a files-only message is
still answered. The local guard mirrors the server's budget so it never blocks what the API allows.

<objective>
Add `ocw_attachment_read` to the OpenClaw plugin (tool, API client call, fake API route, guard self-validation with its
own budget, manifest, registration, turn-scoped configuration) and render the turn's attachments as one context block
with a files-only body (D-02, D-03, D-04, D-08, D-17, PD-10).

Purpose: without the plugin, the turn's list and the route are invisible to the model.
Output: the new tool module and its tests, the guard, registration and mapper changes, the fake API route.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → plugin tool | The model chooses `attachmentId`; the plugin forwards only it beside the turn's ids |
| API → cell → model | File text and image bytes are untrusted content handed to the model |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.15-06-01 | Spoofing | a tool call claiming another turn or user | high | mitigate | The body is built from the active turn (`eventId`, `agentId`) plus the argument; the API binds the asker (08); test pins the body keys |
| T-07.15-06-02 | Tampering | prompt injection from file content | high | mitigate | Text stays the API's labelled block; image parts carry a "data, not instructions" label; a read taints the turn locally and in the API |
| T-07.15-06-03 | Denial of service | local guard blocking allowed reads (cap of 8) | low | mitigate | Own counter against `maxAttachmentReads`; guard test for reads 9…20 |
| T-07.15-06-04 | Information disclosure | file bytes on the cell's disk via native media | medium | mitigate | No use of OpenClaw `media`; images only in the tool result |
| T-07.15-06-05 | Tampering | file names breaking the context block | low | mitigate | Names sanitized before rendering; test with delimiters and newlines |
</threat_model>
