## Objective

Per D-15, D-20, D-22, PD-12, PD-14 (hub `07.13-01-PLAN.md`). The device side of the live view and of taking control:
it streams the page only while the API says someone watches, it pauses the agent while a person holds the lease, it
applies that person's input exactly as the bots' agent does, and it closes the page when a takeover is abandoned.

Purpose: WZB-05 frames and WZB-08 takeover on the device. Output: frame streaming, takeover state, agent ops for
frames/input/focus, the link's binary send, tests.
