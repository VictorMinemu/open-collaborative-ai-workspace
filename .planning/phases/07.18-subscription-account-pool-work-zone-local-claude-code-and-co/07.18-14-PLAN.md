## Phase Goal

See 07.18-01 (the hub). **This plan's slice:** bots draw from the pool. The cell receives the pool (Claude tokens over the
authenticated cell route, ChatGPT profiles and the order), each ChatGPT account for bots is signed in inside the cell as
its own profile, the existing sign-in becomes the first pool account, and every pool change reaches the cell.
