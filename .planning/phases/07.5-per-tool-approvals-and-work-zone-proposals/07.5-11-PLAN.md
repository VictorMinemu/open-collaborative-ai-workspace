## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → three agent-action routes | Tool name and arguments are model output; the cell token is the only credential |
| route → outbound call | Connector and HTTP proxies act with a member's credential |
| decision → re-run turn | The re-run carries tools and credentials |
