## Phase Goal

Admins and leads turn whole modules on or off for a department, team or person from Settings, as resolver deny rules,
so the UI hides what the API already refuses.

**This plan's slice (tracer, browser level):** the hiding. A member's AI chats are turned off by an ordinary catalog
rule (created through the existing rules API, since the module-access API lands in parallel in 07.3-02); their open
chat sidebar loses the AI chats section live, and a deep link shows the off state. Then Work Zone and Bots entries,
then the 1440/390 light/dark review. Settings entries (account "AI chat", Settings › Modules) are 07.3-04. Planner
decisions P-01 … P-12 are in `07.3-01-PLAN.md` (P-08 for this plan).

**UI contract (no UI-SPEC for this phase; this is the layout):**
- `ModuleOff` uses the existing `EmptyState` (`components/common/empty-state.tsx`) inside a `flex min-w-0 flex-1 flex-col`
  container so it fills the section's content column (the section sidebar stays). Icon = the module's rail icon
  (`SquareTerminal`, `Sparkles`, `Bot`). Title: "Work Zone is turned off for you" / "AI chats are turned off for you" /
  "Bots are turned off for you". Description: "An admin or your team lead turned this off. Ask them if you need it."
  plus, for Work Zone, " Your devices stay in Settings › Devices." and, for AI chats, " Your chats are kept and come back
  when it is turned on again." One action: "Go to Chat" (`/chat`, outline button). `data-testid="module-off"` with
  `data-module="<id>"`.
- Loading: a skeleton shaped like the section's content (title bar + three rows), never the off state.
- Nothing else moves: hidden entries leave no gap, divider or empty heading (e.g. the views row keeps its spacing).

    // apps/web/lib/modules.ts (pure, no React)
    export type ModuleStatus = "loading" | "on" | "off";
    export function moduleStatus(perms: { permissions: readonly Permission[] } | undefined, failed: boolean, id: ModuleId): ModuleStatus;
      // failed → "on" (the API stays the authority; a failed cosmetic check never blocks a page); undefined → "loading"
    export function withoutBotDms<T extends { counterpart: { kind: string } }>(dms: readonly T[], showBots: boolean): T[];
      // drops 1:1 bot DMs (counterpart.kind === "agent") when showBots is false; groups and people stay
      // callers pass showBots = useModule("bots") !== "off" (never can("bot.read"), which is false while loading or failed)

    // apps/web/components/shell/module-gate.tsx ("use client")
    export function useModule(id: ModuleId): ModuleStatus;
    export function ModuleGate(props: { module: ModuleId; children: ReactNode }): JSX.Element;   // loading skeleton | ModuleOff | children
    export function ModuleOff(props: { module: ModuleId; className?: string }): JSX.Element;
