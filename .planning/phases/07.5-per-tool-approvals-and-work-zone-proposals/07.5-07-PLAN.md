## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → approvalForCall | Tool name and arguments are model output |
| decider's browser → decision | The decider may be stale, removed or the requester |
| card → conversation readers | Card fields reach every reader through `message.updated` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.5-07-01 | Tampering | arguments changed after approval | critical | mitigate | Hash over canonical arguments recomputed from the stored row and the re-run turn; changed values → new request (Tasks 1, 3) |
| T-07.5-07-02 | Elevation of privilege | a grant replayed by another member, bot or conversation | high | mitigate | Hash binds agent, requester, conversation; one-use consumption; 15-minute window (Tasks 1, 3) |
| T-07.5-07-03 | Elevation of privilege | self-approval or stale approvers | high | mitigate | Live `canDecide`, four-eyes when approvers are not the requester, demoted admin test (Task 2) |
| T-07.5-07-04 | Information disclosure | exact values in a channel card | high | mitigate | Audience rule; summary card and stream-event sentinel test (Task 2) |
| T-07.5-07-05 | Spoofing | hidden characters or secrets in displayed values | medium | mitigate | `revealInvisible` and display masking; notices (Task 2) |
| T-07.5-07-06 | Denial of service | approval floods and races | medium | mitigate | Advisory lock, dedupe, denied-24 h suppression, cap 5, idempotent retries (Task 3) |
| T-07.5-07-07 | Information disclosure | arguments in audit rows | medium | mitigate | Audit carries ids, hash and sizes; sentinel search (Task 3) |
| T-07.5-07-08 | Elevation of privilege | a model guessing an approval id | medium | mitigate | No id input exists; grants are found only by hash (Task 1) |
