<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| channel messages → automatic bot turns | Any member's message can trigger a model call |
| browser → `clientTimeZone` | Client-supplied value enters the prompt |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-08-01 | Denial of service / cost | bot loops in reply mode | high | mitigate | Human-author-only trigger, silence when another bot is mentioned, 6/min per (bot, conversation) cap, daily limit; tests |
| T-03.1-08-02 | Tampering | prompt injection through `clientTimeZone` | medium | mitigate | Strict IANA validation (Zod + Intl), ≤ 64 chars; the server formats `local` itself |
| T-03.1-08-03 | Elevation of privilege | reply mode used where the org denied it | medium | mitigate | Effective `replyModeAll` decided at delivery with the current policy |
| T-03.1-08-04 | Repudiation | suppressed automatic replies | low | mitigate | `agent.reply_rate_limited` audit once per window |
| T-03.1-08-05 | Information disclosure | Redis cap keys | low | accept | Keys hold only counters with org/agent/conversation UUIDs and expire in 2 minutes |
</threat_model>
