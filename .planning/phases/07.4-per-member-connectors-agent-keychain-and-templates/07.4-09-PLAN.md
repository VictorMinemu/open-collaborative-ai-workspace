## Phase Goal

Agent tool calls to a connector go through an API proxy that uses the requesting member's credential; keys are used
by handle (plan map and executor rules: 07.4-01-PLAN.md).

**This plan's slice (tracer, cell level):** `ocw_connector_call` registered in the manifest, pre-checked by the guard,
posted to the Agent Channel API and answered back to the model — proven inside the real OpenClaw image by a new smoke
scenario (the phase's biggest external unknown, research A1); then the list and http-request tools with the guard's
per-logical-tool flags; then the smoke's slow, refusal and config checks. The plugin talks to the fake Agent Channel
API here; the real routes are 07.4-11 and 07.4-12.

<objective>
Add the three fixed `ocw_*` tools to the OpenClaw channel plugin as thin, credential-free callers of the Agent Channel
API, keep the local guard's taint and caps logic correct for them, and prove it in the real cell.

Purpose: CONN-03 (proxy path from the cell), CONN-04 (fixed connect sentence), CONN-05 (handle-only keychain use);
D-02, D-07 (three fixed tools), C-01.
Output: `connector-tools.ts` + tests, manifest, api-client, protocol mirror, guard, test host and fake API, smoke
scenario `connectors`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → plugin tool | Tool arguments written by a possibly prompt-injected model |
| cell → Agent Channel API | Cell bearer; the API decides and audits every call |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.4-09-01 | Spoofing | model chooses whose credential is used | high | mitigate | Bodies carry eventId/agentId only; the API derives the human from agent_turns (Task 1 test asserts exact keys) |
| T-07.4-09-02 | Information disclosure | member credential or per-member server in the cell | high | mitigate | Tools never receive credentials; smoke config check (Task 3); 06 filters /cell |

| T-07.4-09-04 | Information disclosure | API error bodies relayed to the model | medium | mitigate | Fixed sentences per code; canary test (Task 2) |
| T-07.4-09-05 | Denial of service | static tool not discovered or cut mid-call after an OpenClaw upgrade | medium | mitigate | Real-image smoke incl. 20 s call; ADR-0025 adds it to the upgrade checklist (Tasks 1, 3; 14) |
| T-07.4-09-06 | Elevation of privilege | OpenClaw per-requester OAuth turned on | medium | mitigate | Not configured anywhere (prohibition); C-01 recorded in ADR-0025 |
