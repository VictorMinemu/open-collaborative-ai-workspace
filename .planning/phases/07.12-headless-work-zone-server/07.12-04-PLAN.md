## Phase Goal

See `07.12-01-PLAN.md`. **This plan's slice:** the runtime survives logouts, crashes and reboots on a server (D-04):
generated systemd and launchd definitions with absolute paths, driven through an injected exec, guarded so tests never
touch the developer's machine, and refusing to fight another runtime on the same `~/.ocw` (D-14).

<objective>
Build `apps/local-runtime/src/service/`: detection, the systemd user and system units, the launchd LaunchAgent, the
command sequences for install, uninstall, status, logs and restart, the one-owner check, and the PD-19 exec guard,
exposed as `createServiceManager(deps)` and `serviceCommand(argv, deps)` (08 wires the CLI case).

Purpose: HSR-04; `setup` (08) installs through it and `doctor` (05) reads its `ServiceStatus`.
Output: seven modules and their tests (snapshots of generated files, exact command sequences on a fake exec).
</objective>
