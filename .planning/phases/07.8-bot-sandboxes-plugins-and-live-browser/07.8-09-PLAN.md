## Phase Goal

See `07.8-01-PLAN.md`. **This plan's slice:** the broker gains files, quota, idle stop, usage and an event feed, so the
API can offer file tools to bots (10) and to people (11) and mirror sandbox state.

<objective>
Implement the file operations, the `files` helper container, the soft quota, the idle sweeper, usage sampling and the
events long-poll in `sandboxd`, with the `ocw-files` helper in the `sbx` image, proven on real Docker.

Purpose: SBX-01 (quota, idle, limits), SBX-05 (files for people); D-01, D-04, D-09, D-11 (F-9).
Output: `files.ts`, `quota.ts`, `sweeper.ts`, `events.ts` (+ tests), server routes, helper script, smoke additions.
</objective>
