## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.11-02-01 | Information disclosure | `device_runtime_updates` across tenants | high | mitigate | Generic RLS + FORCE from post-migrate; composite FK with the organization; Task 2 cross-tenant cases |
| T-07.11-02-02 | Tampering | forged history row for another org's device | high | mitigate | Composite FK `(organization_id, device_id)`; RLS write check; Task 2 |

| T-07.11-02-04 | Repudiation | policy change without trail | medium | mitigate | Existing PUT audit with `changed: ["runtimeUpdates"]`; Task 1 asserts the row |
| T-07.11-02-05 | Tampering | invalid stored level | low | mitigate | Check constraint + tolerant read to the default |
