## Phase Goal

See `07.16-01-PLAN.md` (PD-04, PD-20). **This plan's slice:** where an owner, lead or admin gives a bot its Work Zone
profile, in the bot sheet, following `agent-messaging-section.tsx` (full desired state, the API's status line as the
confirmation) and the New session dialog's project and control pickers.

**Layout (no UI-SPEC; derived from existing components).** `SheetSection title="Work Zone"`. Row 1: status (dot + "Active"
/ "Inactive · sentence", `text-sm`), with the sponsor ("Runs as Ana Pérez") muted below. Then labelled groups with
`FormField` in a single column at 390 and a two-column grid from `md` where pairs fit (Default model | Bot may also use;
Default mode | Highest mode; the three limits in one row of three on desktop): **Where** (Device select with
`RuntimeLogo`-free device rows: name, "Server" badge for `hostKind = service`, online dot; Runtime as a two-option
segmented control with `RuntimeLogo`), **Projects** (the `ProjectList` look: checkbox rows grouped by team project, a
filter field when more than 8), **Model and options** (selects + chip multi-selects, disabled options show their
`controlReasonText` reason as a tooltip and a muted line on mobile), **Permissions** (two mode menus with
`permissionModeMeta` labels; Full access rows show the `FullAccessBadge` style), **Limits** (number inputs with "at once",
"prompts per hour", "wake-ups per session per day"), **Outside content** (switch or read-only value + amber callout with
the warning), footer: primary "Save profile" (full width on mobile), ghost "Remove profile" (destructive confirm).

<objective>
Add the bot sheet's Work Zone section and its query hooks: load the profile view, edit every profile field from the
caller's live device controls, save the full state, show the API's status and errors, remove the profile (D-01, D-02,
D-08, PD-04, PD-20).

Purpose: BWZ-01's "set by whoever manages it"; success criterion 1 starts here.
Output: one new component with tests, one new queries module, the sheet wiring.
</objective>
