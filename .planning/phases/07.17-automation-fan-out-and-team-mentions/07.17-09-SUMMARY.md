# Phase 07.17 Plan 09: Plugin open tool and route-decided board moves Summary

**`ocw_conversation_open` lets a fan-out run turn (also after reading the orders MCP) open one conversation per new item in a single call, and the cell's gate now lets board moves after outside content or a session read reach the route that decides them, while card creation from injected text stays refused locally.**

## Accomplishments
- New turn-scoped tool `ocw_conversation_open`: closed schema (`items` only, ≤ 25 of `{ externalKey, title, body }`), posts the turn's ids and the items, renders "opened <key> → <thread>", "already open <key>", "not opened <key> (run limit | daily limit)" and "<n> left this run, <m> today", or the refusal's fixed sentence. Logs carry ids and counts only.
- Guard: the open tool is self-validated with static flags and route-decided taint (D-05); `ocw_board_card` moved from `ALWAYS_SIDE_EFFECTING` to `ROUTE_DECIDES_TAINT` plus a new `ROUTE_DECIDES_SESSION_OUTPUT` (D-06, D-12). Every other guard rule is unchanged and still tested (memory, consult, Work Zone proposal, automation proposal keep their local block).
- Board tool: on a tainted or session-read turn, create and read refuse locally and post nothing; a move or waiting change of the thread's card posts without a read (version 1 when unknown) and retries ONCE with the version from the 409's `details.card`, so an automation item turn can move its card. Untainted turns are unchanged.
- Fake Agent Channel API: `/conversations/open`, `state.conversationOpens`, `/__test/conversations`; its board 409 now carries the current card like the real API (for 15's smoke).

## Decisions Made
- "opened <key> → <id>" shows the item's thread root (card or message id), else the conversation id.
- The open tool stays blocked locally after a Work Zone session read (the API's claim refuses side-effecting calls then); only the board tool joins `ROUTE_DECIDES_SESSION_OUTPUT`.
- A tainted or session-read board move without a remembered version names version 1; the one retry happens only on such a turn, only for a 409 `board_card_version_conflict` whose `details.card` is the same card. A retry costs one more call of the route's tool budget (the local gate counts the tool call once; the API stays the authority).
