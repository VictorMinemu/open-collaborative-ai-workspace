## Phase Goal

Any engineering team can install, upgrade, back up, observe and expose an MVP 1 instance with one command each, and
the MVP 1 acceptance scenario runs against that exact stack (user story and plan map: 07-01-PLAN.md).

**This plan's slice (tracer, observe):** a real API request's trace lands in Tempo through the collector after the
profile is enabled on a running stack; then metrics, logs, Grafana and the leak checks. The API side (preload,
redaction) is 07-05. Executor rules (D-11, D-12) as in 07-01.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → collector → backends | Telemetry crosses into separate stores operators may share |
| operator browser → Grafana | Loopback port, admin credential |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-07-01 | Information disclosure | query strings, tokens, host paths in stored telemetry | high | mitigate | Source redaction (07-05) + collector transform; canary checks in Tempo and Loki (Tasks 1, 2) |
| T-07-07-02 | Elevation of privilege | Grafana default credentials or anonymous access | high | mitigate | Generated password, refuse empty, anonymous off, `admin:admin` rejected in the smoke (Task 2) |
| T-07-07-03 | Information disclosure | backends reachable from outside | medium | mitigate | Only Grafana published, on 127.0.0.1; config test (Task 2) |
| T-07-07-04 | Denial of service | profile resources starving the stack | low | accept | Optional profile; memory_limiter in the collector; resource cost documented (Task 2) |
| T-07-07-05 | Tampering | enabling the profile disrupting data | medium | mitigate | Only api is recreated; data count checked before/after in the smoke (Task 1) |
</threat_model>
