## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → API | Ids and a repo-relative path from a less-trusted cell, possibly steered by outside content |
| asker ↔ sponsor | The attachment is decided with the asker's rights; the session and the transfer with the sponsor's |
| API → device | One command per call, after every decision |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.17.1.1-11-01 | Elevation of privilege | another session, another conversation | high | mitigate | `ownBotSession` + origin equality (`not_your_session` cases) |
| T-07.17.1.1-11-02 | Information disclosure | another thread's or conversation's file into a session | high | mitigate | `attachmentForTurn` as the asker (five refusal cases) |
| T-07.17.1.1-11-03 | Information disclosure | secrets or runtime config out of the device | high | mitigate | `workSessionFilePathRefusal` before the claim; the device re-checks (04) |
| T-07.17.1.1-11-04 | Tampering | prompt injection driving a move | high | mitigate | Tainted turns need `actOnOutsideContent`; session-output rule for one read session only |
| T-07.17.1.1-11-05 | Denial of service | many or huge moves | medium | mitigate | 8 calls, 5 each way, the hourly budget, the size limit before any byte |
| T-07.17.1.1-11-06 | Spoofing | cross-tenant cell tokens | high | mitigate | tx0 under the cell's organization; 404 `unknown_turn` case |
| T-07.17.1.1-11-07 | Repudiation | unrecorded outcomes | medium | mitigate | One record per outcome (denied row + refusal audit, or the success audit) |
| T-07.17.1.1-11-08 | Information disclosure | paths in records and logs | medium | mitigate | `pathLength` only; the whole-file record and log scan (P1) |
</threat_model>
