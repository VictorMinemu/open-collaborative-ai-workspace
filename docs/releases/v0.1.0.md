The first public release of Open Collaborative AI Workspace: **MVP 1, ready for testing with your team.**

## What is in it

- **Chat.** Channels, threads, DMs, attachments, search and notifications.
- **AI chats.** Multiplayer, with org keys or each member's own ChatGPT plan.
- **Bots.** OpenClaw bots with personas, Agent Cards, memory, per-tool approvals, sandboxes and a browser,
  automations, and consultations between bots.
- **Work Zone.** Claude Code and Codex sessions on a teammate's Mac (desktop app) or on a shared Linux or macOS
  server, driven from the browser.
- **Self-hosting.** One `docker compose` stack with HTTPS, backups, upgrades, optional OpenBao and observability.

## Install the server

On Ubuntu 24.04 or Debian 12, with a DNS name pointing at the server:

```bash
curl -fsSL https://raw.githubusercontent.com/VictorMinemu/open-collaborative-ai-workspace/main/scripts/install.sh \
  | sudo bash -s -- --domain ocw.your-company.com
```

The installer installs this release (`v0.1.0`). The [README tutorial](https://github.com/VictorMinemu/open-collaborative-ai-workspace#install-it-on-a-server)
walks through the first admin, model providers, invites and what to try first.

**Upgrade** later releases with `sudo node scripts/ocw.mjs upgrade` in `/opt/ocw`. It backs up first and never goes
backwards.

## Desktop app (macOS, Apple silicon)

1. Download `OCW-v0.1.0-macos-arm64.dmg` below and drag OCW to Applications.
2. The app is **not notarized** yet, so macOS blocks the first launch. Open it once, then go to **System Settings ›
   Privacy & Security** and choose **Open Anyway**. Alternatively, run
   `xattr -dr com.apple.quarantine /Applications/OCW.app`.
3. Enter your workspace URL, then pair the Mac under **Settings › Devices › Add device › Desktop app**.

On a server without a screen, use the headless runtime instead (**Settings › Devices › Add a device › Server**).
Signed builds for macOS, Windows and Linux are planned for MVP 2.

## Known limitations

- Bots cannot read attachments yet.
- Claude works only through an org API key.
- A remote install needs HTTPS (the installer sets it up).

The full list is in the [README](https://github.com/VictorMinemu/open-collaborative-ai-workspace#known-limitations).
Report problems as [issues](https://github.com/VictorMinemu/open-collaborative-ai-workspace/issues), and security
problems privately ([SECURITY.md](https://github.com/VictorMinemu/open-collaborative-ai-workspace/blob/main/SECURITY.md)).
