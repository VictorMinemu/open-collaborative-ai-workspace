## Phase Goal

People start their own agent from a template (plan map and executor rules: 07.4-01-PLAN.md).

**This plan's slice (tracer, templates end to end):** a lead publishes a template, a member clicks "Start from
template" in Bots and gets a personal bot carrying the template id and version; then the API rules (visibility,
versions, caps, filters, update/apply, privacy); then the editor, the update dialog and the screenshots. Plan mode
first (CLAUDE.md: permissions, audit and the personal-bot cap, D-06).

<objective>
Let units publish versioned agent templates and let members instantiate them as personal agents within the
personal-agent caps, forking on update with an explicit owner-applied update.

Purpose: CONN-06, SC4; D-05 (fork with "update available"), D-06, C-03.
Output: templates service and routes in the agent module, a `createPersonalBot` extension, Bots page template UI,
e2e with screenshots.
</objective>
