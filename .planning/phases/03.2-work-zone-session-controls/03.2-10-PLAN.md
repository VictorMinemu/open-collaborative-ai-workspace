## Phase Goal

**As a** controller of a Work Zone session, **I want to** work in a session screen that matches the reference layout, **so that** long multiplayer coding work stays readable and every control is where I expect it (ROADMAP Phase 03.2 goal and criterion 6, D-17; full user story in 03.2-01-PLAN.md).

**This plan's slice:** the whole session screen follows ref-4 — sidebar, header, stream, agent bar, composer frame and footer strip — with today's data only.

<objective>
Rebuild the Work Zone session screen around ref-4 using only data that exists (status, timestamps, branch, worktree, diff stat, changes, tool events), keep every existing behaviour, and record the elements that need new data as deferred.

Purpose: D-04 (header badge), D-17; WZC-06 (layout match, nothing faked); ROADMAP 03.2 criterion 6.
Output: new sidebar rows and groups, header breadcrumb + Full access badge, turn summaries, tool groups, changes card, agent bar, footer strip, inventory rows, layout e2e and screenshots.
</objective>
