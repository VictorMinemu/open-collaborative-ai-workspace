## Phase Goal

See `07.17-01-PLAN.md`. **This plan's slice:** the only migration of the phase (D-03 dedupe table, D-02/D-08/D-10 automation
columns, D-14 unit handles, D-07 `team_mention`, D-11 caps), tenant RLS on the new table, the item queue in the job
catalog, the code fallback of the caps, and the upgrade proof.

<objective>

`team_mention` kind to the Drizzle schema; generate the migration `automation_fan_out`; hand-edit the narrowed `SET NULL`

the code fallback to 5 / 288; prove constraints, RLS and the N-1 → N upgrade on ephemeral PostgreSQL (D-01, D-02, D-03,
D-07, D-08, D-10, D-11, D-14, PD-04, PD-05, PD-12, PD-21).

Purpose: every API plan reads and writes these rows; one migration keeps the upgrade a single `ocw upgrade`.
Output: schema, generated migration with header, post-migrate revoke, queue catalog, caps fallback, four test files.
</objective>
