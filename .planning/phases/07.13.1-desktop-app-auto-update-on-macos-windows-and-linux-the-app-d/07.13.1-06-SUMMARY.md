# Phase 07.13.1 Plan 06: The onboarding window shows and acts on the app update Summary

**The onboarding window now shows the same app update state as the tray in one slot under its header (release link
with the `.deb` wording, "Checking…", "Downloading v… N%", "Restart to update to v…", "Waiting for N sessions…" with
"Cancel the restart", "Restarting…", "Move OCW to Applications…", fixed error sentences) and its buttons call one new
channel, `ocw-onboarding:update-action`, accepted only from the onboarding page and only with the four
`UpdateActionArgs`; main runs the menu's `runUpdateAction`. The web app gains nothing.**

## Deviations from Plan

**1. [Rule 1 - Bug] `restarting` offered "Cancel the restart" in the onboarding window**
- **Found during:** Task 2
- **Issue:** `onboardingUpdateView` mapped the `restarting` phase to kind `waiting`, which the plan renders with
  "Cancel the restart". The tray shows no cancel there: once quit has started, `cancelWait()` clears
  `restartRequested`, so the app would quit without installing.
- **Fix:** `restarting` maps to kind `progress` (a sentence only); a test in app-update.test.ts.
- **Files modified:** apps/desktop/src/main/app-update.ts, apps/desktop/src/main/app-update.test.ts (outside the
  plan's `files_modified`)
- **Commit:** f445a49e

**2. [Rule 2 - Testability] The per-kind mapping lives in `shared/update-panel.ts`**
- The renderer runs `init()` on import, so the mapping went into a pure module with a unit test; onboarding.ts
  only writes the DOM. Two new files outside `files_modified`.

**3. [Rule 2 - Missing critical] The window asks for the status on open**
- Main pushes `statusChanged` only on a change; before this, a window opened while an update was already ready
  showed nothing until the next change (the 07.13 link had the same gap).
- **Commit:** 1c42bb10

**4. The link moved into the panel**
- The plan put the panel next to the existing link; the link now sits inside the panel (same `#update` id and
  markup) so the update is one slot and the plan's link + Move pair stays together.
