## Phase Goal

Any engineering team can install, upgrade, back up, observe and expose an MVP 1 instance with one command each, and
the MVP 1 acceptance scenario runs against that exact stack (user story and plan map: 07-01-PLAN.md).

**This plan's slice (tracer, operator CLI):** `pnpm ocw setup` end to end — dispatcher → setup → `.env` → accepted by
compose — then the `setup:env` compatibility shim and the template. Executor rules (D-11, D-12) as in 07-01.

<objective>
Give operators one small, dependency-free CLI whose first command, `ocw setup`, writes every secret once at setup time
without ever printing it, and give later plans the shared helpers and dispatch rule they extend.

Purpose: SELF-01 (`git clone` + `pnpm ocw setup` + `docker compose up`), SELF-02 (secrets as setup-time inputs); D-03,
D-13; D-10/D-18 (port blocks for second instances and gate stacks).
Output: `scripts/ocw.mjs`, `scripts/ocw/{env-file,setup}.mjs` (+ tests), the `setup:env` shim and its updated tests,
`.env.example`, `.gitignore`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator terminal / CI log ← CLI output | Anything printed may be captured in shell history, CI logs or screenshots |
| CLI → `.env` on disk | Secrets at rest on the host |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04-01 | Information disclosure | secrets printed by setup (today's setup token line) | high | mitigate | Names-only reporting; tests compare output against every written value (Tasks 1, 2) |
| T-07-04-02 | Information disclosure | `.env` readable by other users | medium | mitigate | 0600 on every write, including in-place updates (Task 1) |
| T-07-04-03 | Tampering | `--add-missing` rotating a database password and locking the stack out | medium | mitigate | Existing never-append rules kept and tested (Task 2) |
| T-07-04-04 | Denial of service | a second instance colliding with default ports | low | mitigate | `--ports` blocks with derived URLs (Task 1) |
| T-07-04-05 | Information disclosure | secrets/backups committed | medium | mitigate | `.gitignore` entries (Task 2) |
</threat_model>
