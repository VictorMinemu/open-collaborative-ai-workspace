## Setup (owner only; never run by an agent)

Needs real accounts, so only the owner runs it, on a workspace upgraded to this release:

- **Two Claude accounts** on a Pro, Max or Team plan. Run `claude setup-token` once per account and paste each token
  straight into Settings › Account pool. Never write a token in this file, a chat or a ticket: record results only.
- **Two ChatGPT accounts** (Plus, Pro or Business): one signed in **For bots**, one **On a device** (a headless Work
  Zone server updated to this release), plus a second slot on the same server for A-02.
- A member account (`sam@` in the demo) with access to that server and to a project on it.
- Labels used below: `claude-a`, `claude-b`, `chatgpt-bots`, `codex-a`, `codex-b`.

A real limit cannot be reached on demand. For A-01 and A-02, run a long, heavy session on the first account until the
provider reports its limit (a five-hour window is the quickest), or use an account already near its limit (its usage
bars in Settings show it when the runtime reported usage).
