## Broken-windows candidates (not written to WINDOWS.md, per instructions)

1. **The API does not send `CellProvider.imageModels` or `turn.maxSandboxCalls` yet.**
   - Plans 05 and 14 must set them.
   - Until then, the screenshot reaches no model, and the gate uses its default of 40.
2. **The sign-in "skipped" and "expired" sentences are exported (`SIGNIN_SENTENCES`) but not wired.** Plan 21 composes the card outcome; `mention-mapper.ts` will need them there.
3. **The fake model ignores directives after a tool image.** OpenClaw adds a `user` image message after the tool result, so `planToolStep` treats it as the human's text and replies generically. A screenshot therefore cannot be chained with other directives in one smoke turn; the smoke checks the model capture instead. `infra/fake-model/server.mjs` could skip `Image(s) from tool result` messages.
4. **Image downscaling is not exercised.**
   - The fake screenshot is an 8×8 JPEG.
   - OpenClaw's `imageMaxDimensionPx` downscaling of real 960×600 frames is documented, not exercised.
   - Plans 13 and 28 should check it with real `brw` frames.
5. **Pre-existing:** the `pg` "client.query() when the client is already executing" deprecation warning repeats in the integration suite.
