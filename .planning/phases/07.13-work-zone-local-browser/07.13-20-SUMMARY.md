## Accomplishments

- `apps/local-runtime/package.json` is `0.5.0`; `node scripts/check-runtime-version.mjs v0.5.0` prints `ocw-runtime 0.5.0 matches v0.5.0`.
- `ocw-runtime browser-agent --check` (its only flag, fine from a terminal) dynamically imports `playwright-core` and `@ocw/browser-engine/redact`, then prints `browser-agent ok <version>`. It launches nothing and needs no browser installed. The normal mode still refuses a TTY stdin.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The bundled runtime ran unzip.mjs's script mode instead of its own commands**
- **Found during:** Task 1 (the missing-playwright bundle test)
- **Issue:** `packages/browser-engine/src/unzip.mjs` ends with a "run as a script" guard: `import.meta.url === pathToFileURL(argv[1])`. Inlined into `ocw-runtime.mjs` (through `browser/install.ts`, plan 06), `import.meta.url` is the bundle's own URL, which equals `argv[1]` whenever the bundle runs from its real path. The result: `version`, `run` and every other command printed `usage: node unzip.mjs …` and exited 2, or tried to extract a zip named after the command.
  - macOS hid it: tmpdir sits behind the `/var` → `/private/var` symlink, so the paths differed in `bundle.test.ts`.
  - On Linux (CI, or a real `~/.ocw/runtime/versions/<sha12>` path) it would fire. At base, every bundle test outside the repo fails on a real path (reproduced).
- **Fix:**
  - Script mode now also requires the module's own URL to end in `/unzip.mjs`. The brw Dockerfile's `node unzip.mjs` and the unzip CLI test are unchanged.
  - The bundle test's scratch root is now `realpathSync`'d, so macOS catches this too.
- **Files modified:** packages/browser-engine/src/unzip.mjs (outside files_modified), apps/local-runtime/src/bundle.test.ts
- **Commit:** bd5ab31b (fix), e7d26745 (test path)

**2. [Rule 1 - Bug] Every runtime command loaded playwright-core**
- **Found during:** Task 1
- **Issue:** `unzip.mjs` required `playwright-core/lib/utilsBundle` at module load. That contradicted cli.ts's "Loaded lazily, so no other command loads playwright-core". It also made a missing playwright-core crash every command with a stack trace instead of the check's "not installed" line.
- **Fix:** the zip reader is required on first extraction. `capture.mjs` keeps its top-level require; only the agent imports it, lazily.
- **Commit:** bd5ab31b

No other deviations. The test commit came first, as TDD requires. The fix landed between RED and GREEN because the RED test exposed it.
