## Phase Goal

See `07.14-01-PLAN.md`. **This plan's slice (tracer, custody and sign-in tier):** the 07.4 credential module works for a
second principal, the organization, and an admin can connect, re-probe and disconnect an `org_oauth` server's shared
account through the one existing callback, with the same custody guarantees members have.

<objective>
Generalize `connectors/credentials.ts` over a principal (PD-04), move the connect-start body into `flow.ts` with the
`principal` field (PD-06), add `org-routes.ts` (connect, disconnect, the organization branch of the callback), make the
re-probe route mode-aware, keep the member list member-only, and export the organization API for 08, 09 and 10.

Purpose: COA-01's "connects it once" and COA-03's custody; everything bots do with the account (08) builds on it.
Output: the generalized credential module, `flow.ts`, `org-routes.ts`, the callback branch, the org sign-in suite, the
organization custody cases.
</objective>

| browser → public callback | Any browser can hit the callback with any state; the session is checked by hand |
