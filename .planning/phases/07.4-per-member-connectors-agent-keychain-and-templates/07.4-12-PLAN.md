## Phase Goal

Agent tool calls to a connector go through an API proxy that uses the requesting member's credential, audited per
call; without a connection the agent replies with a "connect your account" card (plan map and executor rules:
07.4-01-PLAN.md).

**This plan's slice (tracer, connector call end to end):** two members ask the same bot in their DMs; the cell's
`ocw_connector_call` hits the proxy, which claims the call, opens each member's own token and calls the fake MCP
`whoami` — each gets their own subject; then the refusals, the connect card, the forced refresh and the list route;
then the phase-wide leak sweep. Plan mode first (CLAUDE.md: permissions, audit, D-06).
