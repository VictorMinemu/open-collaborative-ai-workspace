## Phase Goal

**As a** member of an organization that uses the workspace, **I want to** hold a private, streaming AI conversation on my own ChatGPT plan by default or on a model my organization pays for — choosing the model per message, stopping and regenerating answers, with titles, instructions, web search, files, a usage record for every answer and a read-only share link for colleagues — **so that** I get a ChatGPT/Claude.ai-quality assistant inside the workspace where every generation is metered, private by default and attributable.

**This plan's slice (tracer):** the member presses Stop on a slow answer from the browser; the request lands on a second API instance, crosses Redis to the instance holding the stream, the stream aborts, the partial text is finalized and the browser shows it as Stopped. Then crash recovery and regenerate. Planner decisions P-01 … P-14 are in `05-01-PLAN.md` (P-06 streaming, P-07 one generation, P-08 executor rules, P-09 UI).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → stop / regenerate routes | Untrusted ids; identity from the verified session |
| API instance ↔ Redis `ocw:ai:abort` | Shared channel; messages are hints carrying ids only |
| sweeper (pre-tenant) → per-org transactions | SECURITY DEFINER candidate lookup returns ids only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-06-01 | Elevation of privilege | stopping or regenerating another member's generation | high | mitigate | Readable (hidden = 404) + `ai_chat.use` on the chat; generation must belong to the chat; int tests with Alex and the admin |
| T-05-06-02 | Tampering | forged abort messages on the shared Redis channel | low | accept | An abort only ends a generation early and keeps its text; the route that publishes is authorized and audited; the channel carries ids only and is parsed defensively |
| T-05-06-03 | Repudiation | replaced answers lost | medium | mitigate | `message_versions` kind `regenerate` (append-only grants from Phase 4) in the same transaction; audit `ai_chat.regenerated` |
| T-05-06-04 | Denial of service | stuck `running` rows blocking a chat forever | medium | mitigate | Heartbeat + sweeper (> 60 s) + shutdown finalize; int tests |
| T-05-06-05 | Information disclosure | cross-tenant rows through the sweeper | medium | mitigate | SECURITY DEFINER returns ids only; every change in that row's own `withTenant` transaction under RLS |
| T-05-06-06 | Denial of service / financial | parallel generations per user | medium | mitigate | Per-user concurrency cap under an advisory lock (429) |
</threat_model>
