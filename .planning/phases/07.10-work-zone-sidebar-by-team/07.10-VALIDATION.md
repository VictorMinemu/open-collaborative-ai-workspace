## Sampling Rate

- **After every task commit:** the task's quick command (per task below).
- **After every plan:** `pnpm verify` (+ `pnpm typecheck --force` after a contract change, 01 and 02); UI plans also run
  their isolated e2e set on both projects.
- **After every wave:** `pnpm verify` on the merged wave; from W2 on, the Work Zone and chat sidebar e2e specs.
- **Before `/gsd-verify-work`:** the full gate of 07.10-06 must be green.
- **Max feedback latency:** one task's quick command (< 120 s for unit/web, < 300 s for one integration file or one spec).
