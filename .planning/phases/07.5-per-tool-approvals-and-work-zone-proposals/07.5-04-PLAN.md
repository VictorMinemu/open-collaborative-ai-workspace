## Phase Goal

Per-tool approvals and Work Zone proposals (plan map, cross-plan contracts, planner decisions and executor rules in
07.5-01-PLAN.md).

**This plan's slice (tracer, cell level):** a flagged tool's call carries its full arguments to the (fake) Agent
Channel API, which answers `approval_required`, and the model hears the fixed sentence at once — while an unflagged
tool's body never carries arguments; then the param pin with its contract test and the connector tools; then the
approved re-run block.

<objective>
Make the cell's gate approval-aware without ever waiting for a human: send arguments only for policy tools, let the
API decide them after taint, answer with fixed sentences, pin the checked params against later rewrites, and tell the
model exactly what was approved on the re-run turn.

Purpose: APPROVE-01 (arguments only for flagged tools), APPROVE-02 (exact action, one call, any change denied —
the pin), APPROVE-04 (taint routes to a human, not a silent pass); D-01, D-02, D-04, C-01; UI-SPEC R10.
Output: gate, protocol mirror, connector tools, mention mapper, host double and contract tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → gate | Tool names and params are model output |
| other cell plugins → executed params | Lower-priority hooks may rewrite params after our gate |
| gate → Agent Channel API | Arguments leave the cell only for policy tools |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.5-04-01 | Information disclosure | arguments of tools without a policy leaving the cell | high | mitigate | `arguments` set only for flagged tools; key-absence and sentinel test (Task 1) |
| T-07.5-04-02 | Tampering | another plugin rewriting approved params | high | mitigate | Lowest-priority pin returning the checked params; contract test with a rewriting plugin (Task 2) |
| T-07.5-04-03 | Elevation of privilege | taint bypass through a flagged tool | high | mitigate | Flagged tools after taint go to the API, which requires a human (07, 11); unflagged keep the local block (Task 1) |

| T-07.5-04-05 | Tampering | API error text steering the model | medium | mitigate | Fixed sentences only; error bodies never forwarded (Tasks 1, 2) |
| T-07.5-04-06 | Elevation of privilege | model replaying a grant with different values | medium | mitigate | The re-run block carries the exact canonical arguments; any change produces a different hash at the API (07) (Task 3) |
