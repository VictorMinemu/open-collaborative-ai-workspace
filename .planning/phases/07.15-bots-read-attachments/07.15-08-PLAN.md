<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → API | The read request comes from the less-trusted cell, chosen by a model |
| API → Garage | The API reads bytes with server credentials (ADR-0015) |
| API → cell → model | Extracted text and image bytes are untrusted content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.15-08-01 | Information disclosure | reading another org's, conversation's or thread's file by id | high | mitigate | RLS + `attachmentForTurn` + `liveTurn` per call; the D-10 matrix in `attachments-security.int.test.ts` |
| T-07.15-08-02 | Elevation of privilege | a member removed mid-turn | high | mitigate | `liveTurn` re-decides the human's read access at every call → 403 `no_trigger`; test for read and import |
| T-07.15-08-03 | Spoofing | a cell acting for another user | high | mitigate | Strict request without `userId`; the asker comes from the stored turn |
| T-07.15-08-04 | Denial of service | read floods and huge outputs | medium | mitigate | Conditional UPDATE on `attachment_reads < 20`, row-locked character grant ≤ 200 000, per-file 64 000, PDF worker bounds (05); concurrency tests |
| T-07.15-08-05 | Tampering | prompt injection that then writes memory or shares files | high | mitigate | `untrustedOutput` taints at the claim; side-effecting tools refused `tainted`; tests for memory save and share |
| T-07.15-08-06 | Information disclosure | content or names in audit, logs, tool-call rows, activity | high | mitigate | `attachmentAuditFields` (ids, kind, type, counts); `err.name` logging; leak sweep with a marker and a name |
| T-07.15-08-07 | Repudiation | unaudited reads | medium | mitigate | `bot.attachment_read` on every outcome after the turn is known; `auditUnknownTurn` for no live turn |
</threat_model>
