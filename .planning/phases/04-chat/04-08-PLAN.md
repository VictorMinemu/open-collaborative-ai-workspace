## Phase Goal

**As a** member of a team that works in the workspace, **I want to** hold my whole daily conversation there — channels grouped by department and team, DMs and group DMs with people and bots, messages I can edit, delete, react to, pin, save and link to, @channel/@here and notifications I control, search and files — **so that** I do not need a second chat tool and every message stays attributed, editable under audit and delivered in realtime.

**This plan's slice (tracer):** an admin creates #design under the Product department and every member sees it in a collapsible Product section (contracts → `unit_id` → list DTO `unit` → grouped sidebar → browser). Then moving channels with unit-scoped rules, and the views. Planner decisions P-01 … P-12 are in `04-01-PLAN.md` (P-03, P-08, P-09).

<objective>
Group the sidebar by department and team using `conversations.unit_id`, let owners and admins place and move channels, make unit-scoped permission rules apply to channels, and add the All, Threads, AI Chats and Saved views (Mentions arrives with notifications in Plan 09).

Purpose: CHAT-02 with D-08 (Slack / T3 Code quality, Work Zone layout language).
Output: unit on create/move, `unit` in the list DTO, unit path on the channel resource, threads API with thread read markers, grouped sidebar with views, view pages, `e2e/tests/chat-sidebar.spec.ts`.
</objective>
