`/agent-channel/v1/board` from `stack.built.authz.routes` (14 routes) and requires each to be covered by:
- this file's org-B matrix: 14 cases on the 11 user routes and `POST /channels`, with Eve as org B's admin and a
  snapshot of org A's conversations, boards, columns, cards, messages, templates and streams that must be identical
  before and after. Answers are 404, 404 `unit_not_found`, 404 `template_not_found` or 400
  `template_not_available`, and contain none of org A's words;

  `TEMPLATE_CROSS_TENANT_ROUTES` (07) or `AGENT_BOARD_CROSS_TENANT_ROUTES` (10, 403 `no_trigger`), read from their
  source by route name.

## Deviations from Plan

1. **[Scope, user instruction] The guard references the existing tables** instead of duplicating every case. It
   reads them from their source by route name and still has its own org-B matrix for every user route (14 cases),
   so the plan's ≥ 10 route-path grep holds (31).
2. **[Rule 1, found by the gate] Spec defects that the full run surfaced** (`70b608a3`, `f7fa389d`):
   - board-manage asserted `?m=<card>` for a search hit, which predates 07.1-09; a card hit opens `?thread=<card>`.
   - Its org-wide helper template leaked into record-templates' "No templates yet" check; the helper now deletes
     the template once its board exists (D-06 snapshot).
   - Its tests never closed their contexts, and their pages stole focus from later specs. An `afterEach` now closes
     them.
   - record-templates' `pick()` now retries opening and clicking together.
3. **[Rule 1, Phase 4 code] The composer took the keyboard from an open dialog** (`8a6a9ce7`). Run 1:
   `search.spec` (desktop) opened ⌘K while #general was mounting; the composer's mount focus moved focus out of the
   palette, and the rest of the query was typed into the composer (screenshot evidence). `Composer` now skips
   autoFocus when focus is inside a dialog (`focusInDialog`, unit test). The new e2e (All → palette → Back) is
   deterministic, but it was **not RED** on the pre-fix build: in every staged order the composer mounted before the
   palette or not at all. The direct proof is a probe: a programmatic `focus()` outside the open palette moves focus.
   So the e2e documents the contract rather than proving the fix.
4. **[Test] The new palette test first matched the All link by exact name**, which reads "All 5" once other specs have
   run; it now matches by href (`c722b81e`).
5. **[Rule 1, Phase 4 code] A long channel list made the page scrollable** (`d4373944`). The unread badges'
   `sr-only` text is absolutely positioned. With no positioned ancestor it escaped the sidebar's scroller, so the
   document grew to the list's height (4,481 px with 117 channels), and focusing a card or dialog shifted the whole
   app up by 64 px. The app shell and the section sidebar's scroller are now `relative`. `chat-sidebar.spec`, with 40
   unread channels, asserts the document is exactly one window tall: RED 1,670 vs 900, then GREEN.
6. **[Design] Dark primary split into fill and text tones.** No single `--primary` passes both white-on-fill (needs
   L ≤ 0.183) and text-on-background (needs L ≥ 0.21). Darkening `--primary` alone would have dropped every dark
   `text-primary` link and label from 5.5:1 to 4.0:1. `--text-color-primary` (Tailwind 4.3 reads `--text-color-*`
   before `--color-*`) keeps text on the lighter tone. Only `globals.css` changed.
7. **[Registration] `agent.board.refused`** is listed in ADR-0022's audit actions. The repo has no code-level audit
   catalogue (audit actions are free strings in `AuditService.record`).
8. **[Process] Commits are subsets of a verified tree.** `pnpm verify` ran before each batch of commits: three API
   commits plus the Messages-view fix and the contrast fix on one verified tree, then one run each before
   `8a6a9ce7`, `c722b81e`, `d4373944` and the docs commit.
9. **[Docs] AGENTS.md** gained exactly one line (the board row in the stack table, 191 lines). The "Built so far"
   sentence points to `docs/STATUS.md`, which gained the 07.1 entry.
