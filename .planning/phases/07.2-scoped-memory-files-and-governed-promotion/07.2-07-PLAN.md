and executor rules in 07.2-01-PLAN.md).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → plugin tool parameters | Untrusted model output, possibly prompt-injected |
| plugin → Agent Channel API | The plugin forwards; the API is the authority |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.2-07-01 | Spoofing | Model choosing whose memory to read or write | high | mitigate | No owner/user parameter exists; strict mirrors; the API binds to `agent_turns.user_id` (Tasks 1, 2; 11) |
| T-07.2-07-02 | Tampering | Memory poisoning after reading web/tool content | high | mitigate | Write is always side-effecting → refused after taint; propose allowed but flagged and human-approved (Task 2; 09, 11) |
| T-07.2-07-03 | Elevation of privilege | Re-enabling OpenClaw file tools via a memory tool name | medium | mitigate | Fixed built-in names, manifest test, no render-config change (Task 1) |
| T-07.2-07-04 | Information disclosure | Personal file rendered in a shared conversation | high | mitigate | Mapper renders personal files only in direct turns (Task 3); the API sends them only in one-human DMs (11) |
| T-07.2-07-05 | Information disclosure | API error bodies or content in plugin logs | low | mitigate | Fixed refusal texts; ids and codes only in logs (Tasks 1, 2) |
| T-07.2-07-06 | Tampering | Memory read output treated as trusted instructions | medium | accept | Shared files are human-approved or human-written, personal writes need an untainted turn; the output is labelled as workspace memory (ADR-0023) |
</threat_model>
