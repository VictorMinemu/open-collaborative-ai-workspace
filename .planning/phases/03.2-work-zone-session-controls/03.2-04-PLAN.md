## Phase Goal

**As a** controller of a Work Zone session, **I want to** change the model, the thinking level and the permission mode — up to a real Full access where the device owner allows it — **so that** I can steer long coding work while my organization stays in control (ROADMAP Phase 03.2 goal; full user story in 03.2-01-PLAN.md).

**This plan's slice:** the organization's Work Zone policy, the device grain and the per-turn mode check bite on every request and every turn, server-side.

<objective>
Turn the catalog-only checks of Plan 01 into the full server-side intersection: org policy ∩ device opt-in ∩ device cap ∩ Full access grain ∩ runtime catalog, on every settings change, every new session and every turn, with downgrades when anything tightens.

Purpose: D-02, D-03 (server side), D-04 (audits), D-07, D-11, P-06, P-07, P-08; WZC-02/03/04 server enforcement; WZC-05 grain foundation.
Output: `work-session/policy.ts`, completed `controls.ts`, `device/access.ts`, resolver relation `full_access_grantee`, routes `GET/PUT /work-zone-policy` and `GET /work-zone/controls`, per-turn mode and `work_prompt.dispatched` audit, reauthorization (`onAccessChanged`), server-side fail-closed check.
</objective>
