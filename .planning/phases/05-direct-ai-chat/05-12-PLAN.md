## Phase Goal

**As a** member of an organization that uses the workspace, **I want to** hold a private, streaming AI conversation on my own ChatGPT plan by default or on a model my organization pays for — choosing the model per message, stopping and regenerating answers, with titles, instructions, web search, files, a usage record for every answer and a read-only share link for colleagues — **so that** I get a ChatGPT/Claude.ai-quality assistant inside the workspace where every generation is metered, private by default and attributable.

**This plan's slice (tracer):** the member drops an image into the composer: Phase 4 presign → Garage → sniff and renditions (`ready`) → the send links it to the user message → the turn streams the `large.webp` bytes from Garage into a file part → the fake vision model answers "… [images:1]" → the user bubble shows the thumbnail. Then PDFs/text and the gating. Planner decisions P-01 … P-14 are in `05-01-PLAN.md` (P-03 readable set, P-05 prompts, P-08 executor rules — the harness's Garage runs on :4292, P-09 UI).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → presign/complete (AI chat) | Untrusted files; Phase 4 sniffing and renditions apply |
| API → model provider | File bytes leave the server inside the model request only |
| uploaded file content → model | Untrusted content (prompt injection through files); labelled as untrusted and unable to trigger tools |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-12-01 | Information disclosure | storage URLs or internal hostnames sent to providers | high | mitigate | Bytes read with `ObjectStorage.stream` and sent inline; int test scans the captured request for the Garage host, `X-Amz-` and API paths |
| T-05-12-02 | Elevation of privilege | linking another member's or another chat's attachment | high | mitigate | `linkAttachments` requires same conversation, same uploader, `ready`, unlinked (409); int tests |
| T-05-12-03 | Information disclosure | admins or members downloading AI chat files | high | mitigate | Artifact routes use the readable set with kind `ai_chat` (owner-only); int tests for Alex and the admin |
| T-05-12-04 | Tampering | malicious files | medium | mitigate | Phase 4 type sniffing, EXIF-stripped renditions, inline only text ≤ 100 KB, other types refused; no side-effecting tools |
| T-05-12-05 | Denial of service / financial | huge attachments inflating tokens | medium | mitigate | Renditions for images, 10 attachments max, Phase 4 size limit, text inline cap, context cap from policy |
| T-05-12-06 | Elevation of privilege / Tampering | prompt injection in attachment content steering tools or instructions | medium | mitigate | File content only as labelled untrusted parts of the member's message, never in instructions; no tool offered unless the member enabled Web, and the only tool is read-only capped web search; no side-effecting tools in Phase 5; int test with an injected directive in a text file |
