## Deviations from Plan

- **[Order] Task 2 committed before Task 1.** The docs and CODEOWNERS went in first, so the gate's last `pnpm verify`
  ran on the final tree. Task 1's commit is then only the gate record and the screenshots.
- **[Orchestrator] Not rebased on `main`.** The plan's step 1 says "rebased on `main`". The orchestrator syncs before
  the PR.
- **[Orchestrator] Throwaway `.env`.** The `.env` came from `node scripts/setup-env.mjs --ports 73 --project
  ocw-e2e-071111` (orchestrator wording) instead of `pnpm ocw setup --ports 73 --project ocw-e2e-0711-11` (the same
  command, alias). It was never read, and it was removed at the end. `docker compose -p ocw-e2e-071111 down -v` left
  0 containers and 0 volumes.
- **[gate:compose] Its own project.** `gate:compose` always creates its own `ocw-gate-<id>` project (block 34xx) and
  tears it down, so it ran on `ocw-gate-mvsvqm2sb3f0`. None was left.
- **[Acceptance wording] The "status: validated" grep prints two lines.** One is the frontmatter. The other is the
  plan's own 07.11-11-03 row, whose command text contains that string. `nyquist_compliant: true` prints exactly one
  line: the sign-off checkbox was reworded to "`nyquist_compliant` set to true in the frontmatter".
- **[Rule 3] Biome format.** The three new `REQUIRED_AREAS` entries were reformatted by `biome format` (one line was
  too long) before the commit.

**Total deviations:** 0 product fixes. No assertion, check or gate was weakened.
