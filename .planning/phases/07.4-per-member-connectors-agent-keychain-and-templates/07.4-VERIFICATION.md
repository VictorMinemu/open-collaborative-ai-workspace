### Gaps summary

The phase delivers its goal. A shared bot calls per-member connectors and keys only through the two API proxies,
with the asker's own sealed credential. Every outbound byte goes through the pinned egress guard. Results stay where
only the asker reads them unless they share. Templates fork into capped personal agents. Isolation, owner-only data,
audit and the Bots-off backfill are proven by passing tests.

The one gap is architectural. The unit-audience rule for keys and templates lives in two module copies instead of the
resolver, so the resolver alone would allow a unit key to someone outside the unit. Unit memory already does it
right (`memoryPrecondition`). The fix is to move the rule there. The Keychain nav warning is small and optional.
