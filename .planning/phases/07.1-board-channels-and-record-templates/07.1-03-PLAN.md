## Trust Boundaries

| Boundary | Description |

| browser → `/boards/*` | Untrusted ids, move intents, descriptions and field values from any org member |
| API → `conv:<id>` stream | Board events reach every subscriber the topic authorizer admits |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.1-03-01 | Information disclosure | snapshot and card routes across tenants or into private boards | high | mitigate | RLS + `readableBoard` (404 hidden) on every route; cross-tenant table here, full matrix in 07.1-05 |
| T-07.1-03-02 | Information disclosure | board events leaking titles | high | mitigate | Events only on `conv:<id>` (resolver-gated topic); no `org:`/`user:` board events; audits ids only |
| T-07.1-03-03 | Tampering | lost or reordered moves (rank collisions, races) | medium | mitigate | Server-only ranks after `lockNextSeq`; optimistic `version` 409 with recovery; re-rank path; concurrency suite (Task 2) |
| T-07.1-03-04 | Elevation of privilege | posting on a board without `channel.post`, `@channel` without `channel.mention_all` | medium | mitigate | `writableBoard` makes the same decisions as the message route |
| T-07.1-03-05 | Spoofing | duplicate cards from retries | low | mitigate | `clientMessageId` idempotency of `postMessage` |
| T-07.1-03-06 | Denial of service | huge snapshots or replay floods | medium | mitigate | 100 cards per column with paging; one `board.column_reranked` per re-rank (REPLAY_LIMIT 500) |
| T-07.1-03-07 | Repudiation | who created or moved a card | low | mitigate | `board.card.created` / `board.card.moved` with actor, ids, column ids and versions |
