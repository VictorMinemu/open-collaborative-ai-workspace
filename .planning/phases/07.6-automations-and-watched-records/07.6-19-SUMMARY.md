## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `ocw restore` failed on any backup taken after 07.6**
- **Found during:** Task 1, first `gate:compose` (backup stage).
- **Issue:** the restore's first `migrate` installs `pgboss`; it then dropped only `app, auth, drizzle`, so
  `pg_restore` stopped at `CREATE SCHEMA pgboss` and left the stack with no application schema. Every operator restore
  after the 07.6 upgrade would have failed this way (07.6-03 regression; the gate is the first run of the round trip).
- **Fix:** drop `pgboss` too; the second migrate re-installs it for older backups. The backup round trip now also
  compares the restored pgboss version and queue names. Unit test pinned; backup-restore.md updated.
- **Files:** `scripts/ocw/restore.mjs`, `scripts/ocw/backup.test.mjs`, `scripts/gate/backup-roundtrip.mjs`,
  `docs/self-hosting/backup-restore.md` · **Commits:** `6f9b0131`, `ec37f1b4` (format)

**2. [Rule 1 - Bug] The new compose spec missed a run the real cell had already answered**
- **Found during:** Task 1, first gate run (mobile project timed out at 60 s while the run was `answered`).
- **Fix:** `answered` (which only follows `delivered`) counts as delivered. · **Commit:** `16d9b012`

**3. [Rule 2 - Missing] `OCW_JOBS_WORKER` never reached the API container**
- **Found during:** Task 2 (documenting the knob). 07.6-03 added it to the API's env, but `compose.yaml` did not pass
  it, so an operator could not turn workers off on a request-only replica.
- **Fix:** compose passes it (empty = on) with a compose test; `.env.example` (commented placeholder), INSTALL and the
  self-hosting page document it. · **Commit:** `e46b724a`
