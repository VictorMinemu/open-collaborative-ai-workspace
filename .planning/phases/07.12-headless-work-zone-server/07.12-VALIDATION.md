## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (unit; integration on real ephemeral PostgreSQL + Redis; web static markup), Playwright e2e and the proof config |
| **Config file** | root `vitest.config.ts` (projects `unit`, `integration`, `web`), `apps/local-runtime/vitest.config.ts`, `e2e/playwright.config.ts`, `e2e/playwright.proof.config.ts` |
| **Quick run command** | `pnpm exec vitest run --project unit <file>` (contracts, local-runtime, API pure modules, e2e support), `--project integration <file>` (API), `--project web <dir>`; `pnpm --filter @ocw/local-runtime test`; + `pnpm typecheck --force` after a contract change |
| **Full suite command** | `pnpm verify`, then `bash scripts/e2e-isolated.sh --rebuild-web e2e/tests/headless-pairing.spec.ts` and `bash scripts/e2e-isolated.sh e2e/tests/work-zone-headless-server.spec.ts --project=desktop`, then `bash scripts/e2e-isolated.sh --cmd "bash scripts/headless-server-proof.sh"` and `pnpm gate:compose` |
| **Estimated runtime** | quick ~30 s (the bundle smoke test ~10 s); `pnpm verify` ~18 min; each e2e spec ~3 min; the container proof ~4 min with a warm image |

---

## Sampling Rate

- **After every task commit:** the touched package's quick command plus `pnpm typecheck`
- **After every plan wave:** `pnpm verify` (+ `pnpm exec vitest run --project integration apps/api/src/modules/device` after W2 and W3)
- **Before `/gsd-verify-work`:** `pnpm verify` + the two e2e specs + the container proof + `pnpm gate:compose`
- **Max feedback latency:** 60 seconds for the quick command
