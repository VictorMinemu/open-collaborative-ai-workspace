This is environmental, but it means a single local `pnpm verify` is not a reliable gate while the VM is starved. That fits SUMMARY Deviation 7 (the demo cell restart loop, `RestartCount=10`, other containers restarting in the same window). The owner should check the Docker VM's load and memory.

   - `tools.web.search.provider` stays `duckduckgo` after an uninstall. This is log noise only: the API stops offering `web_search`.

Privacy *within* a tenant (owner-only DM) is enforced by the resolver and by membership-scoped queries, and tests prove it (404 for admin and others over REST and WS). This matches the project's model (ADR-0003, the `withTenant()` single entrypoint), but the requirement text overstates the RLS part. Consider rewording it when REQUIREMENTS is next edited.
