## Phase Goal

**As a** member of a team that works in the workspace, **I want to** hold my whole daily conversation there — channels grouped by department and team, DMs and group DMs with people and bots, messages I can edit, delete, react to, pin, save and link to, @channel/@here and notifications I control, search and files — **so that** I do not need a second chat tool and every message stays attributed, editable under audit and delivered in realtime.

**This plan's slice (tracer):** ⌘K → type an accent-less Spanish word → the matching message appears with a highlighted snippet → Enter jumps to it highlighted (resolver readable set → FTS → palette → permalink). Planner decisions P-01 … P-12 are in `04-01-PLAN.md` (P-03 readable set, P-08 executor rules, P-09 UI, P-11 rate limits).

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-06-01 | Information disclosure | private channel / DM content in hits (admins included) | high | mitigate | Readable ids only from `access.readableIds` (resolver, P-03); tests for admin non-member, bot DM of another user, org B |
| T-04-06-02 | Information disclosure | existence oracle via `in` filter | medium | mitigate | An unreadable `in` returns an empty result, never 404/403 |
| T-04-06-03 | Tampering | query syntax injection | medium | mitigate | `websearch_to_tsquery` (never raises on user input), bound parameters only, Zod length 1–200 |
| T-04-06-04 | Tampering | XSS through snippets | high | mitigate | Snippets rendered by `Snippet` as text + `<mark>` from `splitSnippet`; private-use markers; no HTML |
| T-04-06-05 | Denial of service | expensive searches | medium | mitigate | 30/min/user rate limit (P-11), GIN index, `limit ≤ 50`, debounce 250 ms |
| T-04-06-06 | Information disclosure | deactivated members / others' personal bots in people search | medium | mitigate | `deactivated_at is null`; agents only team or owned; tests |
</threat_model>
