## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → Agent Channel API | Bearer cell token; the API trusts only `agent_turns` |
| agent → human's board | The agent acts for the turn's human, never beyond the human's rights |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.1-10-01 | Elevation of privilege | agent acting in another conversation or for another human | high | mitigate | Conversation and human from `agent_turns` only; requests carry no ids of either; `card_not_in_board`; tests (Task 2) |
| T-07.1-10-02 | Tampering | prompt-injected agent creating or moving cards | high | mitigate | `sideEffecting: true` → refused after untrusted output (taint); per-turn cap; audit with human and agent |
| T-07.1-10-03 | Elevation of privilege | confused deputy (human lost access) | high | mitigate | agent ∩ human `channel.post` decision at call time; removed-member case |
| T-07.1-10-04 | Information disclosure | another tenant's turns or boards | high | mitigate | RLS on `agent_turns` and board tables; org B cell token case |
| T-07.1-10-05 | Spoofing | duplicate cards from OpenClaw retries | low | mitigate | `<eventId>:board:<n>` idempotency keys = `clientMessageId` |
| T-07.1-10-06 | Repudiation | which agent changed a card, for whom | medium | mitigate | `board.card.*` audits with `actorKind: agent`, agent id, user id; refusals audited |
| T-07.1-10-07 | Elevation of privilege | tool offered where it should not be | medium | mitigate | Offered only on board channels; text-channel tool lists asserted unchanged |
