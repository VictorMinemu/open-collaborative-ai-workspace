## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → API | Ids and a repo-relative path from a less-trusted cell, possibly steered by outside content |
| device → API | Acks and file bytes from the member's device |
| API → conversation | A downloaded file reaches the origin conversation's readers once the reply links it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.17.1.1-13-01 | Elevation of privilege | another session, another conversation | high | mitigate | `ownBotSession` + origin equality (`not_your_session` cases, both tools) |
| T-07.17.1.1-13-02 | Information disclosure | session files reaching a wider audience | high | mitigate | Origin conversation only; pending until the turn's reply; the deny list both ways |
| T-07.17.1.1-13-03 | Tampering | prompt injection driving a move | high | mitigate | Tainted turns need `actOnOutsideContent`; the session-output rule for one read session only |
| T-07.17.1.1-13-04 | Denial of service | many or huge moves | medium | mitigate | 8 calls, 5 each way, the hourly budget, the device-reported size against the limit before the PUT |
| T-07.17.1.1-13-05 | Information disclosure | paths in records and logs | medium | mitigate | `pathLength` only; the whole-file record and log scan (P1) |
</threat_model>
