## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page content → model | Untrusted; taints the turn |
| bot → member's signed-in site | Actions with the member's account |
| broker/agent output → API | Must not be trusted to have redacted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.8-14-01 | Tampering | prompt injection driving signed-in actions | high | mitigate | Approval floor `always` for act while a session is loaded, per action, 15-min expiry (Task 2) |
| T-07.8-14-02 | Information disclosure | password value leaking from a buggy agent | critical | mitigate | API second pass on `redacted` nodes with an incident record, sentinel test (Task 1) |
| T-07.8-14-03 | Information disclosure | URLs, queries or page text in audit | high | mitigate | Host-only metadata; sentinel `token=abc` absent (Task 1) |
| T-07.8-14-04 | Elevation of privilege | approval bypass by a policy-free re-run | high | mitigate | Grant consumed once inside the claim; `approval_used` (Task 2) |
| T-07.8-14-05 | Denial of service | browser exhaustion | medium | mitigate | Cap under advisory lock, shared budget, kill switch (Task 3) |
| T-07.8-14-06 | Information disclosure | cross-tenant contexts | high | mitigate | RLS, ids in `withTenant`, registry-derived org-B cases (Tasks 1, 3) |
