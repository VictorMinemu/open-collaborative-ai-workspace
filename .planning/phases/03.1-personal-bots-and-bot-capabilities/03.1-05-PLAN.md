<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| members posting (possibly in bursts) → delivery | Many concurrent writers race on one counter |
| API → model provider (via cell) | Metered or subscription-limited calls |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-05-01 | Denial of service / cost | counter race lets a bot exceed its limit | high | mitigate | Single conditional upsert (`WHERE turns < limit`); 20-way concurrency test |
| T-03.1-05-02 | Denial of service | over-limit still calling the model | high | mitigate | No cell event appended when over the limit; integration test counts events |
| T-03.1-05-03 | Denial of service | notice spam in channels | low | mitigate | Once per (bot, conversation, day) via `agent_limit_notices` |
| T-03.1-05-04 | Repudiation | limit hits | low | mitigate | `agent.limit_reached` audit per over-limit delivery, no content |
| T-03.1-05-05 | Information disclosure | notice reveals other humans' usage | low | accept | Notice states only the bot's limit and reset time |
</threat_model>
