## Phase Goal

See `07.11-01-PLAN.md`. **This plan's slice:** the Control Plane's compatibility manifest bites where members start
sessions: a broken installed version refuses a start with an actionable message, an unsupported one is flagged on the
device for everyone who sees it (ROADMAP success criterion 3, the start-time half).

<objective>
Make the manifest decide at session start (PD-13) and expose the per-runtime compatibility on every device DTO
(PD-05), with a test-only way to inject a manifest that has a broken range (the bundled one has none, PD-12).

Purpose: RTU-03's start-time flag and block; 10 renders the flag in the new-session dialog and the device card.
Output: `hub.runtimeManifest` and its plumbing, the start check, the DTO field, integration and cross-tenant cases.
</objective>
