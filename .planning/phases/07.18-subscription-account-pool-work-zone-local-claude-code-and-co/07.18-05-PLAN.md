## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.18-05-01 | Information disclosure | token in a response, an audit row or a log | high | mitigate | DTO without token keys; tests scan response text and audit metadata; `openPoolToken` never logs |
| T-07.18-05-02 | Elevation of privilege | a member managing the pool | high | mitigate | `provider.manage` preHandler on every route; 403 tests |
| T-07.18-05-03 | Information disclosure | cross-tenant account ids | high | mitigate | RLS + tenant tx; 404 tests from organization B |
| T-07.18-05-04 | Tampering | a sealed token moved to another account | medium | mitigate | AAD binds organization and account id; the organization-only AAD does not open it |
| T-07.18-05-05 | Repudiation | pool changes | medium | mitigate | One `account_pool.*` audit row per write, in the same transaction |
| T-07.18-05-06 | Denial of service | unbounded accounts | low | mitigate | 20 per provider (409) |
