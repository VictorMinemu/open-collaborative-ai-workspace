<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| onboarding renderer → main | The bundled local page (sandboxed, contextIsolation) calls the new channel |
| web app → main | Must not gain any update capability |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.13.1-06-01 | Elevation of privilege | web content invoking the update channel | high | mitigate | Handler accepts only `fromOnboarding` senders (`isTrustedSender` + `onboardingUrlOk`); the main preload has no such method (acceptance grep) |
| T-07.13.1-06-02 | Tampering | forged action values | medium | mitigate | `parseArgs(UpdateActionArgs, …)`: four literals; errors are never echoed |
| T-07.13.1-06-03 | Spoofing | a link to another site in the window | medium | mitigate | Links come from the controller's view, already checked with `isReleasePageUrl`; opened through the existing window-open guard |
| T-07.13.1-06-04 | Information disclosure | paths in the window | low | mitigate | The view carries labels, versions, counts and the release URL only |
</threat_model>
