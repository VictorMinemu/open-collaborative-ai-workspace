## UI contract (settings)

Every value comes from existing tokens and primitives (`apps/web/app/globals.css`, `components/ui/*`); no new design
system. Verified widths: 1440 (Playwright `desktop`) and 390 (`mobile`, Pixel 7, touch). Icons (lucide-react 1.48.0,
verified present): `Waypoints`, `X`, `Plus`.

### Placement
- **Settings › Bot policy** (`/settings/bot-policy`): a new section between `<BotPolicySettings />` and
  `<PersonalBotsTable />` (page.tsx gains one import and one line). Same section rhythm as the page: `h2` 15/600
  `tracking-tight`, description `text-sm text-muted-foreground`, content below with `gap-3`.
- **Bot detail sheet**: a new `SheetSection title="Consulting other bots"` directly after "Capabilities", rendered only
  for team and unit bots and only when the viewer holds `rule.read`.

### Organization switch (`data-testid="agent-consult-settings"`)
- One bordered row (`rounded-lg border bg-card p-4`, `flex items-start justify-between gap-4`): left, label (`text-sm
  font-medium`) and helper (`text-[13px] text-muted-foreground`, max 2 lines at 1440); right, `Switch`
  (`data-testid="agent-consult-switch"`), top-aligned.
- Pending: the switch stays visible and disabled with a 14 px `Spinner` to its left. Error: `toast.error(errorMessage(err))`
  and the switch returns to the server state. Success: `toast.success` with the on/off copy.
- No `rule.manage`: the switch is disabled and the helper gains "Only admins can change this."
- 390: the row stays one row; the text wraps; the switch's label area is at least 44 px tall.

### Per-bot section (`data-testid="agent-messaging-section"`)
Stacked, `gap-4`, inside the sheet's scroll area (sheet width at 1440 as today; full width at 390):
1. **Right now** (`data-testid="agent-messaging-effective"`, `aria-live="polite"`): `Waypoints` 14 px muted + one line
   `text-sm`; below it the people note in `text-xs text-muted-foreground`.
2. **Can ask** — `FormField` + `Select` (`data-testid="agent-messaging-mode"`) with four options. "Only these bots" is a
   disabled option while the organization switch is on, and the reason line shows under the select.
3. **Only these bots** (`data-testid="agent-messaging-allow"`, only in mode "only") and **Never ask**
   (`data-testid="agent-messaging-deny"`, hidden in mode "No bot"): a wrapping list of chips (`Badge variant="outline"`,
   `@handle`, a ghost `Button size="icon-xs"` with `X` to remove; `max-md:size-11` hit area) and a `Select` with placeholder
   "Add a bot…" listing team and unit bots that are not this bot and not already in either list (`displayName · @handle`).
   Empty: `text-xs text-muted-foreground` line.
4. **Inbound** (`data-testid="agent-messaging-inbound"`): bordered row like the org switch with its own `Switch`.
- Every change sends the full desired state with one PUT; while it is pending the section's controls are disabled; on
  error a toast and the server state come back; no success toast (the Right now line is the confirmation).
- Loading: three `Skeleton` rows (h-9). Error: inline "Couldn't load consult settings." + `Button variant="outline"
  size="sm"` "Try again".
- Read-only (`rule.read` without `rule.manage`, not reachable in v1 but defined): all controls disabled, no Add selects.
