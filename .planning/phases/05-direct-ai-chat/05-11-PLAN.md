## Phase Goal

**As a** member of an organization that uses the workspace, **I want to** hold a private, streaming AI conversation on my own ChatGPT plan by default or on a model my organization pays for — choosing the model per message, stopping and regenerating answers, with titles, instructions, web search, files, a usage record for every answer and a read-only share link for colleagues — **so that** I get a ChatGPT/Claude.ai-quality assistant inside the workspace where every generation is metered, private by default and attributable.

**This plan's slice (tracer):** one spec walks every AI chat screen and state in four variants (1440/390 × light/dark), asserts the layout invariants and captures the review set; the review drives the polish fixes and the accessibility pass. Planner decisions P-01 … P-14 are in `05-01-PLAN.md` (P-08 executor rules, P-09 UI).

<objective>
Bring the whole AI chat surface to ChatGPT/Claude.ai quality in the Work Zone/T3 Code language (D-08) and record the review: a visual walk-through spec with layout invariants, `05-UI-REVIEW.md`, polish fixes, an empty state with starters, and a keyboard/screen-reader pass.

Design direction (binding for this plan): a single centered reading column (max ~760 px, generous line height) with the header and composer aligned to it; user turns as compact right-aligned bubbles, assistant turns borderless full-width Markdown with a muted one-line footer that reveals actions on hover (always visible on touch); one accent colour for the primary action, METERED as a quiet outlined badge, errors as calm cards (not red banners); composer as a rounded surface with the model chip, tools button and attach inside it, Send/Stop as one icon button; 8-pt spacing; motion limited to the streaming caret and 150 ms fades, off under `prefers-reduced-motion`.

Purpose: D-08 for every AICHAT screen.
Output: `e2e/tests/ai-chat-visual.spec.ts`, `05-UI-REVIEW.md`, `AiEmptyState`, polish across `components/ai-chat/*`.
</objective>
