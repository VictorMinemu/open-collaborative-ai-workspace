## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device → API (Device Link) | `session.rename` carries an agent-chosen title and ids the device claims |
| admins / project leads → session agents | Naming rules travel to every session's title call and tool description |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.13.1.1-03-01 | Spoofing | a device renaming another device's or organization's session | high | mitigate | Device-tenant transaction from the authenticated link; `s.deviceId === device.deviceId`; RLS; `not_available` for both (Task 1 tests) |
| T-07.13.1.1-03-02 | Tampering | an agent overwriting a person's title | medium | mitigate | `title_locked` check under the session lock plus the conditional `title_source <> 'user'` update |
| T-07.13.1.1-03-03 | Denial of service | rename churn from a prompt-injected agent | low | mitigate | One rename per turn claimed in `work_prompts.title_renamed_at`; turns are bounded by people and bot caps |
| T-07.13.1.1-03-04 | Information disclosure | a secret or host path in an agent title | medium | mitigate | `SessionTitle` (host-path check) on the API; the device sanitizes first (plan 04); refused, never fixed |
| T-07.13.1.1-03-05 | Information disclosure | reply frame reaching another socket or a log | medium | mitigate | `replyOn` on the requesting socket only, validated, never queued, published or logged |
| T-07.13.1.1-03-06 | Tampering | naming rule as an injection channel | medium | mitigate | Bounded, tags stripped (`joinNamingRules`), plain text, audited by length only; the device delimits and frames it as data (plans 04, 05) |
| T-07.13.1.1-03-07 | Repudiation | an untraceable rule change or agent rename | low | mitigate | `work_zone_policy.updated { changed }`, `work_project.naming_rule_changed { length }`, `work_session.renamed { by: "agent", promptId }` |
</threat_model>
