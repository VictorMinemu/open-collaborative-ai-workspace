## Sampling Rate

- **After every task commit:** the task's `<automated>` commands (touched unit files, the touched integration file, the plugin suite when `apps/openclaw-channel` changed, the touched smoke scenario, the touched e2e spec through the isolated script), then `pnpm verify`.
- **After every plan:** `pnpm verify`, the plugin, local-runtime and desktop suites, `node --test 'infra/**/*.test.mjs'`, the smoke scenarios added so far when the plan touched `infra/openclaw` or `apps/openclaw-channel`, and the full isolated e2e.
- **After every wave:** the full suite, every smoke scenario so far and the full isolated e2e.
- **Before `/gsd-verify-work 03.1`:** 03.1-15 Task 2 (real-cell proof) and Task 3 (gate) green; screenshots reviewed.
- **Max feedback latency:** ≈ 90 s per targeted vitest command; ≈ 3 min per targeted e2e spec or smoke scenario.

## Hard rules (unchanged from Phases 2–3, plus this phase's)

- **Never touch the owner's demo:** database `ocw`, Redis DB 0, API :4000, web :3000, container `ocw-demo-openclaw`. No `docker compose down/rm/stop/restart`, no `pnpm demo:*`, no `pnpm db:migrate` with the default `.env`, nothing bound to :4000/:3000. Record `curl` answers and the demo container id before and after each wave.
- **Disk:** the Docker VM has about 700 MB free. No image pulls in CI-critical paths. The shipped cell image (with the bundled search plugins) is proven by the CI `images` job (`docker build -f infra/openclaw/Dockerfile -t ocw-openclaw:ci .`, GitHub runners); locally a missing bundled plugin directory is skipped at boot, and the local build is an open item only if it truly cannot be built. The smoke and the proof reuse `ocw-openclaw:local` and `ocw-fake-model:local` with working-tree code bind-mounted. Fakes (SearXNG, MCP, ClawHub) are routes of the existing fake-model server. Any new image (cell rebuild check in 03.1-04, `ocw-mcp-sandbox` in 03.1-14) is built only after `docker system df` shows enough free space, under a new tag, never retagging `ocw-openclaw:local` and never pruning other images.
- **One migration:** only 03.1-01 adds a Drizzle migration (D-05). Every later plan's verification includes "no new directory under `packages/db/drizzle`".
- **Plan mode** for changes touching permissions, policies, audit, tenant isolation or the schema (CLAUDE.md): 03.1-01, 02, 03, 04, 07, 09, 11, 12.
- **Package installs:** only `@openclaw/duckduckgo-plugin@2026.9.7`, `@openclaw/searxng-plugin@2026.9.7` (owner-approved official), `@modelcontextprotocol/sdk@1.30.0` (version OpenClaw ships) and, in the optional sidecar, `@modelcontextprotocol/server-everything@2026.8.31` ([OK]); exact versions, integrity checked, `--ignore-scripts`. No other dependency without a new legitimacy check.
