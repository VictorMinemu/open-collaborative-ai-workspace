## Phase Goal

Any engineering team can install, upgrade, back up, observe and expose an MVP 1 instance with one command each, and
the MVP 1 acceptance scenario runs against that exact stack (user story and plan map: 07-01-PLAN.md).

**This plan's slice (phase gate):** the clean-clone install proves SELF-01 on this machine, the whole local gate runs
green, the release is documented and decided (INSTALL guide, ADR-0021, requirements), and the owner repeats the
install on a real clean machine. Executor rules (D-11, D-12) as in 07-01.

## CI commands (D-12) — copy into the SUMMARY with each run's result

Every pull request (fast, no running stack):

1. `pnpm install --frozen-lockfile`
2. `pnpm verify` — lint, guard (Semgrep rules, dependency licenses, license fields, CODEOWNERS), typecheck, unit and
   integration tests (incl. the N-1 upgrade test, schema guard, OpenBao and telemetry). Needs Docker
   (testcontainers) and `uv` (or Docker) for Semgrep.
3. `node --test 'scripts/**/*.test.mjs'`
4. `npm ci --prefix infra/mcp-sandbox --ignore-scripts --no-audit --no-fund && node --test 'infra/**/*.test.mjs'`
5. `pnpm --filter @ocw/local-runtime test && pnpm --filter @ocw/desktop test`

Every pull request or merge to main (Docker, about 16 GB RAM for the profiles):

6. `pnpm exec playwright install --with-deps chromium`
7. `pnpm gate:compose --with-observability --with-vault`

Release or nightly:

8. `pnpm gate:cleanroom`

The existing jobs in `.github/workflows/ci.yml` (dev-server e2e, image builds, cell smoke) keep their commands.
