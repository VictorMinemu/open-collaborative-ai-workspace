## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → Agent Channel API | Tool bodies are model-written; the cell token proves only the cell |
| API → sandboxd | The API is the only caller; decisions happen before the call |
| admin → kill switch | An organization-wide stop |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
