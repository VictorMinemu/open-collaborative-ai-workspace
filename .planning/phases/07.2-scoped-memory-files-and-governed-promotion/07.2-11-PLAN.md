## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell (model output) → Agent Channel memory routes | Untrusted tool arguments under a cell bearer token |
| agent reply → conversation readers | Anything the bot reads can be quoted to everyone in the conversation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.2-11-01 | Spoofing | Model choosing the human or the scope owner | high | mitigate | Human = `agent_turns.user_id`; strict schemas; alias resolution server-side (Task 1) |
| T-07.2-11-02 | Information disclosure | Bot quoting memory to readers who may not read it | critical | mitigate | Audience rule on every read, list and turn injection; matrix tests (Tasks 2, 3) |
| T-07.2-11-03 | Tampering | Memory poisoning after untrusted content | high | mitigate | Atomic taint + cap check before writes; propose flagged and human-approved (Task 2) |
| T-07.2-11-04 | Elevation of privilege | Agent writing shared scopes | high | mitigate | Resolver precondition + `own_scope_only` mapping; shared notebook case tested (Task 2) |
| T-07.2-11-05 | Information disclosure | Personal notes readable by admins after the move | critical | mitigate | Private scope under RLS + resolver; admin endpoint test (Task 3) |
| T-07.2-11-06 | Information disclosure | Cross-tenant event ids | high | mitigate | Cell's org is the tenant; org B token on org A event → `unknown_turn` (Task 2) |
| T-07.2-11-07 | Repudiation | Agent writes without attribution | medium | mitigate | Revisions authored by the agent on behalf of the human; gate audit `bot.tool_call` for list/read (Tasks 2, 3) |
