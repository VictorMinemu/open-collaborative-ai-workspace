## Phase Goal

**As a** controller of a Work Zone session, **I want to** use the controls my organization allows — including Full access where it is allowed — **so that** I can steer long coding work while my organization stays in control (ROADMAP Phase 03.2 goal; full user story in 03.2-01-PLAN.md).

**This plan's slice:** an org admin governs the Work Zone from Settings, following the Bot policy page pattern.
