# Phase 07.17.1.1.2 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Written at planning time from RESEARCH.md
> § Validation Architecture and the plans' verify blocks (revised after the plan check: 14 plans); 07.17.1.1.2-14
> fills the Local and CI columns, the ADR-to-code map and the phase gate.

`wave_0_complete: true`: there is no separate Wave 0 plan. Every task that adds behaviour is `tdd="true"` and creates
its own test file RED as the first step of the same task, before the implementation (PD-03), and every verify block
names that file in an automated command, so no task waits on a test written elsewhere. The "Wave 0 Gaps" list below is
the inventory of those new test files and the task that writes each one first.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (projects `unit`, `integration` on real ephemeral PostgreSQL + Redis, `web`), `node --test` (fake services, guard), Playwright e2e (desktop 1440 / mobile 390, axe), the real-cell smoke |
| **Config file** | root `vitest.config.ts`; `e2e/playwright.config.ts`; `infra/openclaw/test/run-container-smoke.sh` |
| **Quick run command** | `pnpm exec vitest run --project unit <file>` |
| **Integration command** | `pnpm exec vitest run --project integration <file>` (one file at a time locally; Docker); regression sets as a `for f in …; do …; done` loop |
| **Full suite command** | `pnpm verify` (CI) |
| **Estimated runtime** | unit file ~10 s; integration file ~60–120 s; regression loop ~8–12 min; e2e spec ~4 min per project (four task turns with the 5 s gap); full verify on CI |

Local rule (PD-03): unit, web, typecheck, Biome, guard, each task's integration file and the regression loops run
locally; the e2e, the real-cell smoke, `pnpm gate:compose` and the full `pnpm verify` run on the PR's CI only (the
isolated e2e script would touch the owner's demo database). No test touches the network, a real device, `~/.ocw`, the
demo or `ocw.autofy.ing`.

## Sampling Rate

- **After every task commit:** the task's unit files (+ its integration file).
- **After shared agent-channel changes (07 T3, 09 T3, 11 T2, 12 T2):** the regression loop in the task's verify
  (`work-session-wakes`, `automation-items`, `consult-tick`, `chains`, `work-session-taint`, plus the task's own
  neighbours).
- **After every plan wave:** `pnpm lint && pnpm guard && pnpm typecheck && pnpm exec vitest run --project unit
  --project web` locally, then the PR's pipeline (integration included).
- **Before `/gsd-verify-work`:** every workflow green on the final tree (14 T3).
- **Max feedback latency:** 120 seconds locally (unit).
