# Phase 07.17.1 Plan 10: The daemon updates itself (device end to end) Summary

**The daemon now takes the click: `Daemon.create({ exitForUpdate })` builds the `SelfUpdate` on its own gates, every
`runtime.maintenance` frame carries `self`, the `ocw-runtime` command runs the job (refusals in the ack, redelivered
ids acked without a run), a turn held by the restart is told why, and after the switch `stop()` hands over without a
frame. The next daemon sends the run's `started` + `finished` right after `hello`, then removes the marker and prunes.
`ocw-runtime run` passes the hook: stop, then exit 75.**

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical] The hand-over closes the Device Link before the adapters stop**
- **Found during:** Task 1
- **Issue:** The old `stop()` order (maintenance, then `stopAll()`, then the link) sends a `session.state completed`
  for every session. Any later gate reopen could also run or fail a held prompt on the open socket. Either one would
  undo 09's PD-27 path, which re-queues a held, never-acked prompt after the restart.
- **Fix:** When the SelfUpdate still holds the gates after its own `stop()` (the switch happened), the daemon waits for
  the snapshot chain, closes the link, then stops the rest. A cancelled run (gates reopened) keeps the old order.
- **Files modified:** apps/local-runtime/src/daemon.ts
- **Verification:** the device end to end (no run frame in the hand-over window, gates closed); the busy case (the held
  prompt is never acked)
- **Committed in:** 2ca37682

**2. [Rule 3 - Blocking] cli.ts ran `main()` on import**
- **Found during:** Task 3
- **Issue:** The plan's tests import `selfUpdateExit` from `cli.ts`, but importing it ran `main()`. Inside a vitest
  worker that would start `run` on the real `~/.ocw` (PD-19).
- **Fix:** `main()` is skipped only when `globalThis.__OCW_CLI_IMPORT_ONLY__ === true`. Only `cli.test.ts` sets it,
  before a dynamic import. Real entries never set it, so they behave as before; the spawned-CLI tests still pass.
- **Files modified:** apps/local-runtime/src/cli.ts, apps/local-runtime/src/cli.test.ts
- **Committed in:** 22fda1a4

**3. [Rule 2 - Missing critical] The exit hook has a stop timeout**
- **Found during:** Task 3
- **Issue:** A `stop()` that hangs after `current` moved would leave the old build running with every gate closed.
- **Fix:** `selfUpdateExit` waits at most 10 s (`timeoutMs` for tests), then exits with the code anyway. This matches
  the signal path's 10 s fallback.
- **Committed in:** 045c3510
