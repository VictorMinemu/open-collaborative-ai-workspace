## Phase Goal

See 07.18-01 (the hub). **This plan's slice:** inside the OpenClaw cell, several ChatGPT sign-ins live side by side as
named profiles, each can be signed out alone, and the cell applies the pool the API sends: Claude setup-tokens as
`anthropic` token profiles read from env, and the order the strategy sets. OpenClaw keeps doing what it already does:
session stickiness, failover on a rate limit, refreshing OAuth (ADR-0006).
