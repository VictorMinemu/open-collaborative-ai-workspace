## Phase Goal

**As a** member of an organization that uses the workspace, **I want to** hold a private, streaming AI conversation on my own ChatGPT plan by default or on a model my organization pays for — choosing the model per message, stopping and regenerating answers, with titles, instructions, web search, files, a usage record for every answer and a read-only share link for colleagues — **so that** I get a ChatGPT/Claude.ai-quality assistant inside the workspace where every generation is metered, private by default and attributable.

**This plan's slice (tracer):** the member's plan hits its usage limit in the middle of an answer: the fake streams three deltas then `subscription_sharing_usage_limit_exceeded`; the run loop keeps the partial text and records the code, the gateway leaves the credential connected, and the browser shows the usage-limit dialog with "Manage usage" first and an explicit "Use an organization model". Then the other plan states and the desktop loopback. Planner decisions P-01 … P-14 are in `05-01-PLAN.md` (P-08 executor rules, P-09 UI, P-11 labels).

<objective>
Make the ChatGPT-plan backend behave the way OpenAI's preview requires and members expect: every SIWC error code maps to a clear state and action, no silent billing switch, "Continue with ChatGPT" in the picker, the one-time welcome dialog, and a paste-free desktop sign-in.

Purpose: the error and UX half of D-02 for AICHAT-02/03.
Output: `GenerationError` per code, usage-limit dialog, picker plan states, `ChatgptWelcomeModal`, welcome-seen route, desktop loopback listener + IPC, `e2e/tests/ai-chat-plan-errors.spec.ts`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenAI → API (SIWC error codes) | Untrusted provider errors mapped to states; never echoed verbatim to the UI |
| browser (remote web app) → desktop main via `window.ocwDesktop` | Narrow, Zod-validated IPC; sender re-checked |
| system browser → desktop loopback listener | Any local process could hit 127.0.0.1:<port> while the flow is pending |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07-01 | Repudiation / financial | silent switch from the plan to an org key | high | mitigate | No retry or re-route on failure; "Use an organization model" only changes the composer selection; int test asserts no Anthropic call after a plan failure |
