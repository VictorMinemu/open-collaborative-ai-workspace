<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → plugin | Tool parameters written by the model (possibly steered by outside content) |
| plugin → API | Bodies the plugin posts; the API re-decides everything |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.17.1.1-05-01 | Spoofing | parameters naming a device, user or URL | high | mitigate | Closed schemas, local key checks, tests per forbidden key (P6) |
| T-07.17.1.1-05-02 | Tampering | traversal in `path` | medium | mitigate | The mirror's `WorkSessionFilePath` locally; the API and the device re-check (01, 04, 12) |
| T-07.17.1.1-05-03 | Elevation of privilege | a local taint bypass | high | mitigate | The plugin never allows more than the route: it only stops blocking locally so the route's stricter rule applies (`ROUTE_DECIDES_TAINT`), and the per-turn count stays local too |
| T-07.17.1.1-05-04 | Denial of service | long tool calls | low | accept | One attempt, bounded by `transferMaxMs` + 15 s; A-01 checked by the owner's UAT |
| T-07.17.1.1-05-05 | Information disclosure | file content in the model's context | medium | mitigate | Neither answer carries content; the download answer says to read it later with `ocw_attachment_read` (tainted, 07.15) |
</threat_model>
