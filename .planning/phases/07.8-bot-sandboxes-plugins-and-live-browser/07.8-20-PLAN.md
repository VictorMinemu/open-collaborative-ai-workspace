| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07.8-20-02 | Information disclosure | typed values or element names to non-requesters | high | mitigate | 07.5 summary view for non-DM readers; no value in steps (Tasks 2–3) |
