## Deviations from Plan

### Auto-fixed and added (Rules 1–3)

1. **[Rule 2] API route outside `files_modified`.** "While a watchable context of that conversation is open" is a server
   fact the web cannot derive (an idle stop closes a page without any chat event): `GET /api/v1/conversations/:id/browsers`
   (`browser/conversation-browsers.ts`, registered from `routes.ts`), readable conversation or 404 (hidden = missing),
   `browser.watch` per page as the live view decides it. Tested for readers, threads, non-readers, another organization
   (404, never an empty list) and a member-session page (its member only).
2. **[Rule 2] `requesterName` and `decidedAt` on the sign-in link** (contracts, additive): every reader's card needs the
   requester's name ("Only {person} can sign in here.", "{person} signed in.") and the decision time ("Signed in by …
   · {time}"); the card carried neither.
3. **[Rule 2] Semgrep `ocw.live-input-logging` now covers the DOM input** (`$X.data`, `$X.value`,
   `$X.clipboardData`): a `console.log(e.data)` in the new keyboard input was not caught before. Fixture lines added;
   no false positive in the rule's paths.
4. **[Rule 2] The fake sandboxd writes the `focus` control** on open frame streams on `focus_sensitive`, as the agent
   does, so the password switch is proven end to end (fake test added).
5. **[Rule 1] Card header at 390:** the "Sign-in needed" pill overlapped the workspace badge; the sign-in card's header
   row wraps (other cards untouched).
6. **[Rule 1] Dock handle swipe** lost the pointer once it left the handle: pointer capture.
7. **[Rule 3] Wiring outside the list:** `AgentCardView` gets the posting bot (`author`, from `message-list.tsx` and
   `ai-message.tsx`) so the card can open its live view; `app-shell.tsx` pads `<main>` with `--live-dock-h`;
   `takeover-bar.tsx` gets a `phone` variant (no keyboard hint); `live-header.tsx` exports `IconButton`, `StateChip`,
   `Where` and takes `iconClassName`; `e2e/support/sandbox.ts` gains `signedIn(contextId)`; `live.test.tsx`'s view
   helper gets the three new view fields.
