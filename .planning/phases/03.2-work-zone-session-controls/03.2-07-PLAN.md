## Phase Goal

**As a** controller of a Work Zone session, **I want to** change the model, the thinking level and the permission mode — from the menus or with slash commands — **so that** I can steer long coding work while my organization stays in control (ROADMAP Phase 03.2 goal; full user story in 03.2-01-PLAN.md).

**This plan's slice:** slash commands typed in a prompt are routed through the session controls (policy-checked, audited) or refused; they never reach the runtime raw.

<objective>
Route every leading slash command through one server decision (P-10): settings commands reuse the settings path, passthrough commands become prompts, everything else is refused with a notice; the composer uses it and `POST /prompts` refuses to be a bypass.

Purpose: D-13, ADR-0012 §4; WZC-04 "slash commands cannot raise the mode or change settings outside policy"; WZC-01 "reachable from the same chat".
Output: `slash.ts`, `POST /work-sessions/:id/commands`, `POST /prompts` refusal, composer routing with notices, e2e.
</objective>
