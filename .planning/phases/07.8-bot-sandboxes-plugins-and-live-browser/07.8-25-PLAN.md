## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| member session data → team bot workspace | The workspace is read by every member's turns |
| conversation attachments → workspace | Import must not widen an attachment's audience |

| T-07.8-25-01 | Information disclosure | member data copied to a shared workspace by the model | high | mitigate | `member_data` turn rule for team bots (Task 1) |
| T-07.8-25-02 | Information disclosure | signed-in downloads in the workspace | high | mitigate | Routed to the conversation when a session is loaded (Task 2) |
| T-07.8-25-03 | Information disclosure | importing a DM attachment into a team workspace | high | mitigate | Resolver `audienceCovers`, refuse when unsure (Task 2) |
