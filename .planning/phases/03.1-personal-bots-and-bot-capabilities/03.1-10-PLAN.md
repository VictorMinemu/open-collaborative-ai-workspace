<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell → remote MCP server | Outbound calls with org credentials to admin-registered endpoints |
| MCP server → model | Tool results are untrusted content |
| npm → plugin dependencies (`@modelcontextprotocol/sdk`) | Third-party code inside the gateway process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-10-01 | Information disclosure | MCP credentials in config/logs | high | mitigate | `${OCW_MCP_…}` env refs only (reconciler test asserts no literal value), probe errors stripped of header values, logs without payloads |
| T-03.1-10-02 | Elevation of privilege | un-enabled MCP tools reaching a model | high | mitigate | `toolFilter.include` per server, exact `alsoAllow` names per agent, `toolsAllow` per turn, hook gate; smoke asserts offered names |
| T-03.1-10-03 | Tampering | MCP output steering side effects | high | mitigate | Taint rule in the guard and the API; `trusted_chaining` admin opt-in only |
| T-03.1-10-04 | Elevation of privilege | confused deputy through MCP tools | high | mitigate | `bot.tool.use` with the tool layer decided as agent ∩ human at turn and call time; rule test |
| T-03.1-10-05 | Denial of service | MCP runtime explosion | medium | mitigate | `sessionIdleTtlMs: 600000`; servers without enabled tools never rendered; OpenClaw cap of 256 runtimes |
| T-03.1-10-06 | Repudiation | MCP calls | medium | mitigate | `bot.tool_call` audits with server safe name and tool; completion audit |
| T-03.1-SC | Tampering | npm install of `@modelcontextprotocol/sdk@1.30.0` | medium | mitigate | Exact version equal to the one OpenClaw 2026.9.7 bundles (research B6, older than the too-new window); lockfile integrity; image build uses `--ignore-scripts` |
</threat_model>
