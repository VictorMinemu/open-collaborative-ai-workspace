## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.18-15-01 | Information disclosure | the pasted token lingering in the page | medium | mitigate | Password-type field, form state cleared on close and after save, never shown again (the API never returns it) |
| T-07.18-15-02 | Information disclosure | the device code in logs | low | mitigate | No console output; cleared when the dialog closes |
| T-07.18-15-03 | Elevation of privilege | members reaching the page | low | mitigate | The nav entry is gated by `provider.manage`; the API decides every route (403) |
| T-07.18-15-04 | Spoofing | a verification link pointing elsewhere | low | mitigate | The link comes from the API (bounded `z.url()`), opened with `rel="noopener noreferrer"` |
