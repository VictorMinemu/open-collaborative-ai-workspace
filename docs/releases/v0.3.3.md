A fix for bots with many MCP tools turned on: they get their **Work Zone sessions, sandbox, document tools and long
tasks** back.

## What's fixed

- **Platform tools always fit in a bot's turn.** A turn carries at most 128 tools. When a bot had enough MCP tools
  turned on (for example with **Turn on: All**), those filled the turn first and the platform's own tools were left out
  without a word. The bot then proposed Work Zone sessions instead of starting them (even with an active Work Zone
  profile), said it had no background execution or PDF tools, and did not start long tasks. MCP and plugin tools now
  take at most 101 places, and the remaining 27 stay for the platform's tools: Work Zone sessions and files, sandbox,
  browser, long tasks, reading attachments, consulting other bots and automation fan-out.
- **The bot sheet says which MCP tools do not fit.** **Tools** now counts against the 101: "A turn carries at most 101
  tools from MCP servers and plugins, so the platform's own tools always fit." Turn off the ones a bot does not need.

## Upgrade

In `/opt/ocw` (or wherever the server is installed):

```bash
sudo node scripts/ocw.mjs upgrade --check   # current and newest release; changes nothing
sudo node scripts/ocw.mjs upgrade           # backup, this release, new keys, rebuild; never goes backwards
```

- **No migrations, no new settings.** Only the API changes; bots get the fixed tool list on their next turn.
- **Headless Work Zone servers** on v0.3.1 or later update their runtime with one click (Settings › Devices › the
  server › Runtime updates › **Update**), or by themselves at the *Automatic* level. Nothing in the runtime changed
  besides its version.

The desktop app does not update itself: install the new files below. Its runtime ships inside it.

## Install the server

On Ubuntu 24.04 or Debian 12, with a DNS name pointing at the server:

```bash
curl -fsSL https://raw.githubusercontent.com/VictorMinemu/open-collaborative-ai-workspace/main/scripts/install.sh \
  | sudo bash -s -- --domain ocw.your-company.com
```

The installer installs this release (`v0.3.3`). The [README tutorial](https://github.com/VictorMinemu/open-collaborative-ai-workspace#install-it-on-a-server)
walks through the first admin, model providers, invites and what to try first.

## Desktop app

None of the builds is signed yet, so the first launch needs one extra step:

- **macOS** (Apple silicon): open `OCW-v0.3.3-macos-arm64.dmg` and drag OCW to Applications. Open it once, then go to
  **System Settings › Privacy & Security** and choose **Open Anyway** (or run
  `xattr -dr com.apple.quarantine /Applications/OCW.app`).
- **Windows** (x64): run `OCW-v0.3.3-windows-x64-setup.exe`. If SmartScreen stops it, choose **More info › Run
  anyway**. It installs for the current user, without admin rights.
- **Linux** (x64): on Ubuntu or Debian, `sudo apt install ./OCW-v0.3.3-linux-amd64.deb`. Elsewhere,
  `chmod +x OCW-v0.3.3-linux-x86_64.AppImage` and run it. The app keeps the device token in the desktop keyring
  (GNOME Keyring or KWallet), which must be available.

Then enter your workspace URL and pair the computer under **Settings › Devices › Add device › Desktop app**. On a
server without a screen, use the headless runtime instead (**Settings › Devices › Add a device › Server**). Signed
builds are planned for MVP 2.

## Known limitations

- Long tasks run in channels, threads and DMs, not in AI chats. A task stays in its own thread: it cannot span several
  conversations or bots, and there is no list of a bot's tasks yet (the card in the thread is the place to look).
- A turn carries at most 101 tools from MCP servers and plugins (128 in all). The bot sheet's **Tools** section says
  how many of the ones you turned on do not fit.
- A very large job may need more than the 40 turns of the default. The card then says the task used its turns; an
  admin raises **Turns per task** and the person asks again.
- After **Stop**, a turn already running finishes before the task ends (OpenClaw cannot abort a turn).
- Bots read documents in Spanish and English OCR only, and do not transcribe audio or video.
- The desktop app does not update itself, and its builds are not signed yet.
