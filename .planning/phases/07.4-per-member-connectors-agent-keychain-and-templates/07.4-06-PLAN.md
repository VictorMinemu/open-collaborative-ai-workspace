07.4-01-PLAN.md).

audit and policy changes, D-06).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser → API | Connector configuration including a client secret |
| API → OpenClaw cell (`/cell`) | Only org-level credentials may cross; member credentials never |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.4-06-01 | Information disclosure | per-member connector rendered into the cell | high | mitigate | `cellMcpServers` filters `org_secret`; snapshot test after create and after a mode switch (Tasks 1, 2) |
| T-07.4-06-02 | Information disclosure | client secret in responses or audit | high | mitigate | Sealed via SecretsService, `hasSecret` only, canary assertions (Task 1) |
| T-07.4-06-03 | Elevation of privilege | non-admin edits a connector | high | mitigate | Resolver `mcp.manage` on every mutation, tested (Task 2) |
| T-07.4-06-04 | Tampering | mode switch silently reuses member credentials under another mode | medium | mitigate | 409 until confirmed; connections and secrets deleted in the same tx; audited with count (Task 2) |
| T-07.4-06-05 | Information disclosure | cross-tenant connector or client read | high | mitigate | RLS + 404 tests for another org's admin (Task 2) |
| T-07.4-06-06 | Repudiation | AS-side grants survive a mode switch | low | accept | Local tokens destroyed (security property); AS grants expire or are revoked by the member at the provider; documented in 14's self-hosting doc |
</threat_model>
