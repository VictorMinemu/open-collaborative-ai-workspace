# Phase 07.16 Plan 06: Bot limits in the one controls context and createWorkSession Summary

**A bot's Work Zone caps (`AgentControlsLayer`) are one optional field of the single `ControlsContext`, checked last
in `modeControl` and `modelControl` as `bot_profile`, and `createWorkSession(…, { agent: { layer } })` creates the
bot's session (started_by_agent_id, author_agent_id, tainted_at) through exactly the checks a person's start runs.**

## Intended change (CLAUDE.md plan mode: permissions, policy, audit)

- `context.ts`: `LoadControlsOptions.agent?` copied into `ctx.agent`; nothing else in the member computation changes
  (`modeCap` stays the sponsor's own).
- `controls.ts`: `ControlsContext.agent?`; one last check in each builder: `modeControl` (rank above `maxMode`, or
  Full access without `allowFullAccess ∧ (¬tainted ∨ isolated)`) and `modelControl` (model, effort, context window
  outside the profile's sets; fast mode `off`) → `bot_profile`. Only an otherwise available option is downgraded, so
  every member/runtime/inventory reason keeps its precedence (principle 6). Absent agent = byte-identical controls.
- `start.ts`: `WorkSessionStartOptions.agent` / `firstPromptTainted`; the bot's model decided as a change; the
  session's `started_by_agent_id` and `tainted_at`; the first prompt's `author_agent_id` / `tainted`; audits carry
  ids and booleans only. No human caller passes `agent`; no new permission path; no permission, RLS or approval gate
  touched.
- `app.ts`: `BuiltApp.workSession` (tests only).

## Decisions Made

- `bot_profile` comes after `not_confirmed` too (the plan's "after every existing reason"): an option the inventory has
  not confirmed reports `not_confirmed` even for a bot.
- The bot's start baseline has `model: null` so `decideSettings` sees the bot's model as a change; without this the
  model would equal the baseline and skip the check. The person's baseline is unchanged.
- `tainted` appears in `work_session.created` only for a tainted session (the bot's layer), never for a person's
  `firstPromptTainted` Start, whose taint is recorded on the prompt and its `work_prompt.queued` audit.

**1. [Rule 1 - Bug] Racy "writes nothing" snapshot in the new integration file**
