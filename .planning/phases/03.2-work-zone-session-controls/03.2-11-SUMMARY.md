## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Realtime org streams went silent after 500 events**
- **Found during:** Task 3 (full e2e). Two full runs failed the same two mobile specs: `work-zone-layout` had a sidebar row stuck on "Working", and `work-zone.spec` never showed `device-paired`. Both pass in the Work Zone subset run.
- **Root cause:** org topics subscribe with `afterSeq` 0. Once `org:<id>` has more than `REPLAY_LIMIT` events, the server answers `resync`. The client never moved its cursor off 0, so every live event looked like a gap, triggered another truncated replay and was never delivered. This hit every `org:` consumer: device lists, Work Zone session lists and pairing. It is a pre-Phase-03.2 bug that only shows once the org stream is large, which happens in the full suite and in any real org.
- **Fix:** after `resync`, the client takes the next `subscribed` frame's `lastSeq` as its cursor and ignores gap frames until then. `setLastSeq` clears that state.
- **Tests:** RED test first (aea2d22), then the fix (d0c4abd). The full suite then passed 88/88 (1 skipped by design).
- **Files modified:** `packages/realtime-client/src/client.ts`, `client.test.ts`.

**2. [Rule 1 - Test] Inventory row count:** my first row filter counted the table separator lines. Fixed before the GREEN commit.
