## Phase Goal

See `07.11-01-PLAN.md`. **This plan's slice:** the daemon does it all by itself (D-09): it checks at start and every
6 h, decides with the org level and its own level, waits for an idle moment without cutting anyone, retires idle
processes, updates, verifies and reports, and answers "Update now" from the web, the CLI and the control socket.

<objective>
Write the `RuntimeMaintenance` orchestrator and wire it into the daemon: `runtime.config` in through a new
`onServerFrame` hook, the per-runtime gates on held commands, the `runtime.update` command, the snapshot and run frames
out, the local level read from env/config, cadence and backoffs, stale reporting, session events for held turns, cache
refresh after a run, and the control-socket and CLI triggers (PD-07, PD-08, PD-10, PD-11).

Purpose: RTU-04 on the device; RTU-01/02/03/05 behaviour; the daemon half of 09's end to end.
Output: `maintenance/maintenance.ts` (+ test), daemon/device-link/control-socket/config/CLI changes with tests.
</objective>
