## Sampling Rate

- **After every task commit:** the task's quick unit / integration / web command (per task below).
- **After every plan:** `pnpm verify` (+ `pnpm typecheck --force` after a contract change); UI plans also run their isolated e2e spec on both projects.
- **After every wave:** `pnpm verify` on the merged wave.
- **Phase gate (07.1-14):** full suite + every board spec and the regressions on one fresh isolated stack + `pnpm gate:compose`; screenshots reviewed against the UI-SPEC.
- **Max feedback latency:** one task's quick command (< 120 s for unit/web, < 300 s for one integration file).
