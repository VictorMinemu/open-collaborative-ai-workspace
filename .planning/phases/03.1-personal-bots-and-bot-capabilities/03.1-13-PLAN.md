## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → marketplace/MCP routes | Admin decisions about third-party code and endpoints |
| UI rendering of third-party metadata | Plugin names, descriptions, tool descriptions come from ClawHub or MCP servers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-13-01 | Tampering / XSS | third-party descriptions rendered in the UI | medium | mitigate | Rendered as plain text (no Markdown/HTML), length-truncated; React escaping only, no `dangerouslySetInnerHTML` |
| T-03.1-13-02 | Information disclosure | MCP credential re-display | high | mitigate | Write-only inputs; DTOs carry `hasValue`; e2e asserts the token never appears in the page |
| T-03.1-13-03 | Elevation of privilege | uninformed high-risk installs | medium | mitigate | Typed acknowledgement for high risk, no install button for Blocked, trust note in the sheet; API re-checks everything (03.1-11) |
| T-03.1-13-04 | Elevation of privilege | non-admins reaching admin pages | medium | mitigate | Nav entries gated by `plugin.manage`/`mcp.manage`; pages show ask-an-admin; API decides every call |
| T-03.1-13-05 | Spoofing | e2e fakes in CI | low | accept | Fake server runs only in the e2e job and the isolated script on loopback; never in compose profiles |
</threat_model>
