## Phase Goal

See `07.8-01-PLAN.md`. **This plan's slice (tracer, browser UI):** a bot's configurer opens the Sandbox tab and previews
a file the bot wrote — then file management and the per-bot switches; then the responsive, dark and accessibility proof.

The UI-SPEC wins on every visual and copy detail (P-02). The UI-SPEC says the tree refreshes on a
`sandbox.files.changed` event; this plan refreshes expanded folders every 10 s while the tab is visible and after each
mutation (same behaviour for the person, no new agent-scoped realtime topic); a changed open file shows "This file
changed. Reload" exactly as specified.

<objective>
Build the bot page's Sandbox tab (status card, tree, preview, upload, download, delete, stop, restart), extract the 07.2
tree row into `TreeRowView`, add the Capabilities panel's Sandbox and Browser rows, and prove them in the browser.

Purpose: SBX-05 (files from the bot page); D-04, D-12 (per-bot switch), R4, R11; C-03.
Output: `components/sandbox/*`, `components/common/tree-row.tsx`, agent page tab, capabilities rows, queries, e2e spec.
</objective>
