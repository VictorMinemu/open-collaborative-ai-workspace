# Phase 07.16 Plan 14: Real-cell smoke `bot_work_sessions` Summary

**New real-cell smoke scenario `bot_work_sessions`. In a real OpenClaw cell the bot starts and reads a Work Zone session with the turn's ids only. A tainted start goes to its route, which answers with a proposal. After a read, every other side-effecting tool is blocked except the session prompt. A wake-up event is answered on the session's card. A leak sweep checks model requests and the cell log. The scenario has not run yet: it runs only on the PR's cell-smoke CI (PD-24).**

## Deviations from Plan

**1. [Interpretation] The read answer comes from the knob, not from a new default.**
- **Found during:** Task 1
- **Issue:** The plan asks for a default read answer with one output text and one changed file. But `work-session-tools.test.ts` (plan 08) checks that the default read says "No new output.", so changing the default would break an existing test.
- **Fix:** The scenario sets that read answer through the existing `POST /__test/work-sessions {answers: {read}}`. The fake's default read is unchanged.
- **Committed in:** 59a6576e

**2. [Interpretation] No `/__test/publish` route.**
- **Found during:** Task 2
- **Issue:** The plan says to add one "if none exists". `POST /__test/event` (`{type, data}` → `publish`) already exists, and the automation and consult scenarios use it.
- **Fix:** The wake-up goes through `inject_and_wait <file> <card> /__test/event`. Task 2 did not change the fake API.

**3. [Rule 2 - Missing critical] The leak canaries ride in fields outside the contracts.**
- **Found during:** Task 2
- **Issue:** The plan's leak sweep looks for "the fixture's person prompt marker", but no contract field carries a person's prompt. A sweep for a value that never enters the cell would always pass, whatever the plugin does.
- **Fix:** The marker and a `/Users/…` host path ride in fields outside the contracts, in both the read answer and the wake event. I checked locally that the plugin mirror's parse drops them: with tsx, the read render and `mapWorkSessionEvent` contain no marker and no host path.
- **Committed in:** 546b4d7e
