## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page frames → viewer DOM | Untrusted images, rendered as images only |
| person's keyboard → remote page | Typed secrets must go only to the live-view socket |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.8-22-01 | Information disclosure | another viewer seeing a sign-in | critical | mitigate | Server privacy (16) + UI acceptance test with zero binary frames (Task 3) |
| T-07.8-22-02 | Information disclosure | typed secrets in DOM, console or other requests | critical | mitigate | Listeners only while controlling; sentinel sweep in the browser (Task 3) |
| T-07.8-22-03 | Spoofing | typing into the wrong site | medium | mitigate | Host chip always visible; "Now on {host}" announcement on host change (Task 2) |
| T-07.8-22-04 | Denial of service | memory growth from frames | low | mitigate | Blob URL revocation, latest-frame rendering, perf check (Tasks 1, 3) |
</threat_model>
