## Phase Goal

Any engineering team can install, upgrade, back up, observe and expose an MVP 1 instance with one command each, and
the MVP 1 acceptance scenario runs against that exact stack (user story and plan map: 07-01-PLAN.md).

**This plan's slice (phase tracer, stack level):** the full compose stack has not run on real images since Phase 1
(A5). First build every image under a unique tag and boot the whole stack in an isolated project, then lock in the
compose contract the rest of the phase builds on. Executor rules (D-11, D-12) as in 07-01; this plan writes the guard
that enforces them, so it is written and tested before anything is started.

    export function assertSafe({ project, envFile, imageTag, ports });  // throws naming the violation: project not ^ocw-(gate|cleanroom)-, a DEMO port, tag "local", an env file outside os.tmpdir()
    //   (so a checkout's .env, .env.demo and ~/.ocw-demo are refused by path, without reading them; gate env files and clean-room clones live in tmp)
    export function acquireLock(file = "/tmp/ocw-gate.lock", { timeoutMs = 60 * 60_000 } = {});  // fs.openSync "wx" + PID; waits (bounded) while held, reclaims a dead PID; returns release()
    export function createGateEnv({ dir, runId, block, imageTag, extra });  // <dir>/.env (0600): fresh secrets via scripts/setup-env.mjs --dir, then every port key of the block
    //   (web, api, postgres, redis, s3, grafana, proxy https/http) and matching public URLs,
    //   OCW_IMAGE_TAG, COMPOSE_PROJECT_NAME=ocw-gate-<runId>, COMPOSE_FILE=compose.yaml:compose.e2e.yaml, COMPOSE_PROFILES (from extra), OCW_MODEL_PROVIDER=mock
    export function composeCmd(ctx, args, opts);  // docker compose --project-directory <repo> --env-file ctx.envFile -p ctx.project [...] args (assertSafe first)
    export async function withGateStack({ runId, profiles = [], keep = false, attachEnvFile, build = true }, fn);
    //   lock → env → build (OCW_IMAGE_TAG=gate-<sha>[-dirty]) → up -d --wait → fn(ctx) → down -v --remove-orphans + rmi ocw-*:<tag> (unless keep) → release lock
    //   ctx = { project, envFile, dir, imageTag, ports, urls: { web, api, s3, public }, env /* parsed; never printed */, compose(args, opts), psql(sql) /* superuser in this project's postgres */ }
    //   urls.web/api/s3 are always the direct loopback URLs (http://127.0.0.1:34xx); urls.public is OCW_PUBLIC_WEB_URL (the Caddy origin once the proxy is enabled);
    //   ctx.reload() re-reads env and urls after an `ocw enable …` changed the env file
    export async function ensureAdmin(ctx);  // first-run setup through the API with the env's setup token if not done yet, else sign in;
    //   credentials = e2e/tests/env.ts ADMIN defaults (admin@ocw.test), so Playwright's setup spec and the steps share one admin

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-03-01 | Denial of service | gate overwriting the demo's images, ports, project or volumes | high | mitigate | `assertSafe` before every call, unique project/tag/ports, lock, scoped teardown, before/after image-id diff (Task 1) |
