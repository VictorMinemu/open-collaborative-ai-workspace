## Deviations from Plan

1. **[Rule 2] E2E spec added.** The plan had no spec of its own. Visual verification was required at 1440 and 390,
   light and dark, with axe, so the new `e2e/tests/work-zone-visibility-marker.spec.ts` covers it. The audience is set
   with the guarded `asSuperuser`, because the visibility API (06) and its UI (10) are not merged yet.
2. **Component tests live in one file.** The sidebar and home row tests are in `visibility-marker.test.tsx`. To render
   them as static markup, `ActiveRow`, `SettledRow`, `rowProject` and `orderActiveSessions` (sidebar) and
   `RecentSessionRow` (home) are now exported.
3. **Extra helpers for plan 10.** The library adds `sessionLabels`, `chipName` and `inactiveLine`, beyond the interface
   list, for 10 to reuse.
4. **Routing fix (R8) not done here.** The hub assigns `app/(app)/work-zone/layout.tsx` and R8 to 07.9-11, and 09's
   plan does not list it. It was left to 11 to respect ownership.
5. **TDD gates.** Task 1 had a real RED (the module was missing). Each task is a single `feat` commit, because the repo
   requires `pnpm verify` green before every commit. Task 2's RED was not run separately.
