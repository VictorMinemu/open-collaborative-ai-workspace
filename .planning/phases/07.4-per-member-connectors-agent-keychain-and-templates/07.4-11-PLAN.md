## Phase Goal

Agent tool calls to a connector use the requesting member's credential and default to DMs; keys are used by handle and
never seen by the model (plan map and executor rules: 07.4-01-PLAN.md).

**This plan's slice (tracer, keychain request end to end):** a DM turn offers `ocw_http_request`, the route resolves
Víctor's key by handle for his bot, injects it towards the fake's `/kc/whoami` through the guard and returns the answer
with the secret redacted, audited `secret.used`; then the audience rule and connector tool offering in turns; then
the proxy's refusals, redirects, caps and the shared claim. Plan mode first (CLAUDE.md: permissions, policy, audit,
D-06).

<objective>
Decide, per turn and per call, which member-account tools an agent may use where, and give the cell a keychain proxy
route that injects secrets only towards allowed hosts and audits every use without the value.

Purpose: CONN-03 (audience rule, connector offering), CONN-05 (keychain proxy), SC2/SC3; D-03, D-04, D-07.
Output: turn-policy changes, `claim.ts` extraction, `http-requests.ts` route + tests, turn tests.
</objective>
