## Sampling Rate

- **After every task commit:** the task's quick command (per task below).
- **After every plan:** `pnpm verify` (+ `pnpm typecheck --force` after a contract change); sandboxd plans also run their smoke; UI plans run their isolated e2e spec on both projects.
- **After every wave:** `pnpm verify` on the merged wave; W2+ also the sandbox smoke; W4+ also the stack smoke.
- **Phase gate (07.8-29):** everything in Test Infrastructure on one fresh stack, plus the Woodpecker pipelines.
- **Max feedback latency:** one task's quick command (< 120 s for unit/web/node, < 300 s for one integration file or one smoke section).
