## Deviations from Plan

1. **[Rule 1] Caret after a chip** (in `0632879`). The caret is set in a layout effect, not in rAF, so text typed right after a chip lands after the token.
2. **[Rule 1] Picker clearing note** (`c673233`). The chosen template stays listed while the next unit's list loads, so the clear-and-explain decision is made on the real answer.
3. **[Rule 2, a11y] Unique accessible names.** Editor rows use `Field {n} label`, `Column {n} name`, `Type of {label}`, `Category of {name}` and `When a card enters {name}`. The visible UI-SPEC labels are not repeated per row.
4. **[Scope] Organization-wide templates can be edited from any unit page by `unit.manage` holders.** The UI-SPEC says "managers see New / Edit / Delete on own rows only", but an organization-wide template has no unit page of its own and would otherwise be uneditable. Dana, a lead, sees no menu on it, and the e2e asserts that. The API decides (`unit.manage` on the organization, 07.1-07).
5. **[UI-SPEC, minor] Copy not given by the UI-SPEC:**
   - `Give the field a label`
   - `Give the column a name` (from Column settings)
   - `Add a prefix to use {prefix} or {seq}`
   - `Options must be unique`
   - the empty Fields hint `No fields. Cards then ask only for a title and a description.`
   - the read-only scope text when editing

   The field key shows under the label input (`key: customer`), not inline, so the label keeps its width.
6. **[Test] Dark axe on the editor covers the header and body, not the footer** (see open item 1). Light covers the whole dialog.
7. **[Test helper] The spec's `pick()` retries opening a Base UI select** until the option is visible (the layout-shift race above). The shared helpers in `e2e/support/` are unchanged.
8. **[Spec data] Dana is `dana.cole@ocw.test`** (Team Lead). `dana@ocw.test` already exists as a Developer in `bots.spec.ts`, and a Developer cannot lead a unit.

## Open items

1. **Dark primary buttons fail WCAG AA contrast app-wide.** White text on `--primary` oklch(0.64 0.19 278) (≈ #7c7cf8) measures 3.44:1, and 4.5:1 is required. axe flags every enabled primary button in dark: `Create template` / `Save template` here, and `New card`, `Create channel` and others elsewhere. 07.1-08's dark axe passes only because the buttons it scans were disabled or outside the selector. The fix is a token decision for `globals.css`, either a darker dark `--primary` or a dark `--primary-foreground`. It changes the accent everywhere, so it is left for 07.1-14 or a design pass, not done here.
2. **The live board does not update when a template changes.** Templates have no realtime event, so two editors only meet at the 409 on save. That is enough for D-06; a `record_templates.updated` event could come later.
3. **The field type change keeps options.** Switching Choice → Text keeps the typed options in the draft but does not send them. Switching back restores them. This is intentional.
