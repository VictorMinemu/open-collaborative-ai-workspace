## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (`unit` project: sandboxd with the fake Docker, openclaw-channel); `node --test` (guard); Python stdlib `unittest` inside the `sbx` image (toolkit, venv, `ocw-extract`, batch); bash real-Docker smokes (sandboxd as a host process) |
| **Config file** | root `vitest.config.ts`; no Python config (stdlib); `infra/sandbox/test/run-sbx-image-tests.sh`; `infra/sandbox/test/run-sandbox-smoke.sh` |
| **Quick run command** | `pnpm exec vitest run --project unit <file>` · `node --test scripts/guard/guard.test.mjs` |
| **Image tests** | `sh infra/sandbox/test/run-sbx-image-tests.sh <image>` (CI: images workflow step `sandbox-sbx-tests` on `ocw-sandbox-sbx:ci`) |
| **Smoke command** | `bash infra/sandbox/test/run-sandbox-smoke.sh` (CI `sandbox-smoke`, runc, every section) and `--only core,docs` (CI `gvisor-smoke`) |
| **Full suite command** | `pnpm verify` (CI) |
| **Estimated runtime** | unit file ~10 s; guard tests ~20 s; image tests ~3–6 min (LibreOffice and OCR); docs smoke ~5–8 min runc, longer under gVisor |

Local rule (hub PD-03): unit, guard, typecheck and Biome always; the image tests and smokes only when `df -h /` shows
≥ 20 GiB free, with a dedicated buildx builder or the smoke's own labelled images, everything removed afterwards and
`docker system df` recorded. CI is the authority for the image, runc and gVisor. No test touches the network; the
only networked step is `tools/lock.sh` (dev-time, never CI). Nothing touches the owner's demo (`t3code-81d72154`,
`:local` images) or `ocw.autofy.ing`.

---

## Sampling Rate

- **After every task commit:** the task's vitest or `node --test` files; the image tests when a local image exists.
- **After every plan wave:** `pnpm lint && pnpm guard && pnpm typecheck && pnpm exec vitest run --project unit`
  locally, then the PR's images and sandbox workflows.
- **Before `/gsd-verify-work`:** every workflow green on the final tree (07 T3).
- **Max feedback latency:** 60 seconds locally (unit); one CI images run (~15 min) for image-level feedback.
