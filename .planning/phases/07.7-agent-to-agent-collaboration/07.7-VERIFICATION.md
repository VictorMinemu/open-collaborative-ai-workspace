**Advisory (RESOLVED in `4a480444`, CR-A-01 follow-up "late taint"; was a WARNING, not a gap).**
- **The rule:** a return turn's starting taint is a snapshot taken when the reply is delivered. It is the union of the
  asking turn and the answering turns (`deliverConsultReply`, CR-A-01 fix).
- **The edge:** the target can answer while the asking turn T0 is still running, and T0 can then read untrusted
  content afterwards. In that case the asker's return turn was already delivered untainted. It resumes the same
  per-thread OpenClaw session (`threadSessionKey`), and the plugin's guard is per turn (`beginTurn({tainted})`).
- **The impact:** a narrow race could start a continuation untainted that has seen T0's later content.
- **Resolved (`4a480444`):** the taint is propagated where it is set rather than re-read at the return turn's claim.
  When a claim taints a turn (`claimToolCall` for `/tool-calls`, `/http-requests` and `/connectors/*`, and the sandbox
  claim), `taintReturnTurns` in `claim.ts` also taints every not-yet-finished return turn of a consult that turn asked.
  It does the same, transitively, for the return turns of consults those asked. It is one recursive statement, scoped
  to the turn's chain and bounded by the largest hop budget. Every side-effecting route (`/tool-calls`,
  `/connectors/call`, `/http-requests`, `/consultations`, memory, board, sandbox) claims against `agent_turns.tainted`,
  so the server alone enforces it. The cell's per-turn guard needs no new signal, because its local block only saves a
  round trip. Pinned by three `chains.int` tests in "CR-A-01 follow-up: … (late taint)". The first is the direct case:
  the asking turn is live, the answer is delivered untainted, the asking turn reads the web, and the return turn's
  consult and side-effecting call are refused `tainted`. The second is the transitive case. The third checks that a
  finished return turn and other chains' turns are left alone.
- **Context:** the same per-turn model already applies to a human re-mention during a running turn. The 07.7 tests pin
  the case where T0 is already tainted before delivery ("CR-A-01: Archie's own turn read outside content after
  asking"). No roadmap criterion depends on this edge.
