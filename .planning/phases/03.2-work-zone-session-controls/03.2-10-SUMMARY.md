# Phase 03.2 Plan 10: Session screen per ref-4 Summary

The Work Zone session screen now follows `reference/ref-4-layout.png` with today's data only: a sidebar of rich session rows (project badge and name, "Working 12s" / "Needs approval", title, branch, "+N" diff stat, runtime mark), a collapsible "Settled" group with "Show N more" and a search box. The header is a breadcrumb with a persistent Full access badge. The centered stream collapses each finished turn behind "Worked for Xm Ys ›" with tool calls grouped, keeps the final answer visible with its time and a copy button, and closes the latest turn with a "N changed files +a −b · Open diff" card. A "1 agent working · View · Stop" bar floats above the composer, and a Local/Worktree · device · diff stat · branch strip sits under it.

## What was built

- **Sidebar (Task 1, `session-sidebar.tsx`):** active rows sorted by project, then by recency. Elapsed time comes from `runningSince` and ticks every second while a turn is under a minute old, otherwise every 30 s. "Needs approval" replaces the old "Needs attention" group (`data-tone="warning"`). Settled rows are one line: badge, title, diff stat and time. A failed session's time shows in red, with the status in the title attribute. The per-project "+" moved onto the project badge (on hover or focus). The Devices link and every existing test id are kept. New test ids: `session-search`, `settled-group`, `settled-toggle`, `settled-more`, `row-project`, `row-project-badge`, `row-status`, `row-title`, `row-branch`, `row-diffstat`.
- **Header and stream (Task 2):**
  - **Header:** a borderless breadcrumb `[LA] project / title`, stacked on a phone. `FullAccessBadge` sits on the right on desktop and on the project line on a phone; it renders once, chosen by media query. Next to it are viewers, absent participants, the status chip, Queue/Changes icon toggles with counts, and the ⋯ archive menu.
  - **`groupTurns`:** a pure function that builds one turn per `prompt.started` … `prompt.completed`. Live text joins the open turn, and prompts that have not started stay loose. Duration runs from the prompt's `dispatchedAt` to its `completedAt`, falling back to the event times.
  - **Turn layout:** a finished turn shows the prompt bubble (right-aligned, author name, time and avatar), then `TurnSummary` (with " · Interrupted" or " · Turn failed" when relevant, and the tokens inside), then any errors, which stay visible, then the final message, the `ChangesCard` (latest finished turn only) and the copy + HH:MM footer. The running turn is never collapsed, and its tool groups open by default.
  - **`ChangesCard`:** rolls changes up by top-level folder, with expand all, per-folder files and "Open diff". On reload the folder rows come from the same `useDiff` query the panel uses, fetched only when `diffStat` reports files.
- **Agent bar, footer and inventory (Task 3):**
  - **`AgentBar`:** shows "1 agent working" or "Waiting for approval" (or "1 agent starting") with a pulsing dot. View scrolls to `[data-turn-running]`. Stop carries `data-testid="interrupt"` and the same `useInterrupt` mutation.
  - **`SessionFooter`:** shows Local or Worktree, the device with its online dot (the tooltip names the subscription), the diff stat (`footer-diffstat`) and the branch. The branch keeps its width on 390.
  - **Composer:** takes `above` / `below` slots. The busy-state stop button was removed (it moved to the bar). The hint line now appears only when something is notable (device offline, prompt will queue, or settings pending on a phone).
  - **Inventory:** every exposed `workzone-ui` row names its component file and test id. The deferred rows are `ui.header.actions`, `ui.stream.subagents`, `ui.composer.attach` and `ui.minimap`, each with the reason the plan specified. A new unit test enforces both.

## Deviations from Plan

1. **Screenshot prefix:** `wz-session-*` (orchestrator instruction) instead of `wz-layout-*`. There are 20 captures (sidebar, sidebar-active, stream, diff, idle, running × sizes × themes), so the acceptance `grep -c "^wz-layout-" ≥ 12` reads 0 by name and is met by the `wz-session-` set.
2. **[Rule 3] e2e support `FakeDeviceHandle.shutdown()`:** settled sessions need an ended (completed) status without revoking the device, because a revoked host hides its sessions. A graceful SIGTERM makes the fake runtimes report every session as ended.
3. **Full-access spec extended:** Sam (a second controller) sees `full-access-badge` in the header (the plan's Task 2 behaviour). The old `session-full-access` test id became `full-access-badge`; no spec used the old one.

5. **Extra inventory rows:** `ui.sidebar.search`, `ui.sidebar.settled` and `ui.stream.message-footer` (built elements need rows), each with evidence.
6. **Stop gated by `work_session.interrupt`:** per threat T-03.2-10-04.
