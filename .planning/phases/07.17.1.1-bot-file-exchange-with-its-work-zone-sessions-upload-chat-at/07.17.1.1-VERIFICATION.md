# Phase 07.17.1.1: Bot file exchange with its Work Zone sessions — Verification Report

**Phase Goal:** A bot that started a Work Zone session moves files between that session and the conversation it started
it from: it uploads an attachment of the thread into the session's working tree and downloads a file of the session back
to the conversation as an attachment people open and download, each bounded by a per-file limit the organization and the
bot's profile configure (the lower wins), decided server-side, audited, and never sending an absolute path.
