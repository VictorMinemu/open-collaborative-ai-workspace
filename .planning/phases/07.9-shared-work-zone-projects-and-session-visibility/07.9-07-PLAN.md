## Phase Goal

See `07.9-01-PLAN.md`. **This plan's slice:** close the D-08 leak — session data reaches only the people who may see the
session, live and unstored — and make every narrowing take effect live with a reason the access-lost view can show.

<objective>
Replace the `org:` session broadcast with per-user after-commit delivery (D-08, P-08), prove it with the sentinel (D-08,
D-13 history already blanked by 02), let topic authorizers return a `cause` that the gateway, the realtime client and
the web pass through (D-13, R7), register the `work_project.updated` invalidator and the device-grant invalidation
(P-09), and move the web list to `user:` delivery.

Purpose: WZP-06 (no leak over any socket), WZP-07 (live re-authorization on narrowing).
Output: the fan-out, the sentinel, the cause plumbing, the invalidators, the web list sync.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → `org:` topic | Readable by every member (`org.read`), Work Zone on or off |
| API → `user:` topic | One person's private stream |
| access change → live subscriptions | Standing reads that must be re-decided |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.9-07-01 | Information disclosure | session DTOs on `org:` (live and replay) | high | mitigate | No `org:` append; per-user delivery to resolver-allowed people; sentinel scans all frames and replay (Tasks 1–2) |
| T-07.9-07-02 | Information disclosure | stale live views after narrowing | high | mitigate | Invalidators for project and device changes; `ws:` re-decided within 1 s (Task 3) |
| T-07.9-07-03 | Denial of service | lock-order deadlocks from per-user durable appends | medium | mitigate | Ephemeral after-commit delivery only (P-08) |
| T-07.9-07-04 | Information disclosure | names in revoke frames | low | mitigate | `cause` is a code from `RevokeCause` (Task 3) |
| T-07.9-07-05 | Tampering | a missed ephemeral frame leaves a stale row | low | accept | Refetch on org access events and reconnect; the row can only be one the person may see |
</threat_model>
