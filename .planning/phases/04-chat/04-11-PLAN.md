## Phase Goal

**As a** member of a team that works in the workspace, **I want to** hold my whole daily conversation there — channels grouped by department and team, DMs and group DMs with people and bots, messages I can edit, delete, react to, pin, save and link to, @channel/@here and notifications I control, search and files — **so that** I do not need a second chat tool and every message stays attributed, editable under audit and delivered in realtime.

**This plan's slice (tracer):** Sam mutes #design; Ada's next message there produces no pop-up and no unread count, while a mention still lands in his inbox and badge; unmuted, a mention pops a real Web Notification (prefs API → server popup decision → `user:` event → OsNotifier → browser). Planner decisions P-01 … P-12 are in `04-01-PLAN.md` (P-04, P-08, P-09, P-12).

<objective>
Give members notification preferences — per-conversation level and mute, do-not-disturb, default level, desktop and web toggles — honoured by the inbox, the badges and the pop-ups, and show pop-ups through the Web Notifications API in the browser and the Electron app while it runs, with a title count and a dock badge.

Purpose: CHAT-10 with D-02 (no closed-tab Web Push).
Output: prefs API, per-conversation settings API, level-all ephemeral events, OsNotifier, Settings › Notifications, notify menu levels/mute, user-menu pause, desktop badge IPC, `prefs.int.test.ts`, `e2e/tests/notification-prefs.spec.ts`.
</objective>
