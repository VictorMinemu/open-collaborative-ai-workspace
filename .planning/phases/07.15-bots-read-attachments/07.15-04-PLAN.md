## Phase Goal

See `07.15-01-PLAN.md`. **This plan's slice:** the bot read layer inside the artifact module: what kind a stored file
is, how its text is decoded and capped, which image bytes a model gets, and the untrusted block, all from the store
with server credentials (ADR-0015), never executing the file. 05 adds PDF text to the same entry point.

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.15-04-01 | Denial of service | huge text files | medium | mitigate | `rangeGet` of 256 KiB, never the whole object; code-unit cap; test asserts no `stream` call on the text path |
| T-07.15-04-02 | Elevation of privilege | active content (SVG, HTML, JS) | high | mitigate | Classified as text and returned as text; nothing is rendered, evaluated or executed (P3) |
| T-07.15-04-03 | Denial of service | image bombs | medium | mitigate | Only the upload-time rendition (≤ 2048 px) or an original ≤ 5 MiB; no decode at read time |
| T-07.15-04-04 | Information disclosure | parser or store messages echoing file text into logs | medium | mitigate | Errors mapped to fixed codes; `err.name` only; acceptance grep refuses `.message` in read.ts |
| T-07.15-04-05 | Tampering | file content closing the untrusted delimiter | high | mitigate | The moved `untrustedFileBlock` neutralises the delimiter (T-05-12-06), one definition for AI chats and bots |
</threat_model>
