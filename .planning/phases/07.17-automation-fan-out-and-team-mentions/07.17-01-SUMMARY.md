## Decisions Made

- `*/N * * * *` reads "Every N minutes" only when N divides 60. A cron step restarts at :00, so `*/7` actually fires at :56 and then again at :00, and wording it "Every 7 minutes" would be wrong. The editor presets (5, 10, 15, 30) are all covered.
- In the plugin mirror, `code` and per-item `refused` are snake_case strings, not enums. This is the 07.16 `BotWorkSessionRefused` rule: an unknown code from a newer API still parses, so its sentence reaches the model. The contracts copy stays a strict enum. Every known variant parses identically in both copies (tested).
