## Phase Goal

See `07.16-01-PLAN.md` (PD-17, E16). **This plan's slice:** which turns get the four tools and the Work Zone context, decided
server-side at delivery, with bots without a profile untouched.

<objective>
Add `workZoneOfferFor` (profile active + the asker's module gate → a `TurnWorkZone`), compute it per delivered bot in
`buildMentionEvents` for mention and reply-mode deliveries, and let `turnPolicy` add the four turn-scoped tools and
`turn.workZone` when it is given one; prove the matrix and BWZ-06's byte-identity (D-05, D-21, PD-17).

Purpose: the tools exist exactly when they can be used; nothing changes for other bots.
Output: one new work-session module file, the turn policy and mention changes, one new and one extended integration file.
</objective>
