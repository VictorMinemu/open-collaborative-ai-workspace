# Phase 03.2 Plan 09: Reference composer controls Summary

The composer now matches the owner's reference: a model chip opening a picker with search, favorites, a provider rail, ⌘1–⌘5 and "Legacy models"; a "Reasoning · Context" chip opening Reasoning / Context Window / Fast Mode with Default tags; a permission chip opening Supervised / Auto-accept edits / Auto / Full access (+ Plan) with descriptions. Every option comes from the server's controls, refused ones explain why, unconfirmed ones never show, and on a 390 px screen each menu is a bottom sheet. The New session dialog is driven by the chosen device's catalog.

## What was built

- **Contract fix (ed12c47):** `RuntimeModel.resolvedModel` / `ModelControl.resolvedModel`, filled by `buildClaudeCatalog` from `initializationResult`, passed through by the API. The web's `matchModel` maps an effective id (`claude-sonnet-5-5`) back to its alias row (`sonnet`).
- **Model picker (Task 1, ref-3 content = `reference/ref-2.png`):**
  - Rail: favorites star, both runtimes; the other runtime shows its models disabled under "Switching provider inside a chat is not available yet".
  - Search box (`model-search`), rows with name, NEW badge only for `badge === "new"`, provider sub-label or reason, ⌘/Ctrl 1–5 hints (desktop), star toggle (`model-favorite`, `localStorage` `ocw.wz.favorite-models`, per runtime, live across pickers).
  - "Legacy models · N models" row (`legacy-models`) that expands; arrow keys, Enter, ⌘/Ctrl+1–5.
  - Substitution note when the device runs another model than requested.
- **Reasoning menu (Task 2, ref-2 content = `reference/ref-3.png`):** efforts the model reports (labels Low … Max, Default tag), 200k/1M only when the model offers both, otherwise a read-only "1M · Fixed for this model" line; Fast Mode On/Off with the policy/runtime reason and the runtime's cost line. Chip hidden for models with nothing to choose (Haiku).
- **Permission menu (Task 2, ref-1):** five modes in reference order + Plan after a divider, icons, descriptions, reason text for disabled rows; Full access icon in the warning tone. The chip turns warning-tone with an open lock in Full access (D-04); the session header shows a "Full access" badge instead of the raw `fullAccess` (03.2-06 open item).
- **Composer:** ref-1 bar (model | reasoning | permission … attach, interrupt, send), attach disabled with "Attachments arrive with file uploads" (inventory: deferred), "Applies to the next turn" marker (`settings-pending`), hint moved under the card. Phone layout: two rows.
- **New session dialog (Task 3):** `useRuntimeControls(deviceId, runtime)`; model select = Default + the catalog's available models; effort select when the chosen model has efforts; five mode cards with descriptions and reasons (`mode-<value>` kept); runtime/project switch reloads and resets unavailable choices; request sends model, permissionMode, effort. The static `RUNTIMES[...].models` list is gone.
- **controls-exposed.int.test.ts:** final statuses hard-coded from the 03.2-02 / 03.2-03 SUMMARYs (`claude-code/effort`, `claude-code/mode.auto`, `codex/mode.auto` = exposed), asserted against `controlStatus`, then GET /controls and PATCH `{effort:"xhigh"}` / `{permissionMode:"auto"}` per runtime.

## Deviations from Plan

1. **Reference file names.** The plan calls the model picker ref-3 and the reasoning menu ref-2; on disk `ref-2.png` is the model picker and `ref-3.png` the reasoning menu. Compared by content.
2. **[Rule 1/2] resolvedModel contract (ed12c47).** Needed to display the effective model consistently (03.2-02 open item); optional, so older catalogs parse.
3. **[Rule 3] Int test setup** marks Codex signed in on the test device via superuser SQL (the FakeDevice hello reports it signed out, and session create refuses an unsigned runtime).
4. **ControlSurface signature** is controlled (`open`, `onOpenChange`) and takes a `ReactElement` trigger, `className` / `sheetClassName`, `initialFocus`; the plan sketched an uncontrolled `ReactNode` trigger.
5. **e2e imports the inventory** by relative path (`packages/contracts/src/runtime-controls/index.ts`) so Auto/effort assertions follow `isExposed`.
6. **Pending marker e2e** waits for the next turn (the fake applies held settings when the next turn starts, D-14), not for the current turn to end.
7. **Extra fixes from earlier SUMMARY open items:** header "Full access" badge (06), toasts on top on phones and no "Queue" label for `/commands` (07), plan-mode substitution note (02).
8. **Screenshots:** plan names plus `wz-composer-*` (orchestrator prefix). The regression runs overwrote other plans' captures; they were restored (Plan 06's two full-access captures, committed by mistake in 0ec2342, restored in 8d3f794).
