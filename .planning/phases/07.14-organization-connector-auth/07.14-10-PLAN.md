## Phase Goal

See `07.14-01-PLAN.md`. **This plan's slice (tracer, automations tier):** watched records (07.6) — the other place the API
calls an organization resource on its own — treat organization-account servers as workspace access with the
organization's token, so D-04's "chains and automations" holds and RESEARCH inventory #28 is closed.

<objective>
Convert `watched/{options,check,write,service}.ts` (RESEARCH #28) to the predicates with an organization-credential read
and write path, map org modes to the watched wire's workspace-access value, and switch the two web watched files to
`isWorkspaceAccess`.

Purpose: without this an org-mode server would silently demand a member share and a member connection, then fail.
Output: the four API files, the two web files, extended watched integration tests.
</objective>
