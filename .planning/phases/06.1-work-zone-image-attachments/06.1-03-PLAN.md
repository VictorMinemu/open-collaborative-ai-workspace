<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| clipboard / drag source → composer | Untrusted files and names from any app or page |
| browser → presign / prompt routes | The server re-checks everything (scope, link, budget, model) |
| stored attachment → other controllers' browsers | Previews served only through the API's access-checked routes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.1-03-01 | Tampering / XSS | filenames and pasted content | medium | mitigate | Names are server-sanitized text rendered as text; only image files from the clipboard are taken; previews are webp renditions from the API routes, never the original or SVG |
| T-06.1-03-02 | Information disclosure | preview URLs shared or cached | medium | mitigate | API-relative URLs that re-check `work_session.read` on every load and redirect to 60 s presigned GETs with `no-store` (06.1-01) |
| T-06.1-03-03 | Elevation of privilege | client-side gate bypassed | low | accept | The gate is UX only; the API refuses the same cases (06.1-01 tests) |
| T-06.1-03-04 | Denial of service | many or huge files added at once | low | mitigate | Four-image cap and the Phase 4 per-file limit checked before upload; non-images never uploaded |
</threat_model>
