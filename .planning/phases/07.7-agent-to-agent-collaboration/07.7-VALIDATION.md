## Sampling Rate

- **After every task commit:** run the task's quick unit, integration, web or `node --test` command (listed per task below).
- **After every plan:** run `pnpm verify`, plus `pnpm typecheck --force` after a contract change. UI plans also run their isolated e2e spec on both projects, and 07.7-07 runs its smoke scenario.
- **After every wave:** run `pnpm verify` on the merged wave.
- **Phase gate (07.7-11):** run the security route table, `pnpm gate:compose --with-sandbox` (with the compose spec), the full suite, the full real-cell smoke (unique prefix), every 07.7 spec plus the regressions on one fresh isolated stack (throwaway `.env`), review the screenshots against the UI contracts, and record Woodpecker from the orchestrator's push.
- **Max feedback latency:** one task's quick command (under 120 s for unit/web, under 300 s for one integration file, under 600 s for one smoke scenario).
