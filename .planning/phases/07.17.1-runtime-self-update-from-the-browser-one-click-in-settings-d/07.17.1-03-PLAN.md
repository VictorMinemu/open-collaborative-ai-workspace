## Phase Goal

See `07.17.1-01-PLAN.md` (hub: PD-06, PD-07, PD-15, PD-16). **This plan's slice:** the workspace serves the one file the
daemon cannot get today (the npm lockfile), the package.json and lockfile checks live once in contracts, and the API knows
what build it serves.

<objective>
Add `RUNTIME_ROUTES.externalLock` and `runtimeExternalFiles` to contracts, serve the lockfile from the verified dist,
lift the dist store into `createDeviceModule` and expose the served build through `DeviceHub.servedRuntime()`, keeping
install.sh byte-identical (D-03).

Purpose: 05's daemon downloads the lockfile and builds byte-identical npm files; 09's route and DTO compare builds.
Output: one route, one contracts helper, one shared store, one test helper, tests.
</objective>
