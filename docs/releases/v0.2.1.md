The desktop app now ships for **Windows and Linux** as well as macOS. The server is the same as in
[`v0.2.0`](https://github.com/VictorMinemu/open-collaborative-ai-workspace/releases/tag/v0.2.0), the first public
release (MVP 1).

## Install the server

On Ubuntu 24.04 or Debian 12, with a DNS name pointing at the server:

```bash
curl -fsSL https://raw.githubusercontent.com/VictorMinemu/open-collaborative-ai-workspace/main/scripts/install.sh \
  | sudo bash -s -- --domain ocw.your-company.com
```

The installer installs this release (`v0.2.1`). The [README tutorial](https://github.com/VictorMinemu/open-collaborative-ai-workspace#install-it-on-a-server)
walks through the first admin, model providers, invites and what to try first.

**Upgrade** from `v0.2.0` with `sudo node scripts/ocw.mjs upgrade` in `/opt/ocw`. It backs up first and never goes
backwards.

## Desktop app

None of the builds is signed yet, so the first launch needs one extra step:

- **macOS** (Apple silicon): open `OCW-v0.2.1-macos-arm64.dmg` and drag OCW to Applications. Open it once, then go to
  **System Settings › Privacy & Security** and choose **Open Anyway** (or run
  `xattr -dr com.apple.quarantine /Applications/OCW.app`).
- **Windows** (x64): run `OCW-v0.2.1-windows-x64-setup.exe`. If SmartScreen stops it, choose **More info › Run
  anyway**. It installs for the current user, without admin rights.
- **Linux** (x64): on Ubuntu or Debian, `sudo apt install ./OCW-v0.2.1-linux-amd64.deb`. Elsewhere,
  `chmod +x OCW-v0.2.1-linux-x86_64.AppImage` and run it. The app keeps the device token in the desktop keyring
  (GNOME Keyring or KWallet), which must be available.

Then enter your workspace URL and pair the computer under **Settings › Devices › Add device › Desktop app**. On a
server without a screen, use the headless runtime instead (**Settings › Devices › Add a device › Server**). Signed
builds are planned for MVP 2.

## Files

| File | What |
| --- | --- |
| `OCW-v0.2.1-macos-arm64.dmg` | Desktop app, macOS on Apple silicon (ad-hoc signed) |
| `OCW-v0.2.1-windows-x64-setup.exe` | Desktop app, Windows x64 installer (unsigned) |
| `OCW-v0.2.1-linux-amd64.deb` | Desktop app, Ubuntu and Debian x64 |
| `OCW-v0.2.1-linux-x86_64.AppImage` | Desktop app, other Linux x64 distributions |
| `install.sh` | The server installer of this release |
| `SHA256SUMS` | Checksums: `sha256sum -c SHA256SUMS` (`shasum -a 256 -c` on macOS) |

## Known limitations

- The Windows and Linux builds are new in this release and were checked only in CI (build and bundled runtime start).
  Please report anything that does not work on your machine.
- Bots cannot read attachments yet.
- Claude works only through an org API key.

The full list is in the [README](https://github.com/VictorMinemu/open-collaborative-ai-workspace#known-limitations).
Report problems as [issues](https://github.com/VictorMinemu/open-collaborative-ai-workspace/issues), and security
problems privately ([SECURITY.md](https://github.com/VictorMinemu/open-collaborative-ai-workspace/blob/main/SECURITY.md)).
