# Phase 07.2 Plan 01: Scoped memory and approval contracts Summary

This plan adds the memory path grammar to `packages/contracts`, plus the DTOs, the three memory grains, a Memory module, the generic approve-and-apply contract, platform-owned card fields, the Agent Channel memory tools, the turn's `memoryFiles` and folder rules. Every new field is optional or defaulted, so older payloads still parse.

## What was built

- **Paths (MEM-01, D-01).** `parseMemoryPath` normalises to NFC first and then validates. It rejects bad input and never repairs it, returning the first failing reason. The order of checks is:
  1. empty
  2. control (Unicode Cc/Cf, which covers NUL, LF and bidi overrides)
  3. absolute
  4. backslash
  5. any `%`
  6. trailing slash
  7. per segment: empty, dot-only, edge space, charset `[\p{L}\p{N} ._-]`, more than 64 code points
  8. depth over 8
  9. length over 255 code points
  10. a name that does not end in lowercase `.md`, or has nothing before it
- **Folders.** `parseMemoryFolder` uses the same grammar, must end in `/` (`missing_slash` otherwise) and allows at most 7 segments.
- **Matching.** `isUnderFolder` compares lowercase NFC keys on segment boundaries. A folder passed without its trailing `/` is read as if it had one. `memoryPathKey` is the uniqueness key.
- **Content limits** count UTF-8 bytes with `TextEncoder`: `MemoryContent` allows 256 KiB and `TurnMemoryFile.content` 8 KiB.
- **Grains.** `memory.read` is held by every role through STANDARD. `memory.write` and `memory.promote` are held by admins and by unit leads (`LEAD_PERMISSIONS`). Agents can hold read and write, never promote. None of the three is non-delegable.
- **Memory module.** The module catalog has a `memory` entry with pattern `memory.*` and entry grain `memory.read`.
- **Approvals (MEM-06, D-05, D-08).** This is the generic contract: two modes, a 64-hex action hash required on every decision, and an optional trimmed plain-text note of at most 280 characters. A detail's view is either `memory_proposal` (which must include `spans`) or a generic `fields` view of up to 12 fields.
- **Findings (MEM-05).** `SensitiveFinding` holds at most 3 samples and 20 lines. `SensitiveSpan` requires `end > start`.
- **`maskSample`** masks each kind of value differently. If the masked output would still contain the raw value, it returns `••••` instead.
- **Agent Channel (D-02).** The four memory request schemas are strict objects, so a `userId` or `ownerUserId` field is refused. `write` accepts only the scopes `personal` and `agent`. Each response is either a result or one of 17 named refusals.
