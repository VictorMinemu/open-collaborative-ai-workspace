See `07.16-01-PLAN.md` (PD-07, PD-08, PD-09, PD-23). **This plan's slice:** the agent layer in the one controls context
and the agent option of the one session start, so start, settings, the per-turn arbiter (10) and re-authorization (10)
all apply the bot's caps through the same functions, with human paths untouched.

D-08, D-18, PD-07, PD-08, PD-09).

Output: context and controls changes with a unit matrix, the start option, the queue option, one integration file.
</objective>
