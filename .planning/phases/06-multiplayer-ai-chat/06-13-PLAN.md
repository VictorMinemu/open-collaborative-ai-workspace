## Phase Goal

**As a** member who holds a private AI chat, **I want to** share it in place with a colleague, a team, a department or the whole organization so that several of us and the model write in the same conversation — the model knowing who said what and answering one request at a time on the asker's own plan or model, nobody's private context leaking, and agents joining as full personas that post live cards — **so that** AI work in the workspace becomes multiplayer, attributable and safe.

**This plan's slice:** Agent Cards on the server — the Agent Channel routes agents use, the human actions, the live in-place updates and the action delivery back to the agent. The cell tool is 06-14, the renderer 06-15. P-decisions: `06-01-PLAN.md` (P-11).

<objective>
Implement Agent Cards end to end on the API: agents create and update cards through the Agent Channel API, readers follow and decide through `/api/v1`, every change streams as the message's update, followers are notified on status changes and decisions reach the agent.

Purpose: AGENT-04 (D-07; P-11).
Output: Agent Channel card contracts and routes, card storage in the agent post transaction, `withCards` projection in channel/thread/DM and AI chat snapshots, human action routes, `cards.int.test.ts`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cell (Bearer cell token) → `/agent-channel/v1/cards` | Card content is untrusted model output |
| human → `/api/v1/cards/:messageId/*` | Follow and decide decided by the resolver |
| API → cell stream | Decisions delivered as server-generated events |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-13-01 | Spoofing | Open action to an external phishing URL | high | mitigate | `AgentCardRoute` (internal routes only) validated at the Agent Channel boundary; 400 on external targets (Task 1) |
| T-06-13-02 | Tampering | an agent or a human editing another agent's card | high | mitigate | PATCH only with the card's `agent_id` (403), optimistic version (409); no human edit route (Task 1) |
| T-06-13-03 | Elevation of privilege | card decision by someone who cannot read or may not decide; double decision | high | mitigate | `channel.read` hidden 404, `agent_card.approve` (deny-able), `approverIds`, conditional single update (409), audit (Task 2) |
| T-06-13-04 | Information disclosure | card content in other tenants or to non-readers | high | mitigate | Cards follow their message: tenant RLS on `message_cards`/follows, readable-set checks on every route and snapshot (Tasks 1-2) |
| T-06-13-05 | Denial of service | card spam / decision-triggered agent turns | medium | mitigate | Same posting limits as agent messages; card actions go through `turnPolicy` daily limits (Task 2) |
| T-06-13-06 | Tampering | untrusted card text in search or prompts | low | mitigate | Body = plain summary only; card JSON never indexed; renderer (06-15) treats card text as plain text |
</threat_model>
