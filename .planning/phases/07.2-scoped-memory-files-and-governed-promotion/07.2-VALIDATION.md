## Sampling Rate

- **After every task commit:** the task's quick unit / integration / web command (per task below).
- **After every plan:** `pnpm verify` (+ `pnpm typecheck --force` after a contract change); UI plans also run their isolated e2e spec on both projects with screenshots.
- **After every wave:** `pnpm verify` on the merged wave.
- **Phase gate (07.2-15):** full suite + the full isolated e2e on one fresh stack + the extended-scan run + container smoke + compose tests; screenshots reviewed against the UI-SPEC by the owner.
- **Max feedback latency:** one task's quick command (< 120 s for unit/web, < 300 s for one integration file).
