Bots now use every tool of a big MCP server. Before, tools past roughly the hundredth were refused, and every call with
arguments failed.

## What's fixed

- **Every enabled tool of a connector works.** Tools of servers that use a member's or the organization's account
  (connectors) no longer count toward the 128 tools a bot turn can carry: the bot reaches all of them through one tool.
  Before, a big server's tools past roughly the hundredth were dropped from the turn, and the bot answered "that
  connector tool is not allowed on this turn" although the tool was on. Servers that run inside the bot runtime keep the
  128-tool limit of the model providers; the bot sheet says so.
- **Connector calls with arguments work.** Every call that passed arguments failed with "schema is false" (for example
  a search with a filter); only calls without arguments went through.
- **Big connectors stay readable.** The bot lists a connector's tools without their argument schemas when there are
  many, searches them by name or description, and fetches one tool's arguments when it needs them. This also keeps long
  conversations smaller.
- **More tools.** A bot can hold up to 1000 tools (was 200), and a connector's tool list keeps up to 1000 tools (was
  256).

## Upgrade

In `/opt/ocw` (or wherever the server is installed):

```bash
sudo node scripts/ocw.mjs upgrade --check   # current and newest release; changes nothing
sudo node scripts/ocw.mjs upgrade           # backup, this release, new keys, rebuild; never goes backwards
```

- **No migrations.**
- **A connector with more than 256 tools:** in **Settings › MCP servers**, press **Re-probe** on it to list the rest,
  then turn them on for the bot.
- **Headless Work Zone servers** on v0.3.1 or later update their runtime with one click (Settings › Devices › the
  server › Runtime updates › **Update**), or by themselves at the *Automatic* level. Nothing in the runtime changed
  besides its version.

The desktop app does not update itself: install the new files below. Its runtime ships inside it.
