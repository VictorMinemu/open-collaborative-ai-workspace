<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API process → OTLP endpoint | Operator-chosen destination; may be a third party |
| client → API headers | `X-Forwarded-For` is attacker-controlled unless a trusted proxy rewrote it |
| npm registry → api image | New runtime dependencies |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05-01 | Information disclosure | query strings, tokens, prompts in spans/logs | high | mitigate | Redacting exporter, query-free serializer, no AI SDK telemetry; canary tests (Tasks 2, 3) |
| T-07-05-02 | Information disclosure | absolute host paths and argv in the resource | medium | mitigate | `resourceDetectors: []` + explicit resource; asserted absent (Task 2) |
| T-07-05-03 | Spoofing | forged `X-Forwarded-For` evading the sign-in rate limit and forging audit IPs | high | mitigate | `OCW_TRUST_PROXY` default false; 1 hop behind Caddy; int test (Task 3) |
| T-07-05-04 | Denial of service | telemetry failure taking the API down | medium | mitigate | SDK only with an endpoint; errors warn once; closed-port case tested (Task 2) |
| T-07-05-SC | Tampering | npm installs of the OTel set | high | mitigate | Package legitimacy checkpoint before install (Task 1); exact pins; minimumReleaseAge; no install scripts; license check in `pnpm guard` (07-01) |
</threat_model>
