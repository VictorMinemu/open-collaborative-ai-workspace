## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| memory content → browser | File content and paths are untrusted (written by people and approved agents) |
| URL segments → API | Catch-all route segments typed or crafted by anyone |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.2-10-01 | Tampering | XSS through Markdown or file names | high | mitigate | Shared `<Markdown>` without raw HTML, `safeUrl`, names rendered as text; e2e asserts no script/img elements (Task 3) |
| T-07.2-10-02 | Tampering | Crafted URL segments (traversal, encoding) | medium | mitigate | Segments re-joined and re-parsed before any request; the API re-parses too (Task 2; 08) |
| T-07.2-10-03 | Information disclosure | Existence of unreadable files revealed by different errors | medium | mitigate | One not-found state for missing and unreadable (Task 3) |
| T-07.2-10-04 | Information disclosure | Search snippets or scope names from unreadable scopes | high | mitigate | API narrows to readable ids (16); the Select lists only scopes the API returned; e2e with a deny rule and a non-member (Task 3) |
| T-07.2-10-SC | Tampering | npm install of headless-tree | high | mitigate | Blocking legitimacy checkpoint, exact pins, minimumReleaseAge, license guard (Task 1) |
