# Phase 07.17.1.1.1 Plan 03: The toolkit venv and `ocw-extract` Summary

that turns PDFs (OCR'd when scanned), images (AVIF and HEIC included), Word/Excel/PowerPoint/OpenDocument (legacy
formats through LibreOffice), CSV/JSON/XML/HTML, mail and archive listings into bounded UTF-8 text, and reads a whole
folder or archive into a resumable `.txt` mirror in chunks that always end before the 600 s exec limit. All 68 image
tests pass locally as uid 10001 under the bot shell's hardening, with no network (rootfs 1102 MiB of 1300).**

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `COPY --chmod=0644` gave `/opt/ocw-tools` the mode 0644**
- **Found during:** Task 1 GREEN. 10001 could not traverse the folder, so the runner fell back to the system Python.
- **Fix:** `chmod 0755 /opt/ocw-tools` at the start of the venv RUN, with a comment.
- **Commit:** 8cc1ad70

**2. [Rule 1 - Bug] A short text-layer page was replaced by its OCR**
- **Found during:** Task 2. "Informe de facturación 2026" has 24 non-space characters, under the 25 threshold, so
  page 1 of text.pdf came out `(ocr)`.
- **Fix:** a non-empty text layer is kept unless OCR finds `OCR_GAIN_MIN_CHARS` (10) more characters. An empty layer
  always takes the OCR.
- **Commit:** d1b2c7a3

**3. [Rule 1 - Bug] charset-normalizer read Spanish Latin-1 as cp1250 ("Ańo")**
- **Found during:** Task 2. A probe in the image showed the open guess is cp1250 for Spanish and French samples,
  while Western isolation rejects Cyrillic, Greek, Polish and Shift-JIS text, so those fall through to the open
  detection.
- **Fix:** try UTF-8, then `cp_isolation=[cp1252, latin_1, iso8859_15]`, then the open detection.
- **Commit:** d1b2c7a3

**4. [Rule 2 - Missing critical] OOXML DTD refusal, child backstops, signal handling**
- openpyxl and python-pptx are not trusted to refuse entities. Any OOXML part whose first 64 KiB declares a DTD or
  an entity is refused (lol.xlsx exits 7: "declares XML entities or a DTD (refused)").
- Children also get RLIMIT_CPU (timeout + 5 s), RLIMIT_FSIZE (512 MiB, or the archive limit) and PR_SET_PDEATHSIG,
  so a child in its own session cannot outlive a SIGKILLed `ocw-extract` for long. SIGTERM, SIGHUP and SIGINT kill
  the live child groups and unwind the scratch cleanup.
- **Commits:** d1b2c7a3, 8cc1ad70

**5. [Rule 3 - Blocking] 7-Zip lists a .tar.gz as its single inner .tar**
- **Fix:** tar and tar.gz go through the stdlib `tarfile` in a child for listing and extraction (regular files and
  folders only, bad paths and links refused, byte cap). The size watcher and the tree re-check still run around it.
  For tar.gz the archive-level ratio is checked, since tar has no packed sizes.
- **Commit:** 6aa47c5b

**6. [Rule 2] Batch output root guard**
- `--out` equal to the input folder or containing it would put mirror files inside the input, and could overwrite
  an original named `x.pdf.txt`. It is refused with exit 2.
- A top-level `--batch` argument must be a folder or an archive, decided by extension (a `file` step would break the
  budget rule for tiny budgets).
- **Commit:** 6aa47c5b

**7. [Plan text] `test_venv` imports eleven modules, not twelve**
- `xlrd` is out of the must-have import list, following the orchestrator's decision.

**8. [Process] `.dockerignore` added**
- It is not in `files_modified`. It keeps a developer's `__pycache__` out of the root-owned package.
