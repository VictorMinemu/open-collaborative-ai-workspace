## Sampling Rate

- **After every task commit:** the task's quick unit / integration / node:test command (per task below).
- **After every plan:** `pnpm verify` (+ `pnpm typecheck --force` after a contract change); UI plans also run their isolated e2e spec on both projects; 07.4-09 runs the `connectors` smoke.
- **After every wave:** `pnpm verify` on the merged wave.
- **Phase gate (07.4-14):** full suite + every 07.4 spec and the regressions on one fresh isolated stack + the full cell smoke + `node --test infra/fake-model/`; screenshots reviewed against the UI-SPEC.
- **Max feedback latency:** one task's quick command (< 120 s for unit/node:test, < 300 s for one integration file).
