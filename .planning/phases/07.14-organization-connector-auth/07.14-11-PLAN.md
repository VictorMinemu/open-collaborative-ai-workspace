<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query → page | `?connected=`, `?error=`, `?connector=` are attacker-controllable |
| API DTO → page | Server names and account labels are admin- or provider-chosen text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.14-11-01 | Spoofing | a crafted `?error=` banner | medium | mitigate | Only closed codes render (`OrgSignInError` parse), fixed copy; unknown values ignored; ids matched against the loaded list |
| T-07.14-11-02 | Tampering (XSS) | account label / server name | medium | mitigate | Rendered as React text, never HTML; labels already stripped of control characters by the API |
| T-07.14-11-03 | Repudiation | accidental disconnect | low | mitigate | Confirmation with focus on Cancel; audited server-side (07) |
</threat_model>
