## Decisions Made

- The chain test passes `--infilter=Text (encoded):UTF8` so the text import never depends on the locale; the
  OCR output read the two phrases exactly, accents included.
- `COPY` without `--chmod` (the verify greps `COPY policy.xml`); the image test enforces root owner and no
  group/other write, so a checkout with a loose umask would fail loudly.
- `ImageGate` parses `ocw.xcd` with the stdlib ElementTree: it is our own root-owned file in the image, and the system
  Python has no defusedxml.
