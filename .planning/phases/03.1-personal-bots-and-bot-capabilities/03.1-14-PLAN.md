<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stdio MCP server code → sidecar process | Third-party code executes |
| sidecar → cell network | The cell calls the bridge over an internal network |
| npm → sidecar image (build time) | Packages baked into the image |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-14-01 | Elevation of privilege / Information disclosure | stdio server reading gateway secrets and transcripts | high | mitigate | Never inside the gateway container; sidecar has no state volume and no gateway/provider secrets |
| T-03.1-14-02 | Elevation of privilege | container escape or abuse | high | mitigate | Read-only root FS, `cap_drop: ALL`, `no-new-privileges`, non-root user, pids/memory/CPU limits, tmpfs only |
| T-03.1-14-03 | Information disclosure | exfiltration from a compromised stdio server | medium | mitigate | Internal network without egress by default, reachable only by the cell |
| T-03.1-14-04 | Tampering | runtime installs / mutable latest | high | mitigate | Baked, exact-pinned packages from a committed lockfile, `--ignore-scripts`; allowlist file; `npx -y` never used |
| T-03.1-14-05 | Denial of service | process explosion (one child per session) | medium | mitigate | Max 16 sessions, idle reaping, pids limit |
| T-03.1-SC | Tampering | npm installs `@modelcontextprotocol/sdk@1.30.0`, `@modelcontextprotocol/server-everything@2026.8.31` | medium | mitigate | Research legitimacy audit: SDK pinned to the version OpenClaw ships, server-everything [OK]; lockfile integrity; no lifecycle scripts |
</threat_model>
