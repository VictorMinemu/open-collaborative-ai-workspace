# Phase 07.4 Plan 10: Member connections, custody and shares Summary

**Members connect their own account to a per-member connector through the API's own OAuth callback (or by pasting a key
once), the credential is sealed per member and refreshed exactly once under races, a dead grant or a changed issuer asks
to reconnect, a disconnect revokes at the provider, and a member can knowingly allow their account in one conversation.
Connections are owner-only in PostgreSQL too, with a narrow `mcp.manage` path so admin counts and clearing still work.**

## Accomplishments

- **Task 1 (tracer).** `POST /connectors/:id/connect` discovers the server, picks a client (pre-registered, CIMD or DCR,
  keyed by issuer), stores the flow in Redis for 600 s and returns only the authorize URL. The public callback resolves
  the session by hand, checks `iss`, redeems the code, seals the bundle, audits `connector.connected` and probes the
  tools API-side when the catalog is empty. The tracer passed on its first green run (7 tests).
- **Task 2.** Serialized refresh, forced refresh, terminal and transient failures, issuer change, the secret mode,
  disconnect with revocation, member and tenant isolation (18 tests).
- **Task 3.** Callback hardening and the member-account shares with server-side reader counts (20 + 9 tests).
- **#179 (separate commit).** `oauth_use_cimd` per connector, the dialog switch, the sign-in error note on the card,
  e2e on both widths and themes, and a docs paragraph.

### Plan text vs. reality

- **Deactivated member.** A deactivated member's session no longer authenticates, so connect answers 401, not 403.
  The 403 case is tested with a `connector.connect` deny rule instead.
- **R11 scopes.** The authorize URL's scope is the admin's scopes plus `offline_access`, because the fake lists it
  (07.4-05's `chooseScope`). It is not exactly the admin's list.
- **`OCW_PUBLIC_API_URL`.** The tests use `http://localhost:4999` and rewrite the callback origin to the stack's
  random port. The `https_required` and https/CIMD cases switch `core.env.OCW_PUBLIC_API_URL` per test (it is read
  per request) instead of starting more stacks.
- **"Revocations +1".** Only the refresh token is revoked: revoking it ends the grant, as RFC 7009 allows. The access
  token is revoked only when there is no refresh token.
- **Test fixture.** `apps/api/src/testing-connectors.ts` lives outside `modules/connectors/` so `ocw.raw-egress` stays
  meaningful there.
- **TDD shape.** There are no separate RED commits, because verify must be green before every commit. RED was observed
  for:

  - task 3: 8 share tests on missing routes;

  Most of task 2 and the callback hardening passed on first run, because task 1's implementation already covered them.

## Broken-windows candidates (not appended: WINDOWS.md is off-limits in this run)

1. **deviation (medium), `apps/api/src/modules/connectors/credentials.ts`.** On `issuer_changed` (and every terminal
   code), the sealed bundle is deleted without revoking at the old issuer. The old grant stays live there until it
   expires. A later disconnect has nothing left to revoke.
2. **deviation (medium), `apps/api/src/modules/connectors/shares.ts`.** `conversationName` is null for DMs and group
   DMs. The UI-SPEC renders null as "a conversation you can no longer open", which is wrong for a readable DM. 07.4-13
   should name DMs, or the contract needs a kind.
3. **deviation (medium), `apps/api/src/modules/connectors/probe.ts`.** A failed member probe sets the whole server to
   `status: error` (shared catalog state). One member with a narrower scope or a bad key can flip the admin card.
4. **deviation (low), `packages/db/sql/post-migrate.sql`.** `app.secrets` rows of kind `connector_credential` are still
   readable by any session of the organization, as ciphertext bound to the member AAD. An owner policy would need an
   owner column.
5. **deviation (low), `apps/api/src/modules/connectors/routes.ts`.** When two members race a first DCR registration
   for the same issuer, the loser's registration is discarded locally and stays orphaned at the authorization server.
6. **deviation (low), `apps/api/src/modules/connectors/credentials.ts`.** Each refresh re-discovers the authorization
   server, which adds two metadata requests per refresh. A discovery outage falls back to the stored issuer's token
   endpoint.
7. **deviation (low), `apps/api/src/modules/connectors/oauth.ts`.** `chooseScope` adds `offline_access` to the admin's
   R11 scopes when the authorization server lists it.
8. **unrun-verify (low).** CIMD is proven only up to the authorize URL's `client_id`. The fake's AS fetching the
   document over https is not exercised; the e2e stack is plain http (#173's tail).
9. **process (low).** Testcontainers port-bind timeouts under parallel worktree load hit `ai-chat/grants.int.test.ts`
   once; the rerun was green.
