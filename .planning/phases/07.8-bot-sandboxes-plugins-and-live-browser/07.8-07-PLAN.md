<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web page → browser agent | Page content is untrusted and may try to mislead or exfiltrate |
| person's input → page | Typed secrets must reach the page only |
| agent → caller (sandboxd → API → model) | Only redacted snapshots and masked screenshots leave |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.8-SC | Tampering | playwright-core, Chromium build, system packages | high | mitigate | Blocking human gate with npm integrity, browsers.json revision, archive sha256 (Task 1) |
| T-07.8-07-01 | Information disclosure | password, OTP or typed values in snapshots (E1) | critical | mitigate | Redacting serializer over the AX tree, human-typed marks in an isolated world, real-Chromium regression (Tasks 2–3) |
| T-07.8-07-02 | Information disclosure | secrets in screenshots | high | mitigate | Masked boxes over sensitive and typed fields, pixel check (Task 3) |
| T-07.8-07-03 | Information disclosure | input payloads in logs | high | mitigate | Payloads never written; smoke greps stdout and stderr (Task 3) |
| T-07.8-07-04 | Elevation of privilege | CDP exposed on a port | high | mitigate | Pipe only; `ss -ltn` check (Task 2) |
| T-07.8-07-05 | Spoofing | identity-provider cookies sealed with a site session | high | mitigate | Domain-match filter on export (Task 3) |
| T-07.8-07-06 | Denial of service | oversized downloads or runaway frames | medium | mitigate | Size cap, fps throttle with ack (Tasks 2–3) |
</threat_model>
