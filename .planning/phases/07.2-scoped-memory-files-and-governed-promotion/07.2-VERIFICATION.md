# Phase 07.2: Scoped memory files and governed promotion. Verification report

**Phase goal:** Agents keep their memory as Markdown files in folders the platform owns (personal, agent, project,
team and organization scopes). People browse, read and edit those files in a file-tree viewer with history. Anything
an agent wants to put into a shared scope goes through a detector and a human approval, and the server applies it.
