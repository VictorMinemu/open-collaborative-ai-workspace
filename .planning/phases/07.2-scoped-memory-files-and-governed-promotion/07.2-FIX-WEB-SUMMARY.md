# Phase 07.2 FIX-WEB: web-side ledger gaps before the gate Summary

viewer and the agent page), the Dialog close X is 44 px below 1024, Modules copy names Memory, memory ages read
"3h ago", the scan copy no longer reads as an all-clear, and `memory-files.spec` passes after the bot specs in one
shared database.**
