## Phase Goal

See `07.17.1.1.2-01-PLAN.md` (PD-13, PD-14). **This plan's slice:** the two wake sources: a background sandbox process
the task waits on, and a Work Zone session the task started, so the bot waits instead of polling.

<objective>
Link a task turn's background `ocw_sandbox_exec` to its task (`bot_task_processes`); make sandboxd emit one `process`
event when a yielded process ends and the fake sandboxd do the same; make the API consumer tolerant of unknown event
types and route `process` events to `onProcessEvent`, which wakes the waiting task; carry the process facts into the
continuation; store `bot_work_sessions.task_id` at a task turn's session start and deliver that session's wakes as task
turns (D-03, D-07).

Purpose: "it is woken when long sandbox processes or its Work Zone sessions finish" (owner, CONTEXT D-03).
Output: one handler module, sandboxd emission, fake support, consumer tolerance, wiring, Work Zone wake changes, tests.
</objective>
