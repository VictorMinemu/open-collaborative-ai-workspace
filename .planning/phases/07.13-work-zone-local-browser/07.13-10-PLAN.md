## Objective

Per D-15 (research correction: `work_session.read`), D-20, D-27, D-33, PD-12, PD-13 (hub `07.13-01-PLAN.md`). The
session's audience watches the device's page live: a dedicated binary WebSocket per Work Zone session, built beside
the bots' live view and reusing only its exported pure pieces, with frames requested from the device only while
someone watches, a per-frame privacy gate, and Redis transit when the viewer is on another API instance.

Purpose: "everyone who can see the session watches it live", without leaking a private sign-in or a takeover. Output:
live socket, viewer registry, relay, integration tests.
