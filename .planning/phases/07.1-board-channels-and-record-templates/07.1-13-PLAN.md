## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output → `ocw_board_card` params | Untrusted, possibly prompt-injected intents |
| plugin → Agent Channel API | Cell token; the API trusts only `agent_turns` (07.1-10) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.1-13-01 | Elevation of privilege | model choosing another conversation, human or agent | high | mitigate | Ids from the active turn only; params with ids refused locally; the API re-derives everything from the turn |
| T-07.1-13-02 | Spoofing | duplicate cards from OpenClaw retries | low | mitigate | `<eventId>:board:<n>` keys, one n per tool call |
| T-07.1-13-03 | Information disclosure | API error bodies or text in plugin logs | low | mitigate | Fixed answers; logs with ids and status codes only |
| T-07.1-13-04 | Elevation of privilege | tool offered in text channels | medium | mitigate | Offered only when the turn lists it (board turns, 07.1-10); bot-capabilities spec unchanged |
</threat_model>
