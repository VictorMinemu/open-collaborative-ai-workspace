## Phase Goal

See `07.15-01-PLAN.md`. **This plan's slice:** PDF text for bots (D-05) with the library pinned by D-12, isolated from
the API's event loop and bounded in time, memory, pages and output, so a crafted PDF cannot freeze or exhaust the API.

**Package legitimacy (RESEARCH Package Legitimacy Audit).** RESEARCH flagged `unpdf` `[SUS]` only for `too-new` on 2.1.0.
D-12 pins `1.9.1` (published 2026-10-19, 19 days before planning, past the 14-day rule and the repo's 7-day
`minimumReleaseAge`), verified on the npm registry by the orchestrator (MIT, maintainer johannschopplich, repository
github.com/unjs/unpdf). The owner's full-autonomy grant approved the install (no human checkpoint, PD-14); Task 1
re-checks the registry metadata automatically before installing.

<objective>
Install `unpdf@1.9.1`, add the bounded PDF Worker (`pdf.ts`, `pdf-worker.mjs`), wire the `pdf` case into
`readAttachmentForAgent`, and prove every bound with fixtures (D-05, D-12, PD-07).

Purpose: PDFs are the most common document people attach; parsing them is the phase's main denial-of-service surface.
Output: the dependency, the worker and its parent, the PDF test fixtures, the PDF branch of the read layer, the tests.
</objective>
