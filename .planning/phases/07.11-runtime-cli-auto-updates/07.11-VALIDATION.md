---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (unit + integration on real ephemeral PostgreSQL), Playwright e2e |
| **Config file** | `apps/local-runtime/vitest.config.ts`, root `vitest` projects, `e2e/playwright.config.ts` |
| **Quick run command** | `pnpm exec vitest run --project unit <file>` (local-runtime and contracts), `--project integration <file>` (API, DB), `--project web <dir>`; `pnpm --filter @ocw/local-runtime test`; `env -u ELECTRON_RUN_AS_NODE pnpm --filter @ocw/desktop test`; + `pnpm typecheck --force` after a contract change |
| **Full suite command** | `pnpm verify`, then `bash scripts/e2e-isolated.sh runtime-updates.spec --project=desktop` and `bash scripts/e2e-isolated.sh --rebuild-web runtime-updates-ui.spec`, then `bash scripts/runtime-update-proof.sh` |
| **Estimated runtime** | quick ~30 s; `pnpm verify` ~10 min; e2e spec ~3 min |

---

## Sampling Rate

- **After every task commit:** the touched package's quick command plus `pnpm typecheck`
- **After every plan wave:** `pnpm verify`
- **Before `/gsd-verify-work`:** `pnpm verify` + the e2e spec through `scripts/e2e-isolated.sh` + the headless Linux proof
- **Max feedback latency:** 60 seconds for the quick command
