## Phase Goal

**As an** Organization Admin and every member of the workspace, **I want to** arrange the company into departments, teams and projects with the four PRD roles, have every route decided by one permission resolver, and manage my own password, sessions and profile, **so that** each person and agent can do exactly what their role, units and rules allow and every sensitive change is attributed and audited.

**This plan's slice:** bots, model providers and the OpenClaw cell (research R5, R6, M11–M14) on the resolver, with agents as first-class principals (AGENTS principle 2).

<objective>
Migrate the agent and agent-channel modules to the permission service: admin surfaces (providers, subscription sign-in, cell token, bots CRUD) via org-scope permissions; the Agent Channel API via a cell principal (`cell.sync`) and, when a bot acts, an agent principal with membership preconditions, deny rules and the agent ∩ human intersection (passing `inReplyToMessageId` through the bridge field 02-04 added). Replace the web's role hook with `useCan`. Client kind literals become the caller's real client kind (AUTH-05).

Purpose: SC3 names bots and providers among the Phase 1 routes that must use the single resolver.
Output: agent/agent-channel on perms, requireActiveAgent / requireMembership deleted, web bots gated by permissions, tests.
</objective>
