## Context

Hub: `07.17.1.1.1-01-PLAN.md` (PD-03, PD-10, E20). CLAUDE.md plan mode applies (sandboxd lifecycle at the isolation
boundary): the SUMMARY opens with the intended change, then the executor proceeds. Research finding 1: Compose rebuilds
the same tag (`ocw-sandbox-sbx:${OCW_IMAGE_TAG:-local}`), sandboxd reuses a bot's container and re-creates a stopped one
only for a stale `/etc/hosts` entry, so without this plan Gertru's sandbox keeps the old image and env after the
upgrade. 05 proves the same on real Docker (`drift` section).

its volumes), never touch a running one, and let `restart` re-create a drifted one (D-10).

Purpose: the toolkit must reach Gertru on ocw.autofy.ing without anyone removing containers by hand.
Output: drift detection in `ensure` and `restart`, `shellEnvCurrent`, the fake Docker's image table, the drift test file.
</objective>
