## Phase Goal

Platform-owned Markdown memory per scope with a file-tree viewer and governed promotion (plan map, cross-plan contracts
and executor rules in 07.2-01-PLAN.md).

**This plan's slice (phase tracer, API level):** after the package gate, a person creates and edits a file in their
personal memory through REST → resolver → RLS → append-only revision → audit → owner event; then every scope, file
operation and the access matrix. Memory search (FTS) is its own plan, 07.2-16 (wave 4).

    export type MemoryActor = { kind: "user"; userId: string } | { kind: "agent"; agentId: string; onBehalfOfUserId: string }

      | { kind: "approved"; agentId: string | null; onBehalfOfUserId: string | null; approvalRequestId: string }
        // used only by an approval kind's apply hook: no resolver check (the primitive decided), author recorded as the
        // agent on behalf of the human, revision linked to the approval request
    export interface MemoryService {
      ensureScope(tx, key: { kind: "personal"; agentId; ownerUserId } | { kind: "agent"; agentId } | { kind: "unit"; unitId } | { kind: "org" }): Promise<ScopeRow>
      listScopes(tx, viewerUserId): Promise<MemoryScope[]>
      listReadableFiles(tx, actor, scopeId, folder?): Promise<MemoryFileMeta[]>
      readFile(tx, actor, ref: { fileId } | { scopeId; path }): Promise<MemoryFile>        // 404 when unreadable or missing
      writeFile(tx, actor, op: { op: "create"; scopeId; path; content } | { op: "update"; fileId; content; expectedVersion }
        | { op: "rename"; fileId; path; expectedVersion } | { op: "delete"; fileId; expectedVersion }
        | { op: "restore"; fileId; version; expectedVersion }): Promise<MemoryFile | null>
      appendToFile(tx, actor, a: { scopeId; path; text }): Promise<{ fileId; version }>     // advisory lock, creates the file when missing
      // domain conflicts throw HttpError codes (memory_version_conflict, memory_path_exists, memory_scope_full, secret_detected, …);
      // `approved` callers catch them and map to apply result codes
      forgetScope(tx, actor, scopeId): Promise<{ files: number; revisions: number }>        // personal-like scopes, owner only
      listRevisions(tx, actor, fileId) / readRevision(tx, actor, fileId, version)
      decideAgentRead(tx, a: { agentId; onBehalfOfUserId; audience: { userIds: readonly string[]; unbounded: boolean };
        scopeId; path?: string }): Promise<{ allowed: true } | { allowed: false; reason: "denied" | "audience_too_wide" }>
      scopeFacts(tx, scopeId): Promise<{ row: ScopeRow; facts: MemoryScopeFacts; label: string }>
    }
    export function withPersonalOwner<T>(tx, ownerUserId: string, fn: () => Promise<T>): Promise<T>   // sets app.user_id locally, restores it after
    export function audienceVerdict(...)                       // pure combinator, unit-tested

    export function createMemoryModule(core: Core, memory: MemoryService): ApiModule

## Trust Boundaries

| browser → memory REST | Paths, content and ids from people |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.2-08-01 | Information disclosure | Admin listing or reading personal memory | critical | mitigate | Resolver precondition + RLS + no personal scopes in admin listings; API tests (Task 3) |
| T-07.2-08-02 | Tampering | Path traversal/ambiguity in REST paths | high | mitigate | Every path re-parsed with the shared grammar; case-insensitive unique key; tests (Task 2) |
| T-07.2-08-03 | Tampering | Lost updates between editors | medium | mitigate | Conditional UPDATE on `version`; 409 with the current version; appends under an advisory lock (Tasks 2, 3) |
| T-07.2-08-04 | Information disclosure | Secrets stored in plaintext (principle 8) | high | mitigate | `detectSensitive` block on every write path; 422; nothing stored (Task 2) |
| T-07.2-08-05 | Information disclosure | Cross-unit or cross-tenant reads | high | mitigate | Per-path resolver decisions; D ⊃ A, B matrix; org B ids 404 (Task 3) |
| T-07.2-08-07 | Information disclosure | Agent quoting memory to readers who may not read it | high | mitigate | `decideAgentRead` audience rule with listed and unbounded cases (Task 3); enforced in 11 |
| T-07.2-08-08 | Elevation of privilege | Misuse of `withPersonalOwner` | high | mitigate | Called only after an allowed resolver decision; 15 pins the call sites with a test |
| T-07.2-08-09 | Repudiation | Changes without history | medium | mitigate | One revision + one audit row per change (Task 2) |
| T-07.2-08-SC | Tampering | npm install of `diff` | high | mitigate | Blocking legitimacy checkpoint, exact pin, minimumReleaseAge, license guard (Task 1) |
