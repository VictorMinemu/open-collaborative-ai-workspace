## Phase Goal

See 07.18-01 (the hub). **This plan's slice:** on the device, a Claude Code session runs on the pool token it was given,
in memory only, changes account between turns when the server says so, and reports limits and usage. The fake runtime
gets the same account behaviour so the browser journey (16) runs on the real daemon.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → daemon | The token arrives in a command, in memory |
| repository → CLI | `.claude/settings.json` of the project is untrusted |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
