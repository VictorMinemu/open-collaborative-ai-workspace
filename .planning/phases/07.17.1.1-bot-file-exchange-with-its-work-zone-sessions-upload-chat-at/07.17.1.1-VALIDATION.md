# Phase 07.17.1.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Written at planning time from RESEARCH.md
> § Validation Architecture; 07.17.1.1-15 fills the Local and CI columns and signs it.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (projects `unit`, `integration` on real ephemeral PostgreSQL + Redis + the test Garage `dxflrs/garage:v2.4.1`, `web`), Playwright e2e (desktop 1440 / mobile 390), the real-cell smoke |
| **Config file** | root `vitest.config.ts`; `e2e/playwright.config.ts`; `infra/openclaw/test/run-container-smoke.sh` |
| **Quick run command** | `pnpm exec vitest run --project unit <file>` |
| **Integration command** | `pnpm exec vitest run --project integration <file>` (one file at a time locally; Docker) |
| **Full suite command** | `pnpm verify` (CI) |
| **Estimated runtime** | unit file ~10 s; integration file ~60–120 s (the route timeout case waits the stack's 5 s test deadline); full verify on CI |

Local rule (PD-03): unit, web, typecheck, Biome and each task's integration file run locally; the e2e, the real-cell
smoke, `pnpm gate:compose` and the full `pnpm verify` run on the PR's CI only (the isolated e2e script would touch the
owner's demo database). No test touches the network, a real device, `~/.ocw`, the demo or `ocw.autofy.ing`.

---

## Sampling Rate

- **After every task commit:** the task's unit files (+ its integration file).
- **After every plan wave:** `pnpm lint && pnpm guard && pnpm typecheck && pnpm exec vitest run --project unit
  --project web` locally, then the PR's pipeline (integration included).
- **Before `/gsd-verify-work`:** every workflow green on the final tree (15 T3).
- **Max feedback latency:** 120 seconds locally (unit).
