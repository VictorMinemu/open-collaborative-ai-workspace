## Phase Goal

See 07.7-01 (Phase Goal, plan map, cross-plan contracts, P-01 … P-19).

**This plan's slice:** the return half of a consult — the answer and the asker's reply are accepted by PR #25's rule as
they are (pinned here), the hop closes when the target's turn is done, the asker gets the answer as a new turn for the
same human — plus nesting, handoff, taint, billing, and Stop. Timeouts and automatic cancel are 07.7-09.

<objective>
Close hops on the turn-done signal, deliver the answer back as `agent.consult_reply.v1` on 07.6's delivery pattern, pin
consult turns as valid triggers under the existing rule, and let the human stop a chain.

Purpose: A2A-01 (the answer returns as a new turn; each hop visible and audited), A2A-02 (route-level visibility, Stop
authority), A2A-03 (nesting bounded, H pays, limits, taint); D-01, D-02, D-03, D-04, D-06, D-07, D-09, D-12, D-13, D-15;
P-02, P-08, P-09, P-11, P-12, P-13, P-14.
Output: `chains.ts`, `chain-routes.ts`, done route, reply capture in the existing `onInserted` hooks, three integration
test files.
</objective>

      2. hop set: UPDATE … SET status = answered|failed, answer_message_id = turn.reply_message_id, closed_at = now()
