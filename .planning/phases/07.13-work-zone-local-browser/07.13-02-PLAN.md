## Objective

Per D-01, D-04, PD-02, PD-22 (hub `07.13-01-PLAN.md`). The redaction, isolated-world, capture, zip and site-filter code
of the bots' browser becomes the workspace package `@ocw/browser-engine`, with its tests under vitest; the Local
Runtime depends on it and on `playwright-core@1.64.1` (the brw pin), which stays external to the runtime bundle.
The `brw` image still uses its own copies until 05 switches it (no bots' image change here).

Purpose: one engine for bots and Work Zone (the agent reads exactly what a bot reads), and the dependency every later
device plan needs. Output: the package, the pin, the bundle external and the automated pin check.
