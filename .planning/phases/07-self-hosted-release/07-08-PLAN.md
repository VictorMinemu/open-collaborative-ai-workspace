## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → Caddy | Only public entry in proxy mode; TLS terminates here |
| Caddy → api / web / garage | Compose network; Caddy rewrites `X-Forwarded-*` |
| internet → `/agent-channel/*` | Must not be reachable; cell traffic stays internal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-08-01 | Spoofing | forged `X-Forwarded-For` through the proxy | high | mitigate | Caddy overwrites XFF; API trusts one hop; audit check (Task 2) |
| T-07-08-02 | Elevation of privilege | Agent Channel API exposed publicly | high | mitigate | `/agent-channel/*` → 404 at Caddy; checked (Task 2) |
| T-07-08-03 | Tampering | presigned URL reuse with altered path or signature | medium | mitigate | Host and path preserved so SigV4 holds; tampered/unsigned 403 checked (Task 2) |
| T-07-08-04 | Information disclosure | API/web reachable directly, bypassing TLS | medium | mitigate | Loopback publish in proxy mode; checked (Task 1) |
| T-07-08-05 | Elevation of privilege | Caddy admin API | medium | mitigate | `admin off` (Task 1) |
| T-07-08-06 | Information disclosure | session cookie over plain HTTP | medium | mitigate | HTTPS origin; `Secure` asserted (Task 2) |
</threat_model>
