<objective>
Per D-12 (and D-04 for the checksum refusal). Prove the update path through the real electron-updater code (it needs
Electron's `net`, so it cannot run in vitest) against a fake release served on loopback by the test itself, on the
three operating systems, without ever reaching GitHub, the npm registry, the real `~/.ocw` or installing anything.

Purpose: the offline end-to-end proof of DAU-03 and DAU-09. Output: the fake release fixture, the spec, the
`test:update` script and the release.yml step. The spec runs only in CI (the owner's rule); locally it is typechecked
and listed.
</objective>
