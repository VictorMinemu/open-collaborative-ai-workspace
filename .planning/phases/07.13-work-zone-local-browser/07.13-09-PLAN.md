## Objective

Per D-01, D-02, D-03 (research correction: `TMPDIR`, not Chromium's profile-directory flag), D-04, D-07, D-12, D-35, PD-18,
PD-19, PD-24 (hub `07.13-01-PLAN.md`). The device's browser engine: a TypeScript port of the bots' agent ops it needs
(no proxy, no downloads, one page), running in a child process of the daemon over the bots' frame codec, with the
shared redaction. This is the first runnable slice of the phase tracer: a real Chromium on a real local page.

Purpose: the agent reads exactly what a bot reads, and a Chromium crash never takes the daemon down. Output: agent ops,
child entry, parent-side `BrowserChild`, test helpers (pinned browser, local site with a login form), tests.
