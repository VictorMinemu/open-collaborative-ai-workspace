## Phase Goal

See `07.11-01-PLAN.md`. **This plan's slice:** the device's maintenance core: how each CLI was installed and the one
command that updates it (a fixed on-device table), what the latest version on the install's channel is, and running
that command safely and verifying the result. Pure modules, no daemon wiring (07 wires them; 05 owns the gate).

<objective>
Build `apps/local-runtime/src/maintenance/{install-method,registry,runner}.ts` and the fake CLI, test-first on fake
install trees, starting with one native Claude update end to end (resolve → latest → run → verify) and then widening
to every install method, the lock, the timeout, the output rules and the registry's channel and cache (D-01, D-05,
D-07, D-08, D-12; PD-09, PD-10, PD-11).

Purpose: RTU-01 (what the device reports), RTU-02 (latest on the right channel), RTU-04 (run, lock, timeout, cap,
verify). 07 calls these from the orchestrator; 09 and the Linux proof reuse the fake CLI.
Output: three modules with colocated tests, the fake CLI, the manifest-floor test.
</objective>
