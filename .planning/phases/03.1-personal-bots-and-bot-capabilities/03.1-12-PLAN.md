<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ClawHub artifact → cell filesystem | Third-party code downloaded into the gateway's state |
| installed plugin → gateway process | Native plugins run in-process, unsandboxed (same trust as core) |
| cell → `/agent-channel/v1/plugins/report` | The cell reports what got installed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-12-01 | Tampering | artifact substitution or MITM | high | mitigate | Origin pinned to `OCW_CLAWHUB_URL`, approved sha256 (and npm integrity) verified before install; mismatch → `digest_mismatch`; tests |
| T-03.1-12-02 | Elevation of privilege | installs outside the approval flow (CLI, RPC, update) | high | mitigate | `security.installPolicy` exec allows only approved tuples and fails closed; control UI off; auto-update off (`OPENCLAW_NO_AUTO_UPDATE=1`); smoke proves a manual install is blocked |
| T-03.1-12-03 | Elevation of privilege | malicious plugin code in-process (reads env, tokens, transcripts) | high | mitigate | Refuse-level scorer, official-only default, community needs explicit acknowledgement, re-score on the reported surface with automatic uninstall; documented residual risk in ADR-0011 (in-process plugins are not sandboxed) |
| T-03.1-12-04 | Information disclosure | plugin hooks reading conversations or injecting prompts | high | mitigate | `hooks.allowConversationAccess: false`, `allowPromptInjection: false` rendered for every installed plugin |
| T-03.1-12-05 | Tampering | command injection through package names/versions | high | mitigate | `execFile` with an argv array, values only from the API-approved event cross-checked with the snapshot, no shell |
| T-03.1-12-06 | Denial of service | huge or slow artifacts | medium | mitigate | 50 MB cap, 60 s download timeout, 120 s CLI timeout, one install at a time |
| T-03.1-12-07 | Information disclosure | ClawHub install telemetry | medium | mitigate | `CLAWHUB_DISABLE_TELEMETRY=1` on every child process |
| T-03.1-12-08 | Repudiation | install outcomes | medium | mitigate | `plugin.installed`, `plugin.install_failed`, `plugin.uninstalled`, `plugin.rejected_after_install` audits |
| T-03.1-SC | Tampering | `@openclaw/duckduckgo-plugin@2026.9.7` in the smoke | medium | mitigate | Owner-approved official package; host `npm pack` with the pinned sha512 from bundled-plugins.json verified before use |
</threat_model>
