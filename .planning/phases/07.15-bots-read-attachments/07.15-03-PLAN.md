## Phase Goal

See `07.15-01-PLAN.md`. **This plan's slice:** the one row rule every bot access to a conversation file goes through
(D-16), applied first to the existing `ocw_sandbox_import` (which today accepts any ready row of the conversation,
including someone's unsent upload), with the import audit D-07 asks for, and the test helpers later plans use.

**Hotfix note (PD-05).** At planning, `fix/sandbox-import-attachment-scope` had no commit beyond `main`, so this plan
implements the rule. If, after rebasing on `main`, the hotfix is already there, keep its tests, move its precheck into
`attachmentForTurn` (one helper for read and import) and record that in the SUMMARY; the acceptance criteria below
stay the same.

<objective>
Create `agent-channel/attachment-access.ts` with the shared row rule (`attachmentForTurn`, `turnThreadRoot`,
`messageScopeFilter`), decide the `/sandbox/import` precheck with it, audit every import as `bot.attachment_imported`,
move the history thread filter into it without changing delivery, and add `uploadAttachment` and the attachment-aware
`turnOf` for integration tests (D-07, D-09, D-10, D-16, PD-05, PD-09).

Purpose: read (08) and import can never disagree about which file a turn may touch.
Output: the new module, the tightened import, the regression and audit tests, two test helpers.
</objective>
