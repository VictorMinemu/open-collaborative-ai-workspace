# Phase 07.6 Plan 23: Natural-language automation proposals in the browser Summary

**A bot's automation proposal now works end to end in the browser: only the person it runs as sees Edit · Create
automation · Discard, everyone else reads who can confirm it; confirming goes through the UI-SPEC dialog (Created),
discarding tells the bot (Discarded), and Edit opens the editor from the approval view with the brand-soft draft banner,
whose save closes the proposal as Created with changes. Proven in a DM and a channel at 1440 and 390, light and dark,
with axe and 20 reviewed screenshots.**

## What changed

- **`useAutomationDraft` / `automationDraftOf`** (`automation-queries.ts`): `GET /approvals/:id` → `loading`, `gone`
  (any status but pending, a non-`automation_draft` view, or a 404) or `ready` with the editor's form values (cron →
  preset or Custom via `cronToSchedule`), the bot and the banner's conversation. `useSaveAutomation` marks the saved
  proposal's approval detail stale without refetching it under the open editor.
- **Editor `?draft=`** (`automation-editor-sheet.tsx`): reads the hook instead of the raw approval; `DraftBanner`
  (exported, Zap icon, `bg-brand-soft text-brand-soft-foreground`); `DraftGone` replaces the form (no footer) when the
  proposal is closed; the just-saved proposal never flashes as gone before the sheet closes. Save still sends
  `fromApprovalId` (07.6-15's path, unchanged).
- **Card (two contained fixes in the proposal path of `agent-card.tsx`)**: Instructions is always the block value; the
  kind row of an automation proposal card wraps, so "Created with changes" no longer covers "Created by the workspace"
  at 390.
- **E2E** `automation-proposals.spec.ts`: Ana (standard member, created by the spec), Sam (other reader), Víctor (admin);
  the fake cell without auto-replies plays the bot (waits for the delivered turn, calls `/automations/propose`, then
  answers the turn).

prohibition says agent-card.tsx is 15's; 15 is merged and no parallel plan edits the file (17 only reads it), and the

snapshots pass). Commit `d899be02`.

(its save then failed 409) and showed a blank New automation form for a foreign or missing one (its save would have
created an unrelated automation without `fromApprovalId`). Both now show the gone state with no footer.

  e2e admin (Víctor) owns the bot and the channel. The channel is a fresh `sales-…`, so the card reads `#sales-…`.
