## Phase Goal

**As a** member of a team that works in the workspace, **I want to** hold my whole daily conversation there — channels grouped by department and team, DMs and group DMs with people and bots, messages I can edit, delete, react to, pin, save and link to, @channel/@here and notifications I control, search and files — **so that** I do not need a second chat tool and every message stays attributed, editable under audit and delivered in realtime.

**This plan's slice (tracer):** one Markdown component renders every surface (chat, thread, DM, agent output, Work Zone stream), proven with security fixtures and screenshots; then its engine moves to streamdown + shiki behind the same interface (D-05). Planner decisions P-01 … P-12 are in `04-01-PLAN.md`; this plan follows P-08 (executor rules) and P-09 (UI and screenshots).

<objective>
Replace the two Markdown renderers (chat and Work Zone) with one shared component, first on the current pipeline (zero new dependencies, proves every surface and the security fixtures), then — after the package-legitimacy checkpoint — on streamdown with shiki highlighting and streaming-safe parsing.

Purpose: CHAT-05 and D-05; Phase 5 AI chats reuse the same component.
Output: `components/markdown/{markdown.tsx,rehype-mentions.ts,markdown.test.tsx}`, adapters in chat/ and work-zone/, the `web` vitest project, `e2e/tests/renderer.spec.ts`, before/after screenshots.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02-01 | Tampering | stored XSS through Markdown | high | mitigate | No raw-HTML rehype plugin (explicit `rehypePlugins` list), URL transform/hardening allowlist http/https/mailto/same-origin, images as links; fixtures for script, on* attributes, javascript:/data: links, iframe, style |
| T-04-02-02 | Information disclosure | tracking pixels in message images | medium | mitigate | Images render as anchors, never `<img>`; fixture |
| T-04-02-03 | Tampering | malicious or hijacked npm package | high | mitigate | Blocking-human legitimacy checkpoint (Task 2) before install; exact pins ≥ 7 days old enforced by `minimumReleaseAge`; no lifecycle scripts (`allowBuilds` unchanged) |
| T-04-02-SC | Tampering | npm installs (streamdown, @streamdown/code; frimousse in Plan 05) | high | mitigate | package-legitimacy gate + blocking human checkpoint for every [SUS] package |
| T-04-02-04 | Denial of service | huge code blocks freezing the tab | low | mitigate | 10,000-line fixture under 1 s; streamdown block memoisation |
| T-04-02-05 | Spoofing | mention chips rendered for unknown handles | low | accept | Chips only for handles present in MentionContext (server directory); unknown handles stay plain text |
