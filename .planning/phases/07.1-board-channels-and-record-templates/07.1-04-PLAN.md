## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07.1-04-01 | Tampering | stale or replayed frames reordering the board | medium | mitigate | Version-gated reducer (ignore ≤ cached version); one cursor; resync refetch |
| T-07.1-04-02 | Tampering | stored XSS through titles or descriptions | high | mitigate | Tiles render titles as React text nodes only (never Markdown); descriptions render through the existing `<Markdown>` in the thread only |
| T-07.1-04-03 | Information disclosure | UI gating mistaken for authority | low | accept | Menus only send intents; the API re-decides every move (07.1-03) |
| T-07.1-04-04 | Denial of service | malformed frames crashing the view | low | mitigate | Frames that fail schema parsing are ignored |
</threat_model>
