# Phase 07.18 Plan 01: Account pool contracts Summary

One shared Zod vocabulary for the subscription account pool: Claude setup-tokens (API keys refused), pool DTOs and
admin requests without any token/secret/e-mail key, the Device Link account fields and frames, the server-only
`account.switched` event with its verbatim sentence, and the cell's `CellAccountPool` mirrored byte-for-bound in the
OpenClaw plugin.

## What was built

- **`account-pool.ts` (new, `export *` from `index.ts`)**: `POOL_LIMITS`, `PoolLabel`, `ClaudeSetupToken` (regex +
  "This is an API key. Add it in Settings › Models."), `PoolLimitReason`, `PoolSignInErrorCode`, usage windows and
  snapshots, `PoolProvider`, `POOL_PROVIDER_OF_RUNTIME`, `PoolStrategy` / `PoolStrategyChoice` / `normalizeStrategy`,
  `POOL_STRATEGY_TEXT`, `BOTS_WEIGHTED_NOTE`, `PoolScope`, kinds, statuses, origins, `PoolAccount`, `PoolPolicy`,
  `AccountPoolView`, the six strict requests, `DeviceSignInState`, `DeviceSignIn`, `AccountPoolErrorCode`,
  `AccountSourcePreview` / `AccountPoolPreview` / `accountSourceLabel`, `SessionPoolAccountRef`, `CELL_CLAUDE_TOKENS`,
  `AccountSwitchReason`, `accountSwitchedSentence`. All bounds and sentences as the hub states them.
- **`device-link.ts`**: `DEVICE_ACCOUNT_POOL_VERSION`, `SlotId`, `SessionAccount` (token | device_slot), optional
  `account` on `SessionStartPayload` and `PromptPayload` (PD-02/PD-03 docs), `HelloFrame.accountPool` (literal 1,
  optional), `account.login` / `account.logout` command kinds with strict payloads, `CodexSlotReport`, and
  `session.account_limited`, `account.usage` (exactly one of accountId / slotId), `accounts.sync` (≤ 10 slots),
  `account.login` frames in `DeviceToServerFrame`.
- **`session-events.ts`**: `account.switched` (imports `IsoDateTime` from `common`, never `account-pool`) and
  `SERVER_ONLY_SESSION_EVENTS`.
- **`work-session.ts`**: `WorkSession.poolAccount: SessionPoolAccountRef.nullable().optional()`.
- **`agent-channel.ts` + plugin mirror**: `poolProfileId`, `claudeTokenProfileId`, `POOL_TOKEN_ENV_RE`,
  `CellAccountPool`, `CellSnapshot.accountPool`, `ProviderAuthStartEvent.profileId`,
  `ProviderAuthRevokeEvent.profileIds`, `CellAuthProfileReport`, `profileId` / `profiles` on the provider-auth report
  (a Zod schema in contracts, the TS type plus a Zod `CellAuthProfileReport` in the mirror).
