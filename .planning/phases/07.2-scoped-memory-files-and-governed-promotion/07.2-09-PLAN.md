## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → proposal content, path, reason | Untrusted, possibly derived from web/tool content |
| approver → decision | Approver may not see the source conversation |
| proposal time → apply time | The target file can change in between |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
