## Phase Goal

A shared agent acts with the credentials of the person who asked, secrets are used by reference and never seen by the
model, and people start their own agent from a template (plan map, cross-plan contracts and executor rules:
07.4-01-PLAN.md).

**This plan's slice (tracer, data level):** a member's connector connection stored under forced tenant RLS and
invisible from another organization, through schema → one migration → RLS enumerator; then the remaining constraints
and the upgrade test. CLAUDE.md asks for plan mode on any migration: present the schema plan first, then proceed.

<objective>
Create the single 07.4 migration with every table and column the phase needs, under the platform's tenant isolation,
with database-level guards for the rules that must never be bypassed.

Purpose: CONN-01 … CONN-06 storage; C-02 (RLS + cross-tenant test); D-01 … D-05.
Output: schema in `app.ts`, one drizzle migration folder, RLS enumerator seeds, a constraints test, `HEAD_ONLY`.
</objective>
