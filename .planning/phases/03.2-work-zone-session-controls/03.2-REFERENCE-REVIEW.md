# Phase 03.2 — Side-by-side reference review

**Date:** 2026-10-05 · **Reviewer:** Plan 03.2-11 executor (owner's final look pending) · ROADMAP 03.2 criterion 6.

References: `reference/ref-1.png` (permission menu), `reference/ref-2.png` (model picker), `reference/ref-3.png`
(reasoning menu), `reference/ref-4-layout.png` (whole session screen). The plans call the model picker "ref-3" and
the reasoning menu "ref-2"; on disk it is the other way round, and this review follows the files.

Screenshots: `screenshots/`, all `wz-*` captures regenerated from the final branch state by the phase-gate run
(`OCW_E2E_SCREENSHOT_DIR=… bash scripts/e2e-isolated.sh work-zone presence realtime-access`, 27/27 passed) and read
one by one. Sizes: 1440×900 desktop, 390×844 phone; `-dark` = dark theme. The four `wz-controls-model-*` files are
Plan 01 captures that no current spec writes any more (the controls spec now writes `wz-composer-*`); they show the
Plan 01 chip and are kept only as history.

Verdict: **match**, with the intentional differences listed below. Nothing in the references is faked: options that
the runtime does not report, or that the inventory has not confirmed, are not rendered
(`docs/workzone/runtime-controls-inventory.md`).
